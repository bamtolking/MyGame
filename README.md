# CRIMSON EXILE — 크림슨 엑자일

> 다크에덴의 **종족 전쟁과 낮밤 주기**, 디아블로 4의 **전투 감각과 전설 형상**, 패스 오브 엑자일의 **젬 링크·패시브 트리·오브 제작**을 하나로 섞은 브라우저 핵앤슬래시 ARPG.

빌드 도구, 서버, 외부 라이브러리 없이 `index.html` 하나로 실행됩니다.

## 실행

```bash
# 방법 1: 그냥 파일을 브라우저로 연다
open index.html            # macOS
start index.html           # Windows

# 방법 2: 로컬 서버 (권장, 폰트 로딩 등)
npx serve .                # 또는 python3 -m http.server 8080
```

크롬/엣지/파이어폭스 최신 버전 권장. 저장은 브라우저 `localStorage`에 자동 저장됩니다.

## 조작

## 세 게임에서 가져온 것

### 다크에덴
- **3종족**: 슬레이어(낮에 강함) · 뱀파이어(밤에 강함, 혈액 자원, 박쥐 변신) · 아우스터(새벽/황혼에 강함)
- **실시간 낮밤 주기** (5분 = 하루). 시간대에 따라 종족 피해 보너스/페널티가 실시간으로 변하고, 밤에는 시야가 좁아진다
- **블러드문**: 밤마다 35% 확률로 발생. 몬스터 드롭 증가, 뱀파이어 추가 강화
- **적대 종족 라이벌**: 티어 2부터 밤에 상대 종족 "추방자"가 플레이어를 사냥하러 온다 (연사·회피·포션 사용). 처치 시 희귀 아이템 확정

### 디아블로 4
- 탑다운 실시간 전투, 회피 구르기, 충전식 포션, 넉백·화면 흔들림·피격 비네트
- **형상(Aspect) 시스템**: 유니크 아이템에서 형상을 추출해 희귀/마법 아이템에 각인 → 전설 아이템
- **블러드문(헬타이드)**, **균열 이벤트**(30초 웨이브 생존 → 보상 상자), 제단 버프
- 보스별 패턴: 예고 범위 공격, 돌진, 소환, 광선, 토네이도

### 패스 오브 엑자일
- **스킬 젬 + 서포트 젬** (슬롯당 서포트 2개): 다중 투사체, 연쇄, 관통, 화염 부여, 집중 효과, 주문 반복, 근접 확산 등 19종. 젬은 처치 경험치로 성장
- **대형 패시브 트리** (100+ 노드, 주요 노드, 12개 키스톤: 혈맹, 유리 대포, 무자비, 정신 무장, 원소 과부하, 흡혈의 서약 …)
- **오브 제작**: 변환 · 변경 · 증강 · 군주 · 연금술 · 카오스 · 엑잘티드 · 무효 · 소멸 · 신성 · 후회 · 젬 연마사의 프리즘
- 접두/접미 티어 시스템, 일반/마법/희귀/유니크 희귀도, 몬스터 접두사(신속한·폭발하는·분열하는 …)
- **티어 맵 + 맵 모드**: 몬스터 강화 / 플레이어 페널티 모드에 따라 아이템 수량·희귀도 보너스. 보스 처치 시 다음 티어 해금
- 하드코어 모드 (사망 시 캐릭터 삭제)

## 시스템 요약

- 피해 유형 5종 (물리/화염/냉기/번개/카오스), 저항, 방어도/회피, 치명타
- 상태이상: 점화, 출혈, 둔화/동결, 감전, 기절
- 증가(additive)와 증폭(multiplicative)을 구분하는 PoE식 피해 계산
- 5개 지역 테마(저주받은 숲, 피의 묘지, 버려진 성당, 심연, 화염 협곡) + 각 테마 전용 보스
- 절차적 동굴 맵 생성, 미니맵 탐색, 스포일 데칼(핏자국), 동적 조명

## 파일 구조

```

css/style.css       UI 스타일
js/config.js        상수, 종족 정의

js/data_items.js    속성, 기본 아이템, 유니크, 형상, 화폐 데이터
js/items.js         아이템 생성, 이름, 툴팁, 오브 적용
js/data_gems.js     스킬 젬 / 서포트 젬 데이터
js/skills.js        스킬 계산 및 실행, 종족 궁극기
js/passives.js      패시브 트리 생성 및 할당
js/stats.js         캐릭터 스탯 계산
js/entities.js      투사체, 소환수, 파티클, 드롭
js/player.js        플레이어
js/combat.js        피해 판정, 상태이상, 처치 처리
js/monsters.js      몬스터 데이터, AI, 보스, 라이벌
js/world.js         맵 생성, 스폰, 존, 루팅, 이벤트
js/ui.js            HUD 및 패널 (DOM)
js/game.js          게임 루프, 입력, 렌더링
js/save.js          저장/불러오기
```
