# ⏰ 칼퇴 서바이버 (Clock-Out Survivor)

> **"오늘은 반드시 칼퇴한다."**
> 09:00부터 18:00까지, 몰려오는 메일·서류·회의·상사를 한 손으로 쓸어버리는 직장인 서바이벌 로그라이트.

탕탕특공대·뱀파이어 서바이버 계열의 **자동 공격 서바이벌**에 한국 직장인 유머를 입힌 모바일 웹게임입니다.
서버·회원가입·결제·광고가 없고, 브라우저(휴대폰 포함)에서 파일 하나로 실행됩니다.

## 바로 플레이

- **가장 쉬운 방법:** `play/index.html` 파일 하나가 게임 전체입니다. 휴대폰이나 PC 브라우저(Chrome/Safari)로 열면 바로 실행됩니다.
- **개발 서버:** Node.js 22 설치 후
  ```bash
  cd kaltoe
  npm install
  npm run dev      # 터미널에 표시되는 http://<PC의 IP>:5173 을 같은 Wi-Fi의 휴대폰으로 열기
  ```
- **설치형 앱(PWA):** `npm run build` 후 `dist/`를 아무 정적 호스팅(GitHub Pages 등)에 올리면 휴대폰에서 "홈 화면에 추가"로 앱처럼 설치되고 오프라인에서도 실행됩니다.

## 한 판의 흐름 (실시간 10분)

| 게임 속 시각 | 일어나는 일 |
|---|---|
| 09:00 | 출근. 시작 무기 하나로 자동 공격 시작 |
| 매 20초 안팎 | 보석(결재 도장)을 모아 **레벨업 → 3개 중 1개 선택** (무기 최대 6, 패시브 최대 6) |
| 10:00~ | 엘리트(고장난 프린터 등) 출현 → 처치하면 **택배 상자**(슬롯 연출, 1/3/5개 보상) |
| 11:30 | 중간 보스(팀장님·PM·건배사 과장·삼촌) |
| 12:00 | **점심 메뉴 선택**(국밥·마라탕·샐러드…) — 퇴근까지 유지되는 오후 버프 |
| 17:00 | **최종 보스**(부장님·본부장·폭탄주 부장님·큰이모) |
| 18:00 | 보스를 잡았다면 **칼퇴 성공!** 못 잡았다면 **"야근 확정"** — 시계가 17:59에 멈추고 잡아야 퇴근 |
| 18:00 이후 | (해금 시) **야근 모드**: 끝없이 강해지는 적, 분당 야근수당 |

- **진화:** 무기를 최대 레벨(8)로 올리고 **짝 패시브**를 가진 채 엘리트/보스 상자를 열면 진화합니다. 14가지 진화 레시피는 도감에서 하나씩 발견됩니다.
- **궁극기:** 적을 쓰러뜨리면 게이지가 찹니다. 캐릭터마다 다릅니다(사직서 투척, `rm -rf /`, 최종_진짜최종.psd, 법카 긁기…).

## 조작

- **휴대폰:** 화면 아무 곳이나 누른 채 끌면 그 자리에 조이스틱이 생깁니다(설정에서 고정 조이스틱 선택 가능). 오른쪽 아래 버튼이 궁극기, 오른쪽 위가 일시정지입니다.
- **PC:** WASD/방향키 이동, 스페이스 궁극기, Esc 일시정지.
- 화면을 벗어나면 자동으로 일시정지합니다.

## 계속 하게 만드는 것들 (메타 루프)

- **월급(코인) → 사내 복지:** 판마다 번 월급으로 복지를 도입해 모든 캐릭터를 영구히 강화합니다(되돌리기 가능).
- **업적 연쇄 해금:** 60여 개 업적이 새 무기·패시브·캐릭터·근무지·점심 메뉴·기능을 하나씩 엽니다.
- **캐릭터 8명:** 김신입·박대리·이개발·최디자·정인턴·한과장·윤팀장, 그리고 숨겨진 한 명.
- **근무지 4곳:** 월요일 사무실 → 분기 마감 야근 → 부서 회식 → 명절 친척집(잔소리 말풍선이 적입니다).
- **야근 강도 1~10:** 클리어할 때마다 다음 단계가 열리고, 적이 강해지는 만큼 월급이 늘어납니다.
- **오늘의 업무:** 날짜로 정해지는 캐릭터·근무지·특수 규칙 2개. 매일 보너스 월급과 연속 달성 기록.
- **출석 체크:** 7일 주기 출근 수당.
- **도감:** 무기·진화 레시피·적·점심 메뉴를 발견해 채웁니다.
- **자랑하기:** 결과를 1080×1350 이미지 카드로 공유(카카오톡 등)하거나 저장합니다.

## 구조

```
kaltoe/
  src/content/   게임 데이터(무기·패시브·적·스테이지·캐릭터·점심·복지·업적·규칙·밸런스·문구) — 스키마는 types.ts
  src/sim/       순수 TS 시뮬레이션(DOM 없음, 고정 스텝 1/60초, 결정적 난수) — 헤드리스로 테스트/밸런스 가능
  src/render/    Canvas 2D 렌더러, 이모지·절차적 스프라이트 캐시, 효과(파티클·피해 숫자·흔들림)
  src/ui/        화면(타이틀 자동 플레이 데모·선택·복지·업적·도감·설정·결과), HUD, 모달, 입력, 공유 카드
  src/meta/      업적 평가·해금·정산·일일 도전·출석
  src/platform/  저장(검증·백업·내보내기/불러오기), 절차적 사운드(WebAudio)
  tests/         콘텐츠 무결성·규칙 테스트, 헤드리스 봇 밸런스 스윕
  scripts/       단일 파일 빌드, 실브라우저(Chromium) 휴대폰 뷰포트 e2e
  docs/          BRIEF(고정 로스터), GDD(기획서), balance-results(봇 결과)
```

## 명령

```bash
npm test               # 콘텐츠·규칙 테스트 + 밸런스 스윕
npm run typecheck      # 타입 검사
npm run balance        # 밸런스 스윕만 → docs/balance-results.md
npm run build          # 타입검사 + 빌드(dist/) + play/index.html(단일 파일)
npm run e2e            # 헤드리스 Chromium, 휴대폰 뷰포트 3종 실기동 → e2e-out/
```

## 콘텐츠 추가하기 (확장 가이드)

모든 콘텐츠는 `src/content/*.ts` 배열의 데이터입니다. 엔진 코드를 고치지 않고 항목만 추가하면 됩니다.
추가 후 `npx vitest run tests/content.test.ts`가 상호 참조(진화 짝, 해금 업적, 소환 풀의 적 id 등)를 검사합니다.

### 무기 추가
`weapons.ts`에 `WeaponDef`를 추가합니다. `archetype`(14종: shot·spread·homing·bounce·boomerang·aura·orbit·beam·chain·strike·lob·nova·mine·drone)을 고르고 `base`(레벨 1 수치)와 `levels`(레벨 2~8의 증가분 7개)를 적습니다. 진화시키려면 `evolveWith`(패시브 id)·`evolvesTo`(진화 무기 id)를 넣고 `evolved: true`인 진화 무기를 하나 더 추가합니다.
```ts
{ id: 'stamp', name: '결재 도장', desc: '쾅! 반려입니다.', icon: '🔖', projectile: '🔖', color: '#e03131',
  archetype: 'strike', targeting: 'random',
  base: { damage: 30, cooldown: 2, amount: 2, area: 40, range: 400, speed: 0, duration: 0, pierce: 0, knockback: 6, hitCooldown: 0.5, interval: 0, delay: 0.4 },
  levels: [{ desc: '도장 +1', delta: { amount: 1 } }, /* …7개 */],
  unlockedBy: 'u_weapon_stamp' }
```

### 적·보스 추가
`enemies.ts`에 `EnemyDef`를 추가합니다. 행동은 `behavior`(chase·zigzag·dash·ranged·spawner·exploder·healer·buffer·straight)와 `params`로, 보스 패턴은 `abilities`(summon·charge·ring·aimed·slam·hazard·wall·enrage)로 조합합니다. 사람형 보스는 `body: { suit, tie }`를 넣으면 이모지 얼굴에 정장 몸통이 그려지고, `label`을 넣으면 말풍선 적이 됩니다.

### 근무지(스테이지) 추가
`stages.ts`에 `StageDef`를 추가합니다. 바닥 색(`palette`), 장식 이모지(`decor`), 0~600초를 빈틈없이 덮는 소환 구간(`timeline`), 시각별 이벤트(`events`: 무리·포위·엘리트·보스·토스트), 최종 보스(`finalBoss`)를 적습니다. 해금 업적을 `achievements.ts`에 `u_stage_<id>`로 추가하면 끝입니다.

### 그 밖에
- 캐릭터/궁극기: `characters.ts` (궁극기 원형 6종: blast·freeze·rain·vacuum·shield·clone)
- 점심 메뉴: `lunch.ts` · 복지: `meta.ts` · 업적: `achievements.ts` · 일일 규칙: `modifiers.ts`
- 수치 곡선(경험치·드롭·보상·야근 강도): `balance.ts`
- 문구(타이틀 문구·팁·사망/칼퇴 대사): `strings.ts`

## 알려진 한계

- 검증은 자동 테스트, 헤드리스 봇, 헤드리스 Chromium(휴대폰 뷰포트 3종)으로 했습니다. **실제 iOS/Android 기기에서 사람이 플레이한 검증은 아직 없습니다.**
- 저장은 이 브라우저(localStorage)에만 됩니다. 기기를 옮기려면 설정 → 저장 데이터 내보내기/불러오기를 쓰세요.
- 그래픽은 시스템 이모지를 쓰므로 기기(iOS/Android/Windows)마다 모양이 조금 다릅니다.
