# 칼퇴 서바이버 — 게임 디자인 문서 (GDD)

> 관련 문서: `docs/BRIEF.md`(고정 로스터·밸런스 목표) · `src/content/types.ts`(데이터 스키마 = 엔진 계약) · `src/content/strings.ts`(모든 랜덤 문구)
> 수치의 정본은 항상 `src/content/*.ts`다. 이 문서는 **왜 그렇게 만들었는지**와 **화면·연출·사운드의 명세**를 담는다.

## 1. 비전

**한 줄 소개** — *"09:00 출근, 18:00 칼퇴. 그 사이에 쏟아지는 메일·회의·부장님을 볼펜 한 자루로 쓸어버려라."*

- **장르**: 자동 공격 서바이벌 로그라이트(뱀서류·탕탕특공대류). 세로 모바일 웹, 한 손가락 조작.
- **한 판**: 실시간 10분 = 게임 속 09:00→18:00 (실시간 1초 = 0.9분, 1시간 ≈ 66.7초).
- **톤**: 한국 직장인 공감 유머. 적은 업무, 무기는 사무용품, 궁극기는 사직서. 누구나 웃을 수 있는 가벼운 풍자(특정 집단 비하·혐오·성적 표현 금지).
- **플레이어 약속**: ① 3초 안에 조작을 이해하고 ② 30초 안에 첫 레벨업의 쾌감을, ③ 10분 뒤 "한 판만 더"를 느낀다.
- **타깃**: 출퇴근길·점심시간 10분이 비는 20~40대 직장인/학생. 설치 없이 링크 하나로 실행.

## 2. 디자인 기둥

| 기둥 | 정의 | 이를 떠받치는 시스템 |
|---|---|---|
| **재미** (손맛·웃음) | 매 순간 화면이 터지고, 매 분 피식 웃는다 | 14개 무기 원형의 서로 다른 타격감 · 병합 데미지 숫자 · 히트스톱 · 적/보스 대사와 말풍선 적(명절 잔소리) · 궁극기 대사 · 스테이지 이벤트 토스트 |
| **중독성** (다음 목표가 항상 보임) | 판 안에서는 20초마다, 판 밖에서는 매 판마다 보상 | 레벨업 3택1 · 진화 발견(도감 ???) · 엘리트 상자 슬롯 · 점심 메뉴 · 야근 확정의 아슬아슬함 · 월급→복지 영구 강화 · 업적 연쇄 해금 · 출석/오늘의 업무 |
| **확장성** (데이터만 추가) | 코드 수정 없이 콘텐츠가 자란다 | 모든 콘텐츠는 `src/content/*.ts` 배열 · 무기 14원형 × 파라미터 · 적 9행동 원형 · 보스 8패턴 · 스테이지 = 타임라인+이벤트 · 모디파이어 플래그 · 해금 id 규칙 `u_<종류>_<id>` |

**설계 원칙**
1. **텍스트보다 연출**: 규칙은 토스트 한 줄과 아이콘으로. 설명서는 없다.
2. **실패도 보상**: 죽어도 벌어둔 월급은 가져간다. 첫 판부터 반드시 무언가 하나는 해금된다.
3. **발견은 플레이어의 몫**: 진화 레시피는 숨긴다. 힌트는 '소문' 팁과 도감의 반쪽 레시피로만.
4. **한 손, 한 화면**: 모든 입력은 엄지 하나로 닿는 하단 60%에 둔다.

- 사망 시: 부활 스탯이 있으면 "보험 처리 완료!" — 체력 50%로 부활, 2.5초 무적, 반경 220u 안 일반 적 소멸(보스 제외). 없으면 결과 화면(벌어둔 월급은 지급).

## 5. 조작

| 입력 | 모바일 | 데스크톱 |
|---|---|---|
| 이동 | **플로팅 조이스틱**: 화면 하단 65% 아무 곳이나 터치한 지점이 중심. 최대 반경 56px, 데드존 6px, 아날로그. 손을 떼면 정지·조이스틱 사라짐. 손가락이 반경 밖으로 나가면 중심이 따라온다 | WASD / 방향키 |
| 공격 | 자동 | 자동 |
| 궁극기 | 우하단 72px 원형 버튼(여백 24px + safe-area). 게이지가 원형으로 차오름. 가득 차면 1.2Hz 맥동(1→1.08배)+글로우+진동 20ms | Space |
| 일시정지 | 우상단 44px 버튼. 탭이 숨겨지면(visibilitychange) 자동 일시정지 | Esc / P |
| 카드 선택 | 탭. 오탭 방지: 모달 등장 후 0.35초간 입력 무시 | 1~4, R 새로고침, X 건너뛰기 |

- 설정에서 궁극기 버튼 좌/우 반전(왼손 모드), 조이스틱 고정형(좌하단 고정) 선택 가능.
- 조이스틱 영역과 궁극기 버튼이 겹치면 버튼이 우선. 멀티터치: 이동 중 다른 손가락으로 궁극기 가능.

### 6.1 타이틀
- 로고 "칼퇴 서바이버" + 랜덤 태그라인(`TITLE_TAGLINES`, 3초마다 교체). 배경은 마지막으로 플레이한 스테이지 팔레트로 적들이 천천히 흘러감.
- 큰 버튼 **출근하기**, 작은 버튼 4개(복지·업적·도감·설정). 우상단 월급 잔액 💰.
- 새 소식 빨간 점: 살 수 있는 복지, 받지 않은 업적 보상, 새로 채워진 도감.

### 6.2 출석 체크 팝업
- 7칸 도장 카드("출근 도장"). 오늘 칸에 도장이 **쾅**(스케일 1.6→1.0, 0.18초, 흔들림 0.3, 진동 30ms).
- 7일째 칸은 금색. 보상 수치는 meta.ts 정본. 닫기 = 화면 아무 곳 탭.

### 6.3 캐릭터 선택
- 가로 스와이프 카드. 절차적 초상(Look) + 이름·직급 + 시작 무기 아이콘 + 궁극기 이름/설명 + 보너스 스탯 칩.
- 잠긴 캐릭터: 실루엣 + 해금 업적 조건 문구. 숨은 캐릭터(낙하산)는 조건까지 `???`.

### 6.4 스테이지 선택 + 야근 강도
- 스테이지 4장 세로 리스트: 아이콘·이름·부제·보스 얼굴 2개·코인 배율. 잠김 = "이전 스테이지 칼퇴 시 해금".
- **야근 강도** 스텝퍼 1~10(기능 `heat` 해금 후). 단계를 올리면 적용 규칙 칩이 누적 표시되고 코인 배율이 커진다. 스테이지별 최고 클리어 강도에 도장 표시.
- **오늘의 업무** 탭(기능 `daily` 해금 후): 날짜 시드로 모두 같은 규칙(모디파이어 2~3개) + 고정 캐릭터/스테이지. 1일 1회 보상.

### 6.6 레벨업 카드
- 제목: 랜덤 `LEVELUP_SHOUTS`. 카드 3장(행운 시 4장) 세로 스택, 각 카드 = 아이콘 · 이름 · `NEW!` 또는 `Lv 3 → 4` · 레벨 문구(desc).
- **진화 힌트 배지**: 선택지가 보유 무기의 진화 짝이면 🔗 배지. 레시피를 이미 발견했으면 "○○ 진화 재료", 미발견이면 "무언가와 궁합이 좋아 보인다…".
- 하단 버튼: 🔄 새로고침(n) · ⏭ 건너뛰기(n) · 🚫 제외(n, 새 무기/새 패시브 카드에만, 이번 판 목록에서 영구 제거). 횟수 0이면 회색.
- 선택지가 없을 때는 "체력 30% 회복 / 월급 +25" 카드.

### 6.7 상자 슬롯 연출
- 엘리트/보스 처치 → 상자가 튀어나와 바닥에 2번 바운스. 플레이어가 닿으면 모달.
- 보상 개수 1 / 3 / 5(행운 영향, 보스 상자 최소 3). 각 슬롯은 무기·패시브 아이콘이 릴처럼 회전 후 정지. **진화가 가능하면 진화가 최우선**으로 첫 슬롯에 들어간다.
- 타이밍은 §8.8. 모든 슬롯이 멈추면 획득 월급이 카운트업, "확인" 버튼.

### 6.8 점심 메뉴 (12:00)
- 제목: 랜덤 `LUNCH_TITLES`. 해금된 메뉴 중 3개 무작위. 카드 = 큰 음식 이모지 + 이름 + 설명(스탯) + 즉시 회복량.
- 선택 시 "○○ 든든! 오후도 달려봅시다" 토스트, 이후 30초 소강 구간. 결과 화면과 도감에 기록.

### 6.9 일시정지 (빌드 요약)
- 제목: 랜덤 `PAUSE_TITLES`. 무기 6칸(레벨 점 ●●●●○○○○, 진화 무기는 금테), 패시브 6칸, 보유 무기별 진화 레시피 칸(발견 시 공개, 미발견 `???`).
- 현재 스탯 표(피해·범위·쿨타임·투사체·행운 등 기본 대비 %), 점심 메뉴, 랜덤 `TIPS` 1개.
- 버튼: 계속하기 / 설정 / **퇴사하기**(포기, 확인창: "정말 퇴사하시겠습니까? 벌어둔 월급은 챙겨갑니다").
- 🕶 **위장 모드**: 버튼 한 번에 가짜 스프레드시트 화면으로 전환(탭하면 복귀). 순수 웃음용.

### 6.10 결과
- 제목: 칼퇴 성공 "퇴근 완료 🎉" + `CLEAR_QUOTES` / 사망 "조퇴 처리" + `GAMEOVER_QUOTES` / 야근 확정 후 퇴근 "야근 후 퇴근".
- 통계: 생존 시각, 레벨, 처치, 엘리트·보스 처치, 최장 무피격, 받은 피해, 점심, 진화 목록.
- **무기별 피해** 가로 막대(피해량 내림차순, 비율 %, 처치 수). 1위 무기에 👑.
- **획득 코인** 내역: 처치 코인 + 상자 + 칼퇴 보너스 + 야근 수당 → × 스테이지 배율 × 강도 배율 × greed = 합계(카운트업 0.8초).
- **해금 알림**: 이번 판에 달성한 업적이 도장 연출로 하나씩(0.6초 간격), 해금된 것(무기·캐릭터 등)은 아이콘 확대. "다음 목표" 진행률 상위 3개(80% 이상 우선) 표시.
- 버튼: 다시 출근(같은 설정, 1탭) · 공유 카드 · 메인.

### 6.11 복지 (영구 강화)
- 그리드 카드: 아이콘·이름·설명·단계 점·다음 가격. 구매 시 도장 연출 + 코인 차감 애니메이션.
- 잠긴 복지는 업적 조건 표시. "전체 환불"(무료) 버튼으로 재분배 허용 → 실험 장려.

### 6.12 업적
- 카테고리 탭: 전체 / 해금 보상 / 처치 / 생존 / 수집 / 숨김. 진행 막대 + 보상 아이콘. 숨김 업적은 달성 전 `???`.

### 6.13 도감
- 탭: 무기 · **진화** · 패시브 · 적 · 점심 · 캐릭터. 상단 전체 수집률 %.
- 미발견은 검은 실루엣 + `???`. 무기는 최초 획득 시, 적은 최초 처치 시, 점심은 최초 선택 시 등록.
- **진화 레시피 발견식**: 기본 `??? + ??? = ???`. 그 무기를 한 번 만렙 → 왼쪽 공개, 진화 성공 → 전부 공개 + "새 레시피 발견!" 연출.
- 적 항목: 처치 수, 등장 스테이지, 한 줄 소개(적의 intro 문구).

### 6.14 설정
- 효과음/배경음 볼륨(0~100), 진동 켜기/끄기, 화면 흔들림(끔/약/보통), 번쩍임 줄이기, 데미지 숫자(모두/치명타만/끔), **저사양 모드**, 조이스틱(플로팅/고정), 궁극기 버튼 위치(좌/우), 글자 크기(보통/크게), 데이터 내보내기/초기화, 크레딧.

## 7. 첫 판 온보딩 (최소 텍스트)

규칙: **튜토리얼 화면 없음**, 힌트는 한 줄 + 손가락/화살표 그림, 각 힌트는 평생 1회(localStorage 플래그).

| 순서 | 트리거 | 연출 | 문구 |
|---|---|---|---|
| 1 | 첫 판 시작(김신입 + 월요일 사무실 자동 선택) | 하단에 반투명 손가락이 원을 그림 | "드래그해서 이동" |
| 2 | 첫 처치 | 없음(자동 공격을 보여주기만) | "공격은 자동!" |
| 3 | 보석이 반경에 들어옴 | 보석 흡수 곡선 강조 | — |
| 4 | 첫 레벨업 | 카드 3장이 순서대로 튀어나옴, 첫 카드 테두리 맥동 | "하나 고르세요" |
| 5 | 궁극기 게이지 첫 충전 | 버튼 위 화살표 바운스 | "사직서 준비 완료!" |
| 6 | 첫 엘리트 등장 | 화면 밖 화살표 + 상자 아이콘 | "잡으면 상자!" |
| 7 | 첫 무기 만렙 | 토스트 | "최대 레벨! 짝 패시브 + 상자 = 진화" |
| 8 | 첫 결과 화면 | 복지 버튼에 빨간 점 | "월급으로 복지를 사세요" |

- 첫 판 보장: 결과와 관계없이 업적 1개 이상 달성(예: 첫 출근) → 코인 보상 → 복지 1단계를 살 수 있게 설계.
- 첫 3판은 캐릭터/스테이지 선택 화면을 짧게(선택지 1~2개뿐이므로 자동 넘김 가능).

## 8. 손맛(juice) 명세

### 8.1 피격 플래시
- **적 피격**: 스프라이트 흰색 오버레이 0.12초(화상 틱은 0.04초). 치명타는 노란 테두리 1프레임 추가.
- **플레이어 피격**: 화면 가장자리 빨간 비네트 알파 0.35 → 0(0.3초), 캐릭터 깜빡임 0.1초×2, 진동 25ms. 번쩍임 줄이기 옵션 시 알파 0.15.
- **전체 번쩍임**(궁극기·폭탄·진화): 알파 최대 0.85, 초당 2.5 감소.

### 8.2 넉백
- 무기 `knockback`(u)을 0.12초에 걸쳐 감속하며 밀어냄(시작 속도 = knockback/0.06). `knockbackResist`만큼 감소(보스 대개 1).
- 궁극기 blast는 반경 안 적 일괄 넉백 80u, 부활은 반경 220u 정리 + 넉백 60u.

### 8.3 히트스톱 & 슬로모션
| 사건 | 히트스톱 | 이후 |
|---|---|---|
| 일반 적 처치 | 없음 | 파티클 6개 + 종이 조각 |
| 엘리트 처치 | **60ms** | 흔들림 0.5, 상자 바운스 |
| 중간 보스 처치 | **120ms** | 시간 0.3배 0.6초 → 1배 |
| 최종 보스 처치 | **180ms** | 시간 0.25배 1.0초, 화면 번쩍임 0.6, "퇴근 확정!" 대형 텍스트 |
| 진화 | 100ms | 금색 링 + 무기 아이콘 교체 |
| 레벨업 | 없음 | 시간 1 → 0.2배(0.15초) 후 카드 모달, 선택 후 0.2 → 1배(0.25초) |

- 레벨업 모달이 닫힐 때 플레이어 주변 90u에 피해 없는 밀치기 링(넉백 40) → 선택 직후 억울한 피격 방지.

### 8.4 화면 흔들림 강도표
흔들림 값 s(0~1)는 누적 후 1로 제한, 초당 2.2 감소. 오프셋 = 14 × s² (px). 설정 "약"은 s × 0.5, "끔"은 0.

| 사건 | 추가 s | 체감 최대 오프셋 |
|---|---|---|
| 폭발형 무기 착탄(lob·strike·mine) | 0.06 | 누적형 |
| 플레이어 피격 | 0.25 | ≈ 0.9px (가벼운 떨림) |
| 폭발형 적(긴급 이슈·폭탄주) 폭발 | 0.35 | ≈ 1.7px |
| 보스 slam / charge 충돌 | 0.55 | ≈ 4.2px |
| 엘리트 처치 | 0.5 | ≈ 3.5px |
| 궁극기 발동 | 0.7 | ≈ 6.9px |
| 보스 등장 경고 | 0.6 (1초간 유지) | ≈ 5px |
| 최종 보스 처치 | 1.0 | 14px |

### 8.5 데미지 숫자 병합
- 같은 적에게 **0.22초 안에** 들어온 피해는 한 숫자로 합산(수명 연장 0.55초). 기본 수명 0.6초, 초당 38px 상승, 등장 시 팝(1.4배 → 1배).
- 일반 11px 흰색 / 치명타 15px 노랑(#ffd43b) / 1000 이상 1.15배 + `1.2k` 표기. 검정 외곽선 3px.
- 동시 표시 최대 90개(초과 시 가장 오래된 것 제거). 저사양 모드 = 치명타만.

### 8.6 보석 흡수 곡선
- 획득 반경 = 45u × (1 + magnet). 반경에 들어오면 **0.08초 동안 바깥으로 살짝 튕김(-60u/s)** 후 가속도 1600u/s²로 플레이어를 향해 가속, 최대 750u/s. 도착 시 흡수 파티클 3개.
- 연속 흡수 콤보: 0.4초 안에 이어 먹으면 흡수음 피치가 반음씩 상승(최대 +12반음), 끊기면 초기화.
- 보석 색: 1 파랑 / 5+ 초록 / 20+ 빨강 / 100+ 무지개. 화면에 보석 400개 초과 시 가장 먼 것부터 합쳐 큰 보석 1개로.
- 자석 아이템: 모든 보석이 같은 곡선으로 동시에 날아옴 + 짧은 "촤라락" 효과음.

### 8.7 기타 연출
- **보스 등장**: 화면 상하 검은 띠(시네마 바) 0.3초 인, 경고 사이렌, 보스 이름 카드 1.2초, intro 문구 말풍선.
- **보스 패턴 예고**: slam은 빨간 원이 windup 동안 차오름, charge는 진행 방향 반투명 띠.
- **궁극기**: 캐릭터 컷인(초상 + shout 대사) 0.5초 슬라이드 → 발동. 컷인 동안 시간 0.1배.
- **야근 확정**: 시계 숫자가 흔들리다 17:59로 고정, 화면 테두리 붉은 맥동(주기 1.5초), 대사 `YAGEUN_CONFIRMED`.
- **칼퇴**: 6시 종 3번 + 모든 적이 종이 조각으로 흩어짐(0.8초) + "퇴근!" 스탬프.

### 8.8 상자 슬롯 타이밍
| 구간 | 시간 |
|---|---|
| 상자 흔들림(뚜껑 들썩) | 0.45초, 진동 3회 |
| 뚜껑 열림 + 빛기둥 | 0.25초 (진화 포함 시 금색) |
| 슬롯 회전 | 첫 슬롯 0.9초, 이후 슬롯마다 +0.25초 지연 정지 (5개면 총 ≈ 1.9초) |
| 슬롯 정지 | 1슬롯당 틱 효과음 + 흔들림 0.1 |
| 진화 슬롯 | 정지 후 0.5초 홀드 → 금색 폭발 + 팡파르, "진화!" |
| 코인 카운트업 | 0.6초 |
| 스킵 | 0.3초 이후 탭하면 모든 슬롯 즉시 정지 |

**BGM 강도 레이어** (절차적 시퀀서, 4마디 루프, 스테이지마다 스케일·음색만 교체)
| 레이어 | 켜지는 조건 | 내용 |
|---|---|---|
| L1 기본 | 항상 | 패드 + 베이스(8분음) |

| L3 멜로디 | 적 150+ 또는 엘리트 생존 | 리드 멜로디(펜타토닉) |

## 10. 리텐션 장치

1. **출석 체크**: 7일 도장 카드, 연속일수록 보상 증가(`attendanceDays` 업적과 연동).
2. **오늘의 업무**: 날짜 시드 일일 도전(모디파이어 조합: 노힐, 머리 크게, 체력 1, 유리대포, 빠른 시계, 엘리트 러시 등). 모두 같은 조건이라 공유 욕구 자극.
3. **업적 연쇄 해금**: 스테이지 칼퇴 → 다음 스테이지, 무기 처치 수 → 새 무기, 캐릭터 레벨 → 새 캐릭터. 결과 화면에서 항상 "다음 목표"를 보여 줌.
4. **도감 수집률**: 진화 14종·적·점심의 `???`를 채우는 욕구. 수집률 구간 업적.
5. **야근 강도 1~10**: 스테이지 × 강도 도장판. 강도가 오를수록 코인 배율 증가.
6. **야근 모드 신기록**: 최장 야근 시간, 결과 카드에 표시.
7. **변동 보상**: 상자 1/3/5 슬롯, 4번째 선택지, 희귀 아이템(치킨). 확률은 행운으로 조정 가능.
8. **아슬아슬한 실패**: 야근 확정(시계가 멈추고 계속 싸울 수 있음) → "조금만 더 강했으면" 동기.
9. **빠른 재시작**: 결과 → 다시 출근 1탭, 로딩 없음.
10. **복지 빨간 점**: 살 수 있는 강화가 생기면 타이틀에 표시.

## 11. 공유 기능 (결과 카드 이미지)

- 결과 화면 "공유" → 오프스크린 캔버스로 **1080×1350(4:5)** PNG 생성.
- 구성: 스테이지 팔레트 배경 + 바닥 타일, 캐릭터 절차적 초상, 큰 도장("칼퇴 성공" 파랑 / "조퇴" 회색 / "야근 후 퇴근" 빨강), 게임 시각, 레벨, 처치 수, 무기 6 + 패시브 6 아이콘, 최고 피해 무기 👑, 점심 메뉴, 한 줄 문구(결과 인용구), 하단 게임 이름·링크 텍스트.
- 공유 문구: `SHARE_TEMPLATES` 중 무작위, 자리표시자 `{stage}` `{time}` `{level}` `{kills}` `{char}` 치환.
- `navigator.share({ files })` 지원 시 이미지+문구, 미지원 시 PNG 다운로드 + 문구 클립보드 복사 + "복사됨" 토스트.

## 13. 접근성

- 화면 흔들림 끔/약, 번쩍임 줄이기, 데미지 숫자 끄기, 진동 끄기.
- 색에만 의존하지 않기: 적 탄은 흰 외곽선 + 형태(원/마름모), 보스 예고는 빨간색 + 점선 테두리.
- 글자 크기 2단계, 모든 버튼 터치 영역 ≥ 44px.
- 왼손 모드(궁극기 버튼 좌측), 조이스틱 고정형.
- 언제든 일시정지(모달 포함), 탭 전환 시 자동 일시정지.
- 모든 정보성 토스트는 아이콘 + 짧은 문장. 효과음 없이도 게임 상태를 알 수 있게 시각 신호를 짝지음.

## 14. 성능 목표

| 항목 | 목표 |
|---|---|
| 프레임 | 중급 안드로이드(2020년형)·아이폰 11에서 **60fps**, 최악 구간 45fps 이상 |
| 동시 적 | 상한 **450** |
| 투사체 / 파티클 | 투사체 600, 파티클 700(저사양 220) |
| 시뮬레이션 | 고정 틱 60Hz, 렌더 분리. 공간 해시 그리드로 충돌 O(n) |
| 메모리 | 프레임당 할당 0 지향(오브젝트 풀), 힙 60MB 이하 |
| 렌더 | 이모지 스프라이트는 첫 사용 시 오프스크린 캔버스에 캐시. DPR 최대 2(저사양 1) |
| 용량 | 단일 HTML 파일 ≤ 600KB(외부 에셋 없음, 사운드 합성) |
| 로딩 | 첫 화면 1초 이내 |

**저사양 모드**: 파티클 220, 데미지 숫자 치명타만, 그림자·비네트 끔, DPR 1, 보석 합치기 임계값 200. 평균 프레임 22ms 초과가 5초 지속되면 "저사양 모드를 켤까요?" 1회 제안.
