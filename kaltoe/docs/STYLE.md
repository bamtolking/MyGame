# 칼퇴 서바이버 — 비주얼·사운드 리디자인 방향서 (v2 "야근 네온")

사용자 요청: **"전체적으로 업스케일링, 타격 모션 이펙트·배경음악·효과음 다 너무 구려 — 간지나게."**
목표는 한 번 보면 "오, 이거 제대로 만든 게임이네" 소리가 나는 선명함·손맛·사운드. 기존 게임 규칙·밸런스·UI 흐름은 그대로 둔다.

## 1. 비주얼 콘셉트: 야근 네온 (Overtime Neon)

해가 진 사무실. 모니터·형광등·네온사인만 켜진 어둑한 공간에서 **빛나는 무기와 타격이 화면을 지배**한다.
- **어둡고 채도 낮은 배경 + 채도 높은 발광 효과.** 바닥·장식은 명도를 낮춰(값 15~30%) 무대 뒤로 물러나고, 투사체·폭발·불꽃·보석은 가산 합성 글로우로 튀어나온다.
- **빛의 위계:** 플레이어 주변 조명(따뜻한 스탠드 빛) > 무기 발광 > 적(림라이트) > 바닥.
- **선명함:** 기기 해상도 그대로(최대 dpr 3) 그린다. 스프라이트는 실제 픽셀 크기로 미리 그리고, 성능이 모자라면 해상도보다 **효과를 먼저** 줄인다.
- **움직임:** 모든 것에 무게감 — 피격 시 찌그러짐(squash)·반동, 이동 시 기울기, 죽을 때 팝.

|---|---|---|---|

### 레이어와 후처리 (렌더 담당)
1. 바닥(타일 텍스처 + 스테이지 소품: 책상·파티션·화분·케이블 등 절차적 그림, 은은한 그림자) → `fx.drawGround`(잉크 자국·그을음)
2. 그림자 → 픽업 → 적 → 플레이어 → 궤도체·드론 → 투사체(잔상/리본 트레일) → 광선·고리 → 적 탄
3. `fx.drawWorld`(파티클·불꽃)
4. **조명 레이어:** 화면을 어둡게 덮고(곱하기) 플레이어 주변·광원 자리만 밝게. 광원 = 플레이어, 폭발·번개(`fx.drawLights`), 보스·엘리트 림라이트, 불타는 적.
5. **블룸:** 1/4 해상도 버퍼(+ 1/8 추가 패스)에 빛나야 하는 것만(투사체·광선·폭발·불꽃·보석·오라 가장자리·`fx.drawGlow`) 그린 뒤 가산 합성으로 확대해 얹는다.
5b. `fx.drawLabels`(피해 숫자·떠오르는 글자 — 조명·블룸 뒤, 월드 UI 앞: 어둠에 묻히지 않게)
6. 비네트(근무지 색) → `fx.drawScreen`(번쩍임·집중선·레터박스·피격 붉은 테두리) → 조이스틱·방향 표시
- 품질 단계: `high`(블룸 2단 + 동적 조명 + 트레일 + 파티클 많이) / `medium`(블룸 1단, 조명 단순, 파티클 60%) / `low`(블룸·조명 없음, 그림자 없음, 파티클 30%). 앱이 자동 사다리로 품질과 해상도를 조절한다(`QUALITY_LADDER` in app.ts).

### 개체
- **적:** 이모지 몸 + 2px 짙은 외곽선 + 근무지 조명색 림라이트 + 접지 그림자 + 화난 눈(유지). 피격: 흰 번쩍임 + 60ms 찌그러짐(가로 1.25·세로 0.8) + 살짝 밀림. 엘리트: 바닥 오라 고리 + 금색 외곽선. 보스: 큰 그림자, 붉은 림라이트 맥동, 명판.
- **플레이어:** 더 크고 또렷한 치비 직장인(외곽선·음영·하이라이트), 이동 방향으로 기울기, 달릴 때 먼지, 발밑 빛.
- **투사체:** 무기 고유색 글로우 + 트레일, 진행 방향 회전. 진화 무기는 더 크고 밝게 + 추가 파티클.
- **픽업:** 보석은 반짝이는 글로우 + 끌려올 때 줄무늬 잔상, 코인은 회전 광택.

## 3. 사운드 방향 (음악·효과음 담당)
전부 WebAudio 실시간 합성(외부 음원 없음). 코어(`platform/audio.ts`)가 버스·리버브·딜레이·리미터·덕킹을 제공한다.

### 음악 (곡 id → 콘셉트)
| 곡 | 콘셉트 | 템포 | 조성·진행 예 |
|---|---|---|---|
| title | 로파이 시티팝, 로즈 FM 피아노·따뜻한 베이스·브러시 드럼, 테이프 느낌 | 88~92 | Fmaj7–Em7–Dm7–G7sus |
| office | 업비트 신스웨이브 펑크, 4/4 킥, 슬랩 느낌 베이스, 밝은 아르페지오, 코러스 리드 | 118~124 | I–V–vi–IV 변형, 7th 화음 |
| crunch | 다크 신스웨이브(단조), 펄스 베이스, 차가운 패드 | 126 | Am–F–C–G |
| dinner | 회식 트로트·디스코 뽕끼(2박 쿵짝, 브라스 신스, 흥) | 128~132 | 단조 트로트 선율 |
| holiday | 국악 퓨전: 5음계, 가야금 느낌 플럭(Karplus-Strong), 장구 리듬 + 현대 비트 | 112~116 | 평조/계면조 5음계 |
| boss | 공격적, 디스토션 베이스, 스네어 롤, 긴장 반음 | 140 | 반음계 긴장 |
| overtime | 다크 테크노, 미니멀·최면적 | 132 | 단조 한 화음 |

- 강도 0~3 레이어: 0 = 패드·베이스, 1 = +드럼, 2 = +아르페지오/멜로디, 3 = +리드·추가 타악·필인.
- 스팅어: victory(시티팝 팡파르), defeat(슬픈 로즈), levelup(짧은 상승 화음), evolve(에픽 라이저+화음), lunch(종소리), bossIntro(저음 브라스+경보).
- 곡 전환은 마디 경계에서 크로스페이드. 킥에 맞춰 패드·베이스 사이드체인 덕킹.
- 레벨: 음악 RMS −24 ~ −14 dBFS, 피크 ≤ 0.99(클리핑 0) — `scripts/audio-check.mjs`로 확인.

### 효과음
- 여러 겹(트랜지언트 + 몸통 + 꼬리), 음높이 무작위 변주, 화면 좌우 위치로 팬, 큰 소리는 리버브 센드 + 음악 덕킹.
- 무기별 정체성: 볼펜 휙(짧은 바람), 커피 지글, 명함 스치는 소리, 서류철 붕붕, 클립 챙, 번개 지직(FM 잡음), 레이저 웅(지속), 토너 퉁 + 폭발, 종이비행기 슉, 엔터키 딸깍+충격파, 드론 삐빅, 법인카드 칭, 포스트잇 톡, 알람 따르릉.
- 처치 팝은 연속 처치에 따라 음이 조금씩 올라가고(콤보), 보석 획득은 5음계로 올라가는 반짝임.
- 피격 음은 짧고 굵게(저역 쿵 + 로우패스 잡음), UI 클릭은 부드럽게.
- 동시 발음 수 제한(스로틀·보이스 캡)으로 탁해지지 않게.

## 4. UI 방향 (UI 담당)
- 서체: 제목·HUD 숫자·배너·큰 버튼 = **Black Han Sans**, 본문 = **Noto Sans KR**(`ui/fonts.ts`의 DISPLAY_FONT/BODY_FONT; Google Fonts, 오프라인이면 시스템 글꼴).
- HUD: 반투명 유리 패널 + 근무지 강조색 얇은 네온 테두리, 시계 글로우, 경험치바 광택 애니메이션, 무기 슬롯 카드(레벨 점), 보스 체력바 재디자인(해골 아이콘, 흰 '따라오는' 잔상 바) — **무기 슬롯 6개가 한 줄이어도 보스바와 겹치지 않게.** 궁극기 버튼: 원뿔 게이지 링, 준비되면 발광 맥동.
- 모달: 레벨업 카드 등급 테두리(무기 청록·패시브 보라·진화 가능 금색), 순차 등장, 상자 빛줄기, 배너 사선 줄무늬·발광 글자.
- 메뉴: 타이틀 로고 업그레이드(디스플레이 서체 + 네온 글로우), 버튼 광택, 화면 간 일관성.
- **바꾸면 안 되는 것:** e2e/스크린샷 스크립트가 쓰는 클래스·문구(`.choice`, `.ult`, `.pausebtn`, `.lunch-card`, `.chest-stage`, `.result-head`, `.confirm-wrap .btn.primary/.danger`, `.title-grid .btn`, `.screen-head .btn.icon`, `.modal`, 버튼 문구 '출근하기', '다음 → 근무지 선택', '🏃 출근!', '▶ 계속 일하기', '🏳 조퇴하기', '받기!').

## 6. 계약(인터페이스) — 바꾸지 말 것
- `Fx` 레이어 훅: `drawGround / drawWorld / drawGlow / drawLights / drawLabels / drawScreen(g, View)`, `zoomPunch()`, `shakeOffset()`, `update(dt)`, `reset()`, `invalidateText()`, `setLow()`, 그리고 juice가 부르는 생성 메서드들(`burst, dmg, boom, bolt, text, addShake, addFlash` — VFX가 새 메서드를 더하는 건 자유). `View`, `Quality` 타입은 fx.ts.
- `juiceEvent(fx, ev, w, {vibrate})`, `juiceDeath(fx)` — app.ts가 부른다.
- `Renderer`: `render(w, dt, joy, steps)`, `resize()`, `viewSize()`, `setQuality(q)`, `dprCap`, `camX/camY`, `live`, `fx`. 렌더러는 `fx.zoomPunch()`/`fx.shakeOffset()`을 적용하고 레이어 훅을 위 순서로 부른다.
- 오디오: `createMusic(core, live): MusicAPI`(start/stop/setTrack/setIntensity/stinger/scheduleRange), `createSfx(core): SfxAPI`(play/onSimEvent), `SFX_NAMES`, `TRACK_IDS`, `STINGER_IDS`. 기존 효과음 이름은 계속 동작해야 한다(새 이름 추가 가능). 오프라인 렌더링(`scheduleRange`)이 실시간과 같은 소리를 내야 한다.
- 스프라이트 캐시는 `setSpriteScale`/`clearSpriteCache`로 무효화된다. 글자를 캐시하는 곳은 `onFontsReady` 이후 다시 그려져야 한다(`clearSpriteCache`, `fx.invalidateText`가 호출됨).

## 7. 성능 예산
- 기준(변경 전, 헤드리스 소프트웨어 렌더 390×844@2x): 무거운 장면(적 ≈160, 무기 6) **39.6fps**.
- 변경 후: `medium` 품질에서 기준의 90% 이상, `high` 품질에서 28fps 이상(헤드리스는 GPU가 없어 실기기보다 훨씬 느림). 메인 스레드 작업(앱 `debugState().work`, ms/프레임)은 무거운 장면에서 평균 9ms 이하.
- 금지: 프레임마다 그라디언트·캔버스 새로 만들기, 적마다 save/restore, 프레임마다 문자열 렌더, 무제한 캐시(크기 제한 필수), 적 수에 비례하는 전면 오버드로.

## 8. 점검 도구
- `node scripts/shots.mjs <html> <outDir>` — 타이틀·4개 근무지 초반·무거운 전투·보스·궁극기·레벨업·상자·일시정지 스크린샷 + 무거운 장면 FPS. **Read 도구로 PNG를 직접 보고 판단할 것.**
