# 야식 대질주 — 보름달까지 달려라! (베타)

도깨비 방망이로 깨어난 야시장 간식들이 **몸이 식기 전에** 보름달 잔치까지 달려가는 두 버튼 자동 달리기 게임입니다.
쿠키런 같은 러너 장르의 흥행 요소는 가져오고, 플레이어들이 싫어했던 점(하트·에너지, 뽑기, 강화, 광고, 유료 부활, 억울한 판정)은 덜어냈습니다.
싱글 플레이, 서버·계정·결제·광고 없음. 휴대폰 브라우저(세로·가로)와 PC에서 실행되는 HTML5 게임이고, 웹에 올리면 홈 화면에 앱처럼 설치(PWA)할 수 있습니다.

> 한 문장: **누구나 3초면 배우지만, 모든 피격은 내 탓이고 모든 점수는 내 실력인 러너.**

## 바로 실행하기

1. **가장 쉬운 방법**: `play/index.html` 파일 하나가 게임 전체입니다. 휴대폰이나 PC 브라우저로 열면 바로 실행됩니다(인터넷 불필요).
2. **개발 서버** (같은 Wi‑Fi의 휴대폰에서 테스트): Node.js 22 설치 후
   ```bash
   cd runner
   npm install
   npm run dev      # 터미널에 표시되는 http://<PC의 IP>:5173 을 휴대폰 브라우저로 열기
   ```
3. **앱처럼 설치**: `npm run build` 후 `dist/` 폴더를 HTTPS 정적 호스팅(GitHub Pages, Netlify 등)에 올리고 휴대폰에서 열어 "홈 화면에 추가". 오프라인에서도 실행됩니다.

## 조작

| 입력 | 동작 |
|---|---|
| 화면 왼쪽 절반 탭 (세로: 왼쪽 큰 패드) · Space/↑/W/Z | 점프, 공중에서 한 번 더 = 2단 점프 |
| 화면 오른쪽 절반 누르고 있기 (세로: 오른쪽 패드) · ↓/S/Shift/X | 슬라이드 · 공중에서는 빠른 낙하 |
| ⏸ · P/Esc | 일시정지 (화면을 벗어나면 자동 일시정지) |

설정에서 좌우 바꾸기, 버튼 표시, 슬라이드 토글, 게임 속도(60–100%) 등 도움 옵션을 켤 수 있습니다.

## 흥행작에서 가져온 것 · 덜어낸 것 (요약)

| 가져온 것 | 우리 버전 |
|---|---|
| 두 버튼(점프·슬라이드), 2단 점프 (쿠키런) | 코요테 타임·점프 선입력·착지 직전 입력 보존·턱 보정으로 판정은 관대하게 |
| 체력이 곧 시간 (쿠키런) | '따끈함'이 식어 가고, 꿀물로 데우고, 부딪히면 확 식음 |
| 길을 그려 주는 젤리 줄 | 별사탕 줄 = 안전한 궤적. 모든 별사탕은 무피격 경로에서 먹을 수 있음을 자동 증명 |
| BONUSTIME 글자 모으기 | 보·름·달·잔·치 5글자 → 10초 하늘 잔치, 위기에 들어가면 왕보름달 잔치 |
| 캐릭터 고유 스킬, 펫, 이어달리기 | 6명 모두 '동사 하나만 다른' 사이드그레이드, 짝꿍 3종, **무료** 이어달리기 |
| 에피소드 스테이지·별 3개 (오븐브레이크) | 골목 지도: 고정 코스, ★ 도착 · 별사탕 % · 황금 복주머니 |
| 미션 3칸·계급 (젯팩 조이라이드) | 언제든 무료 교체, 점수 배수 없음 |
| 매일 같은 코스 (데일리 시드) | 오늘의 골목: 무제한 도전, 7일 보관, 연속 출석 압박 없음 |
| 최고 기록 유령 (마리오 런) | 결정적 시뮬 + 입력 기록으로 내 최고 기록과 함께 달리기 |

| 덜어낸 단점 | 해결 |
|---|---|
| 하트·에너지로 판 수 제한 | 무제한, 타이머 없음 |
| 뽑기·강화·파워 인플레·유료 부스트 | 없음. 해금 조건과 가격을 미리 공개 |
| 유료 부활·'이어하기?' 창·광고 | 없음. 구덩이도 즉사 대신 구출 튕김 |
| 프레임 단위 패턴, 그림보다 큰 판정 | 모든 청크를 실제 물리로 증명하고, 강제 동작마다 150–250 ms 이상의 여유 창 보장. 판정은 그림 안쪽 |
| 회전 강요 | 세로 '게임보이' 배치와 가로 모두 정식 지원 |

자세한 기획은 `docs/GDD.md`를 보세요.

## 구조

```
src/data/      수치·콘텐츠: 물리, 튜닝, 청크(ASCII), 캐릭터, 짝꿍, 풍경, 스테이지
src/sim/       순수 TS 시뮬레이션: 몸 물리, 청크 파서, 공정성 검증기/탐색기, 레벨 생성, 런 규칙, 자동 조종기
src/meta/      저장 모델·보상·미션·업적 (DOM 없음, 테스트됨)
src/render/    Canvas 2D: 절차적 캐릭터·짝꿍·배경·위험물·아이템, 이펙트, HUD
src/ui/        화면·입력·루프
src/platform/  저장(검증·백업·마이그레이션), WebAudio 절차 사운드, PWA
tests/         Vitest: 청크 공정성, 규칙, 결정론, 메타, 스테이지, 밸런스 봇 스윕
scripts/       단일 파일 빌드, 아이콘 생성, Playwright 모바일 e2e
docs/          기획서(GDD), 상태, 테스트 결과, 청크·밸런스 리포트
```

- 고정 스텝(1/60초) 결정적 시뮬레이션. 같은 시드 + 같은 입력 = 같은 결과(리플레이 해시 테스트). 시뮬에는 정확히 정의된 연산만 씁니다.
- **공정성 검증기**: 모든 청크를 실제 플레이어 물리로 탐색해, 판정 상자를 키우고 입력 간격을 제한한 불리한 조건에서도 무피격으로 통과할 수 있음을 증명합니다(티어별 모든 속도, 모든 입력 위상).
- 코스는 메인 청크 순번별 독립 난수로 뽑아서, 누가 어떻게 달리든(보너스 순간이동 포함) 같은 시드면 같은 코스입니다.

## 명령

```bash
npm test            # 전체 테스트 (청크 공정성 증명 포함, 수 분)
npm run validate    # 청크 공정성 증명만 → docs/chunk-report.md
npm run balance     # 봇 밸런스 스윕 → docs/balance-results.md
npm run build       # 타입검사 + 빌드 + play/index.html (단일 파일)
npm run e2e         # 헤드리스 Chromium으로 휴대폰·데스크톱 뷰포트 실기동 테스트
```
