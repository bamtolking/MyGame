# 테스트 결과

마지막 전체 실행: `npx vitest run` → **테스트 파일 10개, 테스트 192개 모두 통과** (약 3분 10초). 브라우저 e2e: `node scripts/e2e.mjs` → **201개 확인 모두 통과, 콘솔 오류 0**.

## 브라우저 e2e (`scripts/e2e.mjs`, 헤드리스 Chromium)

화면: 390×844 · 360×640 · 844×390 · 1280×720(마우스·키보드) · 저장소 차단 · 640×360(좌우 바꾸기).
확인 예: 첫 탭이 점프하고 소리가 켜짐, 두 손가락 입력과 누른 채 탭, 버튼이 다른 손가락이 닿아 있어도 동작, 튜토리얼 되감기 안내(40% 속도), 일시정지·자동 일시정지·3-2-1 재개, 420 ms 멈춤 자동 일시정지, 뒤로 가기(달리는 중 = 일시정지, 메뉴 = 홈, 홈 = 나가기), 1-1 완주 → ★ 기록, 결과 화면 연타 보호, 점수 내역 줄바꿈, 세로 패드 크기 ≥ 180×120.

## 성능 (`scripts/perf.mjs`, 4배 CPU 제한, 3회 중앙값)

| 화면 | 프레임 p95 |
|---|---|
| 세로 390×844 | 4.7 ms |
| 가로 844×390 | 6.5 ms |

바이옴이 바뀌는 프레임 2–5 ms, 즉시 다시하기 33–37 ms.
