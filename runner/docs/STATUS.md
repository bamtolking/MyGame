# 야식 대질주 — 현재 상태 (베타)

한 줄 요약: **플레이 가능한 완성 베타**입니다. 무한 달리기·골목 지도 21단계·오늘의 골목·튜토리얼, 캐릭터 6·짝꿍 3, 미션·업적·꾸미기까지 모두 들어 있고, 자동 테스트와 헤드리스 브라우저 e2e를 통과합니다. 실제 휴대폰 기기에서의 손맛 검증은 아직 사람이 해 봐야 합니다.

## 품질 관문 (모두 자동)

- **공정성**: 모든 청크를 실제 물리로, 판정 상자를 키운 불리한 조건과 모든 입력 위상에서 무피격 통과 증명. 모든 별사탕·꿀물·복주머니가 무피격으로 먹을 수 있음을 증명.
- **결정론**: 같은 시드 + 입력 기록 = 같은 해시. 시뮬은 정확한 연산만 사용(테스트로 강제).
- **밸런스**: 봇 4단계(전문가·능숙·보통·초보)가 실제 스트림을 플레이. 숙련도 순서와 캐릭터 점수 균형(±12%)을 테스트로 고정. 결과는 `balance-results.md`.
- **스테이지**: 21단계 모두 첫 도전 클리어율이 목표 경사(W1 95→85%, W2 85→70%, W3 75→55%, 리믹스 ≥40%)의 ±10 안, ★2 기준은 보통 봇의 p55, 복주머니는 게으른 길 밖. 결과는 `stages.md`.
- **브라우저 e2e**: 헤드리스 Chromium, 5가지 화면(390×844, 360×640, 844×390, 1280×720, 저장 차단) — 첫 탭 점프, 멀티터치, 일시정지·재개, 뒤로 가기, 1-1 완주, 결과 화면 입력 보호, 콘솔 오류 0.
- **성능**: 4배 CPU 제한에서 프레임 p95 가로 ≈6.5 ms / 세로 ≈4.7 ms(목표 ≤ 8 ms).
- **적대적 리뷰**: 6개 관점(규칙·공정성·모바일·성능·메타·아트)으로 찾고 독립 검증 → 확인된 50건 수정 후 재검증.

## 알려진 한계 · 다음에 할 일

- **실기기 검증 필요**: 모든 테스트는 헤드리스 Chromium입니다. iOS Safari·저가 안드로이드에서 입력 지연, 오디오 시작, 성능을 사람이 확인해야 합니다.
- **안 만든 기능**: 결과 화면의 타임라인 다시보기, 한 손 모드, 스테이지 연습(25/50/75% 지점 시작).
- **GDD와 다르게 조정한 값**: 달콩 식는 속도(GDD 1.08 → 균형 때문에 0.97), 일부 미션 목표(봇으로 달성 불가능했던 값은 낮춤 — `src/meta/missions.ts` 주석), 무한·오늘의 골목 엽전 밀도 절반(전부 사는 데 약 3시간).
- **PWA 업데이트**: 새 버전은 온라인 접속 시 바로 받지만, 설치된 앱의 오프라인 캐시는 브라우저가 서비스 워커를 다시 확인한 뒤(보통 다음 실행) 바뀝니다.
- **초보 봇 생존 시간**(중앙 ≈127초)은 기획 목표(60–100초)보다 깁니다. 봇은 길을 완벽히 읽고 타이밍만 흔들리므로 실제 초보보다 잘합니다. 실제 플레이 데이터로 다시 맞춰야 합니다.
