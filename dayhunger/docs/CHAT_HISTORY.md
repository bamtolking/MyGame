> 이 문서는 사용자와 AI(Claude)가 나눈 대화를 다른 AI(ChatGPT Codex 등)가 이어받을 수 있도록 정리한 것입니다.

## 0. 현재 상태 한눈에
- 저장소: https://github.com/bamtolking/MyGame
- 작업 브랜치: `claude/starcraft-eud-mobile-game-1ytq58` (데이헝거 전체가 여기 있음). 기본 브랜치 `claude/session-xitrmc`에는 데이헝거가 없음(아직 머지 안 함).

- 실행: `cd dayhunger && npm ci && npm start` → http://localhost:8080
- 검증: `cd dayhunger && npm run verify` (규칙 테스트 36개 + 브라우저 e2e)
- 안드로이드 APK: 푸시하면 GitHub Actions가 자동 빌드. 다운로드 https://github.com/bamtolking/MyGame/releases/download/dayhunger-latest/dayhunger.apk (현재 v0.2.7, 서명 키 고정)
- 다음 작업 안내: `dayhunger/AGENTS.md`(규칙·구조), `dayhunger/docs/HANDOFF.md`(현재 상태·다음 할 일)
- 사용자 성향: 개발자가 아님. 게임 기획 의견을 주고 결과물(앱)을 직접 설치해 확인함. 설명은 짧고 쉬운 한국어로, 실행할 것은 복붙 가능한 형태로 주는 것이 좋음.

## 1. 게임 만들기 요청
**사용자:** 스타크래프트의 Eud데이헝거라는 벽짓살종류의 유즈맵을 모바일게임으로 만들고싶은데 만들어줄래? 같이할수있는기능도 있으면좋겠어

**AI가 한 일:**
- 저장소에 이미 다른 게임(대박수비대, 타워디펜스)이 있어서 새 게임은 `dayhunger/` 폴더에 독립 프로젝트로 만듦.
- 구조: `shared/`(솔로·서버 공용 시뮬레이션), `server/`(WebSocket 방 서버), `client/`(모바일 터치 UI), `tests/`, `scripts/e2e.mjs`.
- 첫 버전 내용: 48×48 맵, 낮 90초 채집·건설 / 밤 60초 습격, 자원 나무·돌·식량, 건물 6종(나무 벽·돌 벽·문·포탑·모닥불·밭), 적 4종(좀비·러너·브루트·괴수), 배고픔, 10일째 아침 승리.
- 적 AI: 다익스트라 흐름장. 벽은 `1 + 체력/12` 비용으로 지나갈 수 있어 돌아갈지 부술지 스스로 판단(벽짓살의 핵심 재미).
- 협동: 방 코드 4자리, 최대 4명, 중간 참가, 동료가 살아 있으면 아침 부활, 빠른 채팅 6종.
- 검증: 규칙 테스트 13개, 헤드리스 Chromium으로 솔로 + 2인 협동 실기동 확인. 커밋 `f1c96a4`.

## 2. 앱으로 만들기
**사용자:** 어플로만들어줘

**AI가 한 일:**
- Capacitor로 안드로이드 프로젝트(`dayhunger/android/`) 생성, 뒤로가기 처리, 전체화면, 평문(ws://) 허용.
- `index.html`을 프로젝트 루트로 옮기고 상대 경로로 통일(서버와 앱 `www/`가 같은 구조).
- 메뉴에 "협동 서버 주소" 설정 추가(앱은 서버 주소가 필요), `client/js/config.js`에 기본 서버 주소 자리.
- PWA(manifest + 서비스 워커 + 아이콘)로 아이폰 홈 화면 설치 지원.
- GitHub Actions 워크플로 `.github/workflows/dayhunger-android.yml`: `dayhunger/**` 변경 시 APK 빌드 → 릴리스 `dayhunger-latest` 갱신. 첫 빌드는 Capacitor CLI가 Node 22를 요구해 실패 → Node 22로 고쳐 성공.
- 커밋 `ff0a246`, `305db46`.

## 3. 대규모 콘텐츠 확장
**사용자:** 맵을 많이 넓혀주고 자원의 다양성도 늘려줘 / 전장과 난이도도 다양하게 만들어주고 / 적도 다양하게 / 주인공 캐릭터도 다양하게 / 블록크기를 전반적으로 줄이자 / 캐는모션도 좀 더 현실적이게

**AI가 한 일:**
- 전장 5종: 초원 96, 설원 104(추위: 모닥불 밖 배고픔 1.5배), 사막 112(선인장·오아시스, 낮 120초), 늪지 96(낚시·버섯·진흙), 화산 88(용암, 철 풍부). 적은 맵 끝이 아니라 기지에서 24~44칸 고리에서 출현.
- 난이도 4단계: 쉬움(7일)·보통(10일)·어려움(12일)·악몽(15일). 적 수·체력·공격·보급 배율.
- 캐릭터 7종: 생존자·벌목꾼·광부·사냥꾼(활, 원거리)·요리사·기사·건축가. 직업별 모자·도구 그림.
- 자원: 철광석(철), 소나무·고목·선인장, 버섯, 약초(즉시 회복), 물가 낚시, 진흙(느림), 용암(막힘). 건물 추가: 철 벽·중포탑·가시 함정·횃불.
- 적 9종: 좀비·러너·스피터(원거리)·도둑(자원 훔쳐 도망, 잡으면 회수)·박쥐(벽 무시 비행)·파괴자(건물 4배)·브루트·폭탄병(자폭)·괴수(좀비 소환). 정예 6%.
- 타일 32px → 24px, 두 손가락 핀치 줌, 미니맵 확대, 화면 밖 기지 방향 화살표.
- 채집 모션: 도구를 뒤로 들었다 내려찍는 3단계 스윙, 몸 기울임, 걷기 발동작, 타일 흔들림·파편, 남은 횟수 진행 링.
- 설정 화면(전장/난이도/캐릭터), 대기실에서 방장이 전장·난이도, 각자 캐릭터 선택.
- 규칙 테스트 27개(전장 5종 완주 포함). 커밋 `2105cae`, `6482ebd`.

**AI가 한 일:**
- 원인: GitHub 빌드가 실행마다 새 임시 키로 서명 → 예전 버전이 설치돼 있으면 서명 불일치로 거부.

## 다음 AI가 알아야 할 결정 사항 (요약)

- 서명 키가 공개 저장소에 있으므로 스토어 배포 전엔 GitHub Secrets로 교체.
- 실제 기기 밸런스 피드백은 아직 없음. 사용자가 설치해 보고 의견을 줄 예정.
