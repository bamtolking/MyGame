# 데이헝거 인수인계 (2026-09-21 기준)

## 한 줄 요약
스타크래프트 유즈맵 "데이헝거/벽짓살"을 모바일용으로 다시 만든 것. 낮에 채집·건설, 밤에 습격. 혼자 또는 최대 4인 협동. 안드로이드 APK 자동 빌드까지 됨.

## 지금까지 된 것
- **핵심 루프**: 전장 5종(초원·설원·사막·늪지·화산, 88~112칸), 난이도 4단계, 캐릭터 7종(도구·모자 다름, 사냥꾼은 활), 자원 8종(나무·돌·철·식량 + 낚시·버섯·약초·선인장), 건물 10종, 적 9종(원거리·비행·도둑·파괴자·폭탄병·소환 보스·정예), 다익스트라 흐름장 경로(벽을 돌지/부술지 판단).
- **판 안의 성장**: 새벽 특전 16종(아침마다 3장 중 1장, 중첩), 괴수 전리품, 다음 밤 예고, 밤 10초 전 경고.
- **메타 진행**(`client/js/profile.js`): 경험치·레벨, 생존 포인트, 영구 강화 9종(두 번째 기회 포함), 캐릭터·전장·난이도 해금, 업적 25종, 통계·생존 일지, 오늘의 도전(날짜 시드).
- **UX**: 터치 조이스틱, 건설 패널(탭으로 배치), 빠른 채팅, 핀치 줌, 미니맵, 기지 방향 화살표, 효과음(절차 합성)·진동·화면 흔들림, 일시정지, 첫 판 도움말, 설정, 결과 화면(경험치 게이지 애니메이션).
- **협동**: 방 코드 4자리, 방장이 전장·난이도, 각자 캐릭터, 중간 참가, 죽으면 아침 부활, 특전 25초 자동 선택.
- **앱**: Capacitor 안드로이드 프로젝트, 고정 서명 키(v1+v2+v3), 버전 코드 = CI 실행 번호, 릴리스 `dayhunger-latest` 자동 갱신. PWA(manifest+서비스 워커)로 아이폰 홈 화면 설치 가능.
- **검증**: 규칙 테스트 36개(전장 5종 완주 포함), e2e(솔로 전 과정 + 2인 협동 동기화 + 프로필/강화/특전/일시정지/결과).

## 알아두면 좋은 결정
- 적 출현은 맵 가장자리가 아니라 기지에서 `spawnRing` 거리(전장별 24~44칸)의 고리. 맵을 넓혀도 밤 리듬이 유지됨.
- 특전·강화 효과는 전부 플레이어 개인 능력치에만 적용(건물 능력치는 타일별 소유자가 없어 제외). 건물 소유자를 추가하려면 `tileOwner` 배열과 직렬화가 필요.
- 무한 모드는 첫 승리 시점에 판을 기록하고, 이후 탈락 시 추가분(처치·건물·채집 증가량)만 다시 기록(`main.js`의 `S.snapshot`).
- 사냥꾼 화살·스피터 침·포탑 사격은 벽을 넘어감(의도).
- 서명 키가 공개 저장소에 있음. 스토어 배포 전엔 GitHub Secrets(`DH_KEYSTORE_B64` 등)로 교체(워크플로가 자동 인식).

## 알려진 빈틈 / 다음에 하면 좋은 것 (우선순위 순)
1. **협동 재접속**: 연결이 끊기면 캐릭터가 사라짐. 재접속 토큰(방 코드 + 비밀값)으로 같은 플레이어에 다시 붙기. 서버 `Room.members`에 토큰 보관, `leave` 시 60초 유예.
2. **밸런스 실측**: 실제 기기 플레이 데이터가 아직 없음. 특히 악몽 난이도, 폭탄병, 사막 식량. 수치는 `shared/constants.js`. 헤드리스 봇으로 밸런스 스윕(대박수비대의 `tests/bot.ts` 참고)을 만들면 좋음.
3. **그림**: 전부 도형으로 그림. 스프라이트 시트를 넣는다면 `renderer.js`의 `drawTile`/`drawPlayer`/`drawEnemy`만 교체하면 됨(좌표계: 타일 단위, `ts`=픽셀/타일).
4. **온라인 리더보드/오늘의 도전 순위**: 서버에 `/api/daily` 점수 제출·조회 추가(현재는 기기 로컬 최고 점수만).
5. **캐릭터 숙련도**: 캐릭터별 누적 XP로 소소한 고유 보너스 해금(프로필에 `classRuns`만 있음).
6. **건물 추가 아이디어**: 치료소(근처 회복), 창고(공용 자원), 함정 강화, 성문(넓은 문), 신호탄(동료 호출).
7. **이벤트**: 유성(철 낙하), 안개 밤(시야 감소), 보급 상자 낙하, 상인 방문 등 낮 이벤트.
8. **iOS 앱**: `npx cap add ios`는 macOS 필요. PWA로 대체 중.
9. **접근성**: 왼손잡이 조이스틱 위치 옵션, 글자 크기 옵션.
10. **서버 배포 문서**: Railway/Fly 예제 Dockerfile 추가(현재는 README 설명만).
