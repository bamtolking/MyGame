# 구현·검증 현황 (v0.1)

## 구현된 것

**핵심 루프**
- 슬라임 행진: 2.5초마다 1마리, 7등급 × 30종, 등급 가중치 + 서버 행운(날씨·대폭주·구매 행운), 변이 슬라임은 할인가. 클라이언트 60fps 렌더링(통통 뛰는 이동), 서버는 공식으로 구매 거리 검증.
- 희귀 등장(전설 이상 또는 ×5 이상 변이) 전체 공지.
- 기지 8개(서버당 8명), 발판 24칸(기본 10 + 업그레이드 10 + 게임패스 4), 수금 발판·잠금 발판, 기지 간판에 주인 이름.
- 1초마다 수입 → 기지 금고(자동 수금 패스는 바로 지갑), 금고 금액이 수금 발판 위에 표시.

**사회적 요소**
- 훔치기: 길게 누르기(등급·★에 따라 1~4.2초, 서버가 시작/완료 시간 검증) → 머리에 이고 달리기(무게만큼 느려짐, 최저 35%) → 내 기지 도착 시 소유권 이전.
- 취소 조건: 뿅망치에 맞음, 사망, 60초 초과, 도둑/주인 퇴장, 주인이 기지를 잠가 밀려남. 취소 시 원래 자리로.
- 뿅망치: 전방 9스터드, 넉백 + 1.2초 기절, 쿨타임(업그레이드), 등 뒤는 안 맞음, 최대 3명.
- 잠금: 60~120초, 만료 후 10초 충전. 잠긴 기지 안의 남은 자동으로 밖으로 밀려남(클라이언트에서는 방어막 충돌도 켬, 주인은 통과).
- 좌절 방지: 초보 보호막(첫 10분), 도난 직후 30초 보호막, 즐겨찾기 1마리 도난 불가, 빈 발판 없으면 훔치기 불가.
- 복수: 도둑맞는 순간 도둑이 빨간 윤곽선(벽 너머로 보임) + 15초간 이동 속도 +6. 모든 사람에게 도둑 머리 위 "THIEF!" 표시.
- 친구 보너스(친구 1명당 +10%, 최대 +40%), 그룹 보너스(선택).

**성장**
- ★ 합성(★1~★5, 수입 ×1/3.5/12/40/135, 크기 1~2.1배), 변이는 가장 좋은 것 유지.
- 변이 6종(×2~×10), 날씨 이벤트 6종이 행진·기지 슬라임을 변이시킴, 매시 정각(UTC) 대폭주.
- 업그레이드 6종(발판·속도·잠금·오프라인·행운의 손길·뿅망치), 환생(현금 + 등급 조건, +50%/회, 즐겨찾기·업그레이드·도감 유지).
- 도감 210칸(종류×변이), 1칸당 수입 +0.5%. 3D 미리보기(ViewportFrame), 미발견은 실루엣.
- 오프라인 수입(20~70%, 최대 2~7시간), 재접속 팝업.

**리텐션·보상**
- 7일 출석(7일째 영웅+ 슬라임, 끊기면 1일차), 일일 퀘스트 3개(9종 중 날짜·유저별 고정 추첨) + 전부 완료 보너스, 접속 선물 7개(2~60분).
- 튜토리얼 3단계(빛나는 빔 + 말풍선): 사기 → 수금 → 잠그기, 이후 팁 4개.

**수익화**
- 게임패스 5종(VIP·수입 2배·자동 수금·발판 +4·프로 도둑), 개발자 상품 5종(서버 행운·무지개 폭풍·현금 팩 3종).
- `ProcessReceipt` 영수증 기록으로 중복 지급 방지, VIP 채팅 태그.

**UI·연출**
- HUD(돈·초당 수입·금고·날씨·대폭주 카운트다운·행운·부스트), 왼쪽 메뉴 7개(알림 배지), 뿅망치·잠금 버튼(모바일 크기), 창 9개(상점·도감·환생·퀘스트·선물·스토어·설정·슬라임 관리·오프라인).
- 알림 토스트 + 큰 배너, 색종이, +$ 떠오르는 글자, 충격파, 반짝 터짐, 날씨별 조명·안개·입자·유성, 대폭주 화면 테두리, 무지개 색 순환, 슬라임 말랑 호흡, 흐르는 도로 화살표.
- 영어/한국어 자동 선택(플레이어 언어).
- 순위표 3종(누적 수입·환생·훔치기, 전체 서버) + 플레이어 목록 leaderstats.

**운영**
- 관리자 채팅 명령 7종, 저장 세션 잠금·자동 저장·종료 저장·데이터 복구·버전 이전 구조.

## 아직 확인 못 한 것 (중요)

- **실제 Roblox Studio/서버에서 돌려 보지 못했습니다.** 이 환경에는 Studio가 없어서, 대신 위의 가짜 엔진으로 코드 경로를 전부 실행했습니다.
  물리(넉백 세기, 들고 달리기 느낌), 실제 네트워크 지연, 조명·그림자, 모바일 터치 배치는 Studio에서 한 번 확인해 주세요.
- 효과음은 로블록스 기본 내장 소리(`rbxasset://sounds/...`)를 씁니다. 일부가 없으면 Output에 경고만 뜨고 게임은 정상입니다. 더 좋은 소리로 바꾸려면 `src/client/Controllers/Sound.luau`의 id를 바꾸세요.
- 캐릭터 애니메이션(뿅망치 휘두르기 등)은 에셋이 필요해서 넣지 않았고, 대신 충격파·글자·소리 연출을 씁니다.
- 게임패스·상품 ID는 비어 있습니다(출시 때 입력).
- 배경음악 없음(오디오 에셋 필요).
