# 슬라임 하이스트! (Slime Heist!) — 게임 기획서

> 한 줄 요약: **행진하는 슬라임을 사서 내 기지에서 돈을 벌고, 남의 기지에서 제일 비싼 슬라임을 훔쳐 오는 게임. 대신 들키면 뿅망치로 맞는다.**

## 1. 왜 이 게임인가 (시장 분석)

2025~2026년 로블록스 동시접속 1위를 찍은 게임들의 공통점을 뽑아서 한 게임에 모았습니다.

| 히트 게임 | 검증된 요소 | 슬라임 하이스트에서의 형태 |
|---|---|---|
| Steal a Brainrot | 컨베이어에서 캐릭터 구매 → 기지에서 수입 → **남의 기지에서 훔치기**, 기지 잠금 | 슬라임 행진 + 훔치기 + 잠금 발판 |
| Grow a Garden | **날씨 이벤트가 변이(×배수)를 붙임**, 오프라인에도 성장, 정해진 시각 이벤트 | 날씨 6종 → 변이 6종, 오프라인 수입, **매시 정각 슬라임 대폭주** |
| Pet Simulator 류 | 등급 뽑기, 도감, 리버스(환생) 배수 | 7등급, 도감 보너스, 환생 |
| Merge 장르 (모바일) | 같은 것 3개 → 상위 1개 | **★ 합성** (★1~★5, 크기·무게가 커짐) |

그 위에 이 게임만의 차별점 4가지를 얹었습니다.

1. **★ 합성 + 무게**: 3마리를 합치면 수입 ×3.5, 몸집이 커집니다. 커진 슬라임은 **무거워서 훔쳐 갈 때 느려집니다.** 비쌀수록 훔치기 어렵고, 그래서 성공하면 더 짜릿합니다.
2. **매시 정각 '슬라임 대폭주'** (UTC 기준, 모든 서버 동시): 3분간 행운 ×5, 수입 ×2, 무지개/유성우 날씨. 사람들이 같은 시각에 몰려 들어오게 만드는 약속 장치입니다.
3. **복수 시스템**: 도둑맞으면 도둑이 빨간 윤곽선으로 보이고 15초간 이동속도가 올라갑니다. 뺏긴 사람이 바로 "쫓아가는" 이야기가 생깁니다.
4. **친구 보너스**: 같은 서버 친구 1명당 수입 +10%(최대 +40%). 친구를 데려올 이유 = 자연 유입.

## 2. 핵심 루프

```
[30초 루프]  행진에서 슬라임 구매 → 기지 발판에 배치 → 초당 수입 → 수금 발판 밟기 → 더 비싼 슬라임
[5분 루프]   같은 슬라임 3개 합성(★) · 업그레이드 · 남의 기지 털기/지키기 · 날씨 이벤트 변이
[장기 루프]  환생(수입 배수 영구 증가) · 도감 완성 · 7일 출석 · 매시 대폭주 · 전체 서버 순위표
```

### 슬라임 행진 (공유 컨베이어)
- 서버 중앙 도로를 따라 2.5초마다 슬라임 1마리가 포털에서 나와 반대편 포털까지 걸어갑니다(약 47초).
- **서버의 모든 플레이어가 같은 행진을 봅니다.** 먼저 가서 사는 사람이 임자. 비싼 슬라임이 나오면 전체 공지가 뜨고 모두가 달려갑니다.
- 행진은 클라이언트에서 60fps로 그리고, 서버는 시각·위치 공식만 들고 구매 거리를 검증합니다(부드러움 + 보안 + 네트워크 절약).

### 기지
- 서버당 8명, 도로 양쪽에 기지 4개씩. 발판 최대 24개(기본 10 + 업그레이드 10 + 게임패스 4).
- 앞마당에 **수금 발판**(초록)과 **잠금 발판**(빨강). 수입은 기지 금고에 쌓이고 수금 발판을 밟아야 내 돈이 됩니다 → 주기적으로 기지에 돌아오게 만드는 장치.

### 훔치기 · 뿅망치 · 잠금
- 남의 기지 슬라임에 다가가 **길게 누르기**(등급·★에 따라 1~3초) → 슬라임을 머리 위에 들고 이동 속도 감소(최저 35%).
- 내 기지 안에 들어오면 소유권 이전. 도중에 **뿅망치(F키/모바일 버튼)** 에 맞거나, 죽거나, 60초가 지나거나, 주인이 나가면 슬라임은 원래 자리로 돌아갑니다(복제 버그 원천 차단: 배달 완료 순간에만 데이터가 옮겨짐).
- 잠금 발판: 60초(업그레이드로 최대 120초) 동안 방어막. 만료 후 10초 재사용 대기 → "틈"이 생김.
- 좌절 방지 장치: **초보 보호막**(첫 10분), **도난 직후 30초 보호막**, **즐겨찾기 슬라임 1마리는 절대 도난 불가**, 빈 발판이 없으면 훔칠 수 없음.

### ★ 합성
| ★ | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 수입 배수 | ×1 | ×3.5 | ×12 | ×40 | ×135 |
| 크기 | 1.0 | 1.2 | 1.45 | 1.75 | 2.1 |

같은 종류·같은 ★ 3마리 → ★+1 1마리. 변이는 셋 중 가장 좋은 것을 물려받습니다. 3마리 합이 ×3보다 크므로 합성은 항상 이득이고 발판도 2칸 비워집니다.

## 3. 등급 · 슬라임 · 변이

- 등급 7단계: 일반 · 고급 · 희귀 · 영웅 · 전설 · 신화 · **비밀**. 등장 가중치 55 / 28 / 12 / 4 / 0.85 / 0.13 / 0.02.
- 슬라임 30종(등급별 6·5·5·4·4·3·3). 등급이 오를수록 가격 대비 회수 시간이 길어져서(20초 → 320초) 뒤로 갈수록 "모으는 맛"이 납니다.
- 전부 파트(도형)로 절차적 생성 → 외부 모델·에셋 없이 동작. 등급마다 모자·왕관·뿔·날개·후광 등 장식.

| 변이 | 배수 | 주로 생기는 날씨 |
|---|---|---|
| 황금 | ×2 | 황금 시간 |
| 다이아 | ×3 | 수정 폭풍 |
| 사탕 | ×4 | 슈가 러시 |
| 용암 | ×5 | 화산 폭발 |
| 무지개 | ×7 | 무지개 폭풍 |
| 은하 | ×10 | 유성우 |

- 평소 4분 맑음 → 2분 날씨 이벤트. 이벤트 중에는 행진 슬라임의 30%에 변이가 붙고, **이미 기지에 있는 슬라임도 10초마다 2% 확률로 변이**를 얻습니다(더 좋은 변이일 때만 교체). "지금 접속해 있어야 하는 이유".

## 4. 성장 · 경제

- 수입 = Σ(기본 수입 × ★배수 × 변이배수) × 환생배수 × 도감보너스 × 친구보너스 × 게임패스 × 부스트 × 대폭주
- **환생**: 조건 = 현금($4M부터 회차마다 ×7) + 특정 등급 이상 슬라임 보유(1~2회차 영웅, 3~4회차 전설, 5~8회차 신화, 9회차~ 비밀). 보상 = 수입 +50%(누적), 즐겨찾기 1마리 유지, 업그레이드·도감 유지. 현금·슬라임 초기화.
- **도감**: 종류×변이 조합(30×7=210칸)을 발견할 때마다 수입 +0.5%. 수집 욕구를 영구 배수로 연결.
- **업그레이드**(현금, 환생해도 유지): 발판 +1(10단계), 이동 속도(8), 잠금 시간(4), 오프라인 수입(5), 행운의 손길=구매 시 변이 확률(10), 뿅망치 쿨타임(5).
- **오프라인 수입**: 나가 있던 시간 × 수입 × 20%(업그레이드로 최대 70%), 최대 2시간(최대 7시간). 재접속 시 "돌아온 걸 환영해요!" 팝업.

수치 전체는 `src/shared/Config/`에 있고, 밸런스 시뮬레이션 결과는 `docs/BALANCE.md`에 있습니다.
목표 곡선(시뮬레이션 중앙값): 첫 영웅 7분 · 첫 전설 20분 · 첫 환생 17분 · 3회 환생 1시간 · 5회 환생 3.3시간 · 첫 신화 2시간 · 첫 비밀 5시간 전후.

## 6. 수익 모델 (게임패스 · 개발자 상품)

ID는 `src/shared/Config/Products.luau`에 넣습니다. ID가 0인 상품은 상점에 표시되지 않습니다.

- 게임패스: VIP(수입 ×1.5 + 채팅 태그), 수입 2배, 자동 수금, 발판 +4, 프로 도둑(들고 달리기 속도 +25%)
- 개발자 상품: **서버 행운 ×2 (15분, 구매자 이름이 전체 공지)**, 현금 팩 3종(현재 수입 기준 10/60/300분치), **무지개 폭풍 소환**(서버 전체 이벤트)
- 서버 전체에 혜택이 가는 상품은 "산 사람이 영웅이 되는" 구조라 구매 동기가 강합니다.
- 모든 결제는 `ProcessReceipt`에서 영수증 ID를 저장해 중복 지급을 막습니다.

## 7. 확장성 (라이브 운영)

- **슬라임 추가 = 표에 한 줄**: `Config/Slimes.luau`에 id·이름·등급·색·장식·수입을 넣으면 행진·도감·저장·UI에 자동 반영.
- **변이·날씨 추가 = 표에 한 줄**: `Config/Mutations.luau`, `Config/Weather.luau`.
- **장식 추가**: `Shared/SlimeBuilder.luau`의 장식 함수 표에 함수 하나.
- **퀘스트 추가**: `Config/Quests.luau`.
- 데이터는 버전 필드 + 마이그레이션 함수가 있어 구조를 바꿔도 기존 저장이 안전합니다.
- 관리자 명령(`/cash`, `/event`, `/frenzy`, `/spawn`, `/luck`, `/rebirth`, `/wipe`)으로 라이브 이벤트 진행.

## 8. 기술 구조

- Rojo 프로젝트, Luau `--!strict`. 서버 권위(클라이언트는 "하고 싶다"만 보냄, 서버가 거리·돈·쿨타임 검증).
- 순수 로직(`Shared/Logic`)은 로블록스 API 없이 작성해서 Lune으로 단위 테스트.
- 저장: DataStore `UpdateAsync` + 세션 잠금(중복 접속 시 데이터 덮어쓰기 방지), 60초 자동 저장, 종료 시 저장, 재시도, 버전 마이그레이션. Studio에서 API 접근이 꺼져 있으면 메모리 저장으로 자동 전환.
- 맵·기지·슬라임·UI 전부 코드로 생성 → 파일 하나(.rbxlx)로 배포 가능.
