# 저승 휴게소 (Ghost Diner) — 로블록스 협동 요리 디펜스 (v0.3 베타)

> 한 문장: **저승 가는 길목의 분식집. 밤마다 몰려오는 귀신 손님에게 원하는 음식을 제때 내주지 못하면 악귀가 되어 주방을 부순다. 친구들과 역할을 나눠 몇 번째 밤까지 버틸 수 있을까?**

Overcooked 식 "주방 대혼란"에 웨이브 디펜스의 긴장감을 합친 2~6인 협동 게임입니다.
지도·조리대·손님·UI 전부를 스크립트가 파츠로 만들기 때문에 **에셋 업로드 없이 파일 하나로 바로 실행**됩니다.

## 왜 이 아이디어인가

- **협동이 저절로 생김**: 재료 꺼내기 → 썰기·합치기 → 익히기 → 서빙까지 동선이 길고, 익힌 음식은 10초 안에 안 꺼내면 탑니다. 혼자 다 하려 들면 무조건 무너져서 "너는 재료, 나는 냄비, 쟤는 서빙"이 자연스럽게 나옵니다.
- **짧은 루프, 확실한 긴장**: 손님 머리 위 인내심 바가 빨개지고, 악귀가 된 손님이 주방으로 넘어와 조리대를 부수면 진짜로 아우성이 납니다. 한 밤은 1~3분.
- **"한 밤만 더"**: 밤이 갈수록 새 메뉴(어묵탕 → 김밥)·새 손님(도깨비 → 호랑이)·5밤마다 보스 산신령이 열리고, 낮에는 번 돈으로 팀 업그레이드를 삽니다. 최고 기록은 저장됩니다.
- **채팅이 없어도 됨**: 필요한 정보는 전부 조리대 위 라벨·손님 머리 위 주문·E 프롬프트 문구로 보여서, 어린 플레이어나 모바일에서도 바로 협동이 됩니다.

## 바로 실행하기 (비개발자용)

1. [Roblox Studio](https://create.roblox.com/)를 설치합니다.
2. `roblox/build/GhostDiner.rbxlx` 파일을 내려받아 Studio에서 엽니다 (파일 > 파일에서 열기, 또는 더블클릭).
3. 홈 탭의 **▶ 플레이**로 혼자 테스트합니다. 여럿이 테스트하려면 **테스트 탭 > 클라이언트 및 서버 > 플레이어 2~4명 > 시작**.
4. 게시: **파일 > Roblox에 게시**. 게임 설정에서 서버 최대 인원은 6을 권장합니다.
5. 기록 저장(최고 밤 등)을 Studio에서도 보려면 게임 설정 > 보안 > **"Studio의 API 서비스 접근 허용"**을 켭니다. 꺼져 있어도 게임은 정상 작동합니다.

## Studio 자가 진단 (플레이만 누르면 됩니다)

Studio 에서 ▶ 플레이를 누르면 게임 안에 들어 있는 검사기가 90초 동안 실제 엔진에서 벌어지는 일을 지켜보고, **보기 > 출력** 창에 `[자가진단]` 줄과 마지막 요약(✅/❌)을 남깁니다. 서빙을 한 번 해 보면 "서빙 성공 → 성불" 까지 확인됩니다. 이상이 있으면 `자가진단 요약` 두 블록(서버·클라이언트)을 복사해서 보내 주세요. 게시된 게임에서는 검사기가 동작하지 않습니다.

플레이어 없이 **테스트 > 실행(Run)** 을 눌러도 5초 뒤 무인 시연이 시작되어 손님이 오고, 서빙이 없으니 악귀가 되어 조리대를 부수는 것까지 볼 수 있습니다.

## 조작

| 조작 | 설명 |
|---|---|
| WASD / 조이스틱 | 이동 (기본 로블록스 조작) |
| **E** (모바일: 화면 버튼) | 조리대·손님과 상호작용. 프롬프트에 지금 할 수 있는 행동이 표시됨 ("꺼내기: 떡", "넣기: 어묵", "서빙: 라면") |
| **E 길게** | 도마에서 야채 썰기 |
| **R** / 📖 버튼 | 레시피 책 |
| **B** / 🛒 버튼 | 상점 (팀 코인으로 구매) |

규칙: 한 손에 **한 가지**만 들 수 있습니다. 탄 음식·잘못 만든 것은 쓰레기통에 버립니다.

## 게임 흐름

```
개장 준비 15초 → 🌙 밤 (손님 웨이브 · 이벤트 · 밤 목표) → ☀️ 낮 25초 (상점 · 준비 투표) → 🌙 다음 밤 → … → 평판 0 = 💀 폐업 → 결과 → 자동 재시작
```

### 시스템 한눈에

| 시스템 | 내용 |
|---|---|
| 🔥 **콤보** | 12초 안에 연속 서빙하면 콤보. 2번째부터 보상 +10%씩(최대 2배). 악귀가 생기거나 음식을 태우면 끊김 |
| 🧯 **화재** | 탄 음식을 8초 방치하면 불이 나고 7초마다 옆 조리대로 번짐(번질 때마다 평판 -3). 벽의 소화기함에서 소화기를 꺼내 E를 길게 눌러 진화 |
| ⚡ **밤 이벤트** | 3번째 밤부터 45% 확률: 폭주의 밤(손님 ↑ 보상 +30%) · 황금의 밤(팁 2배) · 정전의 밤(12초 암흑) · 느긋한 밤(인내심 +30%) · 까다로운 밤(주문 +1) |
| 🎯 **밤 목표** | 2번째 밤부터 매 밤 하나: 무사고 영업 · 팁 부자 · 연속 서빙 · 완벽한 밤 · 번개 서빙 · 화재 예방. 달성 시 보너스 코인 |
| 🦊 **구미호의 변덕** | 인내심이 절반이 되면 주문 하나를 바꿈(❗ 표시, 대신 8초 더 기다려 줌) |
| ✅ **준비 투표** | 낮·개장 준비 중 모두가 ✅ 준비 완료를 누르면 바로 다음 밤 |
| 🏆 **MVP** | 밤이 끝날 때 서빙을 가장 많이 한 요리사를 발표 |
| ✨ **명성·옷장** | 서빙 +1, 밤 클리어 +5+밤 만큼 명성이 영구 저장. 옷장(C)에서 명성으로 해금한 모자 9종 착용 |
| 🥇 **전체 순위표** | 주방 오른쪽 벽에 모든 서버를 통틀어 최고 밤 순위 (OrderedDataStore) |
| 👋 **튜토리얼** | 처음 온 요리사에게 첫 밤 동안 어묵탕 서빙 4단계 체크리스트 |
| 🧧 **부적 (팀 필살기)** | 서빙할수록 차는 팀 게이지(서빙 +10, 팁 +5, 보스 +30). 가득 차면 누구나 1·2·3 키로 사용: 시간 부적(기다리는 손님 전원 인내심 +12초) · 평온 부적(난동 중인 악귀 전부 진정) · 풍요 부적(20초 보상 ×1.5) |
| 🔮 **도깨비 상인의 유물** | 보스 밤(5·10·15…)을 넘기면 유물 3개 제시, 20초 팀 투표(전원 투표 시 즉시). 황금 국자(팁 +50%) · 도깨비 방망이(난동 피해 -50%) · 튼튼한 조리대 · 불꽃 수호 부적(불 안 번짐) · 다정한 미소 · 바람 신발 · 복주머니 · 얼음 국자 · 부적 먹물 |
| ✨ **성불** | 배불리 먹은 손님은 걸어 나가지 않고 빛과 함께 승천합니다. 결과 화면에 "성불한 영혼" 집계 |
| 🥢 **떡메치기 (2인 조리대)** | 밥을 떡메에 올리고 두 요리사가 번갈아 6번 쳐야 인절미(6번째 밤 해금, 20코인). 혼자면 1.2초 간격으로만 가능 |
| 💬 **손님 대사·리뷰** | 손님마다 카운터에 서면 한마디, 폐업하면 그 판 기록으로 손님들이 별점 리뷰 3줄 |

- **손님**은 저승 문에서 나와 카운터 앞 자리(6칸)에 서고, 그때부터 인내심이 줄어듭니다. 자리가 없으면 대기줄(8칸)에서 기다립니다.
- 원하는 요리를 들고 손님에게 **E** → 코인 + 인내심이 많이 남았을수록 **팁**. 잘못된 요리를 내밀면 인내심 -10초.
- 인내심이 바닥나면 **악귀**가 되어 평판을 깎고, 주방으로 넘어와 조리대를 하나(호랑이·산신령은 둘) 부숩니다. 부서진 조리대는 10초 뒤 복구됩니다.
- 밤의 손님을 전부 처리하면 보너스 코인과 함께 낮이 됩니다.

### 상점 (한 판 동안 유지, 팀 공용 코인)

날카로운 칼(칼질 -25%/단계) · 센 불(조리 -15%/단계) · 친절한 미소(인내심 +12%/단계) · 빠른 신발(이동 +2/단계) · 냄비/화덕/튀김기/밥솥 추가 · 평판 수리(+25, 살수록 비싸짐)

### 모자 (명성으로 해금, 영구)

종이 모자(0) · 요리사 모자(50) · 빨간 두건(120) · 갓(250) · 도깨비 뿔(400) · 호랑이 귀(600) · 신령의 후광(900) · 저승 왕관(1500)

### 연출

서빙하면 요리가 손님에게 날아가 반짝이고, 손님은 둥실 떠다니다 기쁘면 점프·화나면 부들부들 떨며 붉은 기운을 내뿜습니다. 조리대는 끓는 거품·달아오른 화덕·김으로 상태를 보여 주고, 산신령이 오면 번개가 치며, 밤을 넘기면 폭죽이 터집니다. 평판이 낮으면 화면 가장자리가 붉게 맥동하고 정전이 오면 화면이 깜빡이며 어두워집니다. 야시장 장식(네온 간판·등불 줄·달·안개·반딧불·유령나무·룬 길)은 전부 파츠와 파티클입니다.

배경음악은 `src/shared/Config.luau` 의 `MusicId` 에 Creator Store 오디오 ID(`rbxassetid://…`)를 넣으면 재생됩니다(기본은 없음).

밤별 손님 수·등장 간격 등 자세한 수치는 [`docs/DESIGN.md`](docs/DESIGN.md)를 보세요.

```
  tests/sim/    Lune 위에서 실제 게임 코드를 돌리는 헤드리스 통합 시뮬레이션 (rbx.luau 흉내 환경, run.luau 시나리오)
  tests/studio/ run-in-roblox 로 Studio 를 띄워 무인 시연을 돌리는 스크립트
  build.sh      테스트 + 타입 검사 + 빌드
```

설계 원칙: 게임 상태는 서버가 `ReplicatedStorage.GhostDinerState`의 Attribute로 복제하고(늦게 들어온 사람도 즉시 동기화), 조리대·손님의 진행 바는 파츠 Attribute(`DoneAt`, `DeadlineAt` 등)를 클라이언트가 서버 시간으로 계산해 그립니다. 클라이언트가 서버에 보내는 것은 프롬프트 입력(로블록스 내장)과 상점 구매 요청뿐이라 치트가 어렵습니다.

## 개발자용

```bash
# 도구 설치 (처음 한 번, 인터넷 필요): rojo, luau, luau-lsp, lune 을 roblox/.tools/ 에 받음
bash scripts/setup-tools.sh

# 전체 검증 (로직 테스트 + 타입 검사 + 속성 검사 + 빌드 + 시뮬레이션)
./build.sh

# 순수 로직 테스트만 (.tools/luau 를 자동으로 찾음)
tests/run.sh

# PC 에 Studio 가 있으면: 터미널에서 Studio 를 띄워 무인 시연을 돌리고 자가진단 출력을 받아옴 (Windows/macOS)
#   run-in-roblox: https://github.com/rojo-rbx/run-in-roblox
run-in-roblox --place build/GhostDiner.rbxlx --script tests/studio/run_in_studio.luau

# 헤드리스 통합 시뮬레이션 (Lune 필요: https://github.com/lune-org/lune/releases)
#   실제 서버·클라이언트 스크립트를 Lune 의 Roblox API 위에서 실행하고, 가짜 요리사 2명이 5밤을 진행하며
#   서빙·성불·난동·화재·소화·부적·떡메·구미호·정전·보스·유물 투표·상점·옷장·폐업·재시작을 검증합니다 (약 2~3분).
.tools/lune run tests/sim/run.luau .

# Studio 와 실시간 동기화 (Rojo 플러그인 설치 후)
rojo serve default.project.json
```

시뮬레이션은 물리·렌더링·네트워크 복제가 없는 흉내 환경(`tests/sim/rbx.luau`)에서 돕니다. 손님 이동은 직선 이동으로, 트윈은 즉시 적용으로 대체되므로 "보기에 어떤가"는 여전히 Studio 에서 확인해야 합니다.
