# 저승 휴게소 (Ghost Diner) — 로블록스 협동 요리 디펜스 (첫 베타)

> 한 문장: **저승 가는 길목의 분식집. 밤마다 몰려오는 귀신 손님에게 원하는 음식을 제때 내주지 못하면 악귀가 되어 주방을 부순다. 친구들과 역할을 나눠 몇 번째 밤까지 버틸 수 있을까?**

Overcooked 식 "주방 대혼란"에 웨이브 디펜스의 긴장감을 합친 2~6인 협동 게임입니다.
지도·조리대·손님·UI 전부를 스크립트가 파츠로 만들기 때문에 **에셋 업로드 없이 파일 하나로 바로 실행**됩니다.

## 왜 이 아이디어인가

- **협동이 저절로 생김**: 재료 꺼내기 → 썰기·합치기 → 익히기 → 서빙까지 동선이 길고, 익힌 음식은 10초 안에 안 꺼내면 탑니다. 혼자 다 하려 들면 무조건 무너져서 "너는 재료, 나는 냄비, 쟤는 서빙"이 자연스럽게 나옵니다.
- **짧은 루프, 확실한 긴장**: 손님 머리 위 인내심 바가 빨개지고, 악귀가 된 손님이 주방으로 넘어와 조리대를 부수면 진짜로 아우성이 납니다. 한 밤은 1~3분.
- **"한 밤만 더"**: 밤이 갈수록 새 메뉴(어묵탕 → 김밥)·새 손님(도깨비 → 호랑이)·5밤마다 보스 산신령이 열리고, 낮에는 번 돈으로 팀 업그레이드를 삽니다. 최고 기록은 저장됩니다.
- **채팅이 없어도 됨**: 필요한 정보는 전부 조리대 위 라벨·손님 머리 위 주문·E 프롬프트 문구로 보여서, 어린 플레이어나 모바일에서도 바로 협동이 됩니다.

## 바로 실행하기 (비개발자용)

1. [Roblox Studio](https://create.roblox.com/)를 설치합니다.
2. `roblox/build/GhostDiner.rbxlx` 파일을 내려받아 Studio에서 엽니다 (파일 > 파일에서 열기, 또는 더블클릭).
3. 홈 탭의 **▶ 플레이**로 혼자 테스트합니다. 여럿이 테스트하려면 **테스트 탭 > 클라이언트 및 서버 > 플레이어 2~4명 > 시작**.
4. 게시: **파일 > Roblox에 게시**. 게임 설정에서 서버 최대 인원은 6을 권장합니다.
5. 기록 저장(최고 밤 등)을 Studio에서도 보려면 게임 설정 > 보안 > **"Studio의 API 서비스 접근 허용"**을 켭니다. 꺼져 있어도 게임은 정상 작동합니다.

## 조작

| 조작 | 설명 |
|---|---|
| WASD / 조이스틱 | 이동 (기본 로블록스 조작) |
| **E** (모바일: 화면 버튼) | 조리대·손님과 상호작용. 프롬프트에 지금 할 수 있는 행동이 표시됨 ("꺼내기: 떡", "넣기: 어묵", "서빙: 라면") |
| **E 길게** | 도마에서 야채 썰기 |
| **R** / 📖 버튼 | 레시피 책 |
| **B** / 🛒 버튼 | 상점 (팀 코인으로 구매) |

규칙: 한 손에 **한 가지**만 들 수 있습니다. 탄 음식·잘못 만든 것은 쓰레기통에 버립니다.

## 게임 흐름

```
개장 준비 15초 → 🌙 밤 (손님 웨이브) → ☀️ 낮 25초 (상점·재료 준비) → 🌙 다음 밤 → … → 평판 0 = 💀 폐업 → 결과 → 자동 재시작
```

- **손님**은 저승 문에서 나와 카운터 앞 자리(6칸)에 서고, 그때부터 인내심이 줄어듭니다. 자리가 없으면 대기줄(8칸)에서 기다립니다.
- 원하는 요리를 들고 손님에게 **E** → 코인 + 인내심이 많이 남았을수록 **팁**. 잘못된 요리를 내밀면 인내심 -10초.
- 인내심이 바닥나면 **악귀**가 되어 평판을 깎고, 주방으로 넘어와 조리대를 하나(호랑이·산신령은 둘) 부숩니다. 부서진 조리대는 10초 뒤 복구됩니다.
- 밤의 손님을 전부 처리하면 보너스 코인과 함께 낮이 됩니다.

### 메뉴 (해금 밤 순)

| 요리 | 가격 | 해금 | 만드는 법 |
|---|---|---|---|
| 🍢 어묵탕 | 8 | 1밤 | 어묵 → 냄비 5초 |
| 🍜 라면 | 10 | 1밤 | 건면 → 냄비 6초 |
| 🥞 호떡 | 10 | 2밤 | 반죽 → 화덕 6초 |
| 🍲 떡볶이 | 14 | 3밤 | 떡 + 고추장 → 조리대 → 냄비 7초 |
| 🐟 붕어빵 | 14 | 5밤 | 반죽 + 팥 → 조리대 → 화덕 7초 |
| 🍤 모둠 튀김 | 16 | 7밤 | 야채 → 도마 / 썬 야채 + 반죽 → 조리대 → 튀김기 6초 |
| 🍙 김밥 | 18 | 9밤 | 쌀 → 밥솥 8초(타지 않음) / 야채 → 도마 / 밥 + 김 + 썬 야채 → 조리대 |

### 손님

| 손님 | 인내심 | 주문 | 난동 피해 | 보상 배율 | 등장 |
|---|---|---|---|---|---|
| 꼬마 도깨비 | 50초 | 1 | 8 | ×1.0 | 1밤~ |
| 처녀귀신 | 60초 | 1 | 10 | ×1.1 | 2밤~ |
| 저승사자 | 40초 | 1 | 18 | ×1.4 | 4밤~ |
| 구미호 | 80초 | 2 | 14 | ×1.3 | 6밤~ |
| 배고픈 호랑이 | 60초 | 2 | 20 (조리대 2개) | ×1.5 | 8밤~ |
| 👑 산신령 (보스) | 100초 | 3 | 30 (조리대 2개) | ×2.5 | 5·10·15…밤 |

### 상점 (한 판 동안 유지, 팀 공용 코인)

날카로운 칼(칼질 -25%/단계) · 센 불(조리 -15%/단계) · 친절한 미소(인내심 +12%/단계) · 빠른 신발(이동 +2/단계) · 냄비/화덕/튀김기/밥솥 추가 · 평판 수리(+25, 살수록 비싸짐)

밤별 손님 수·등장 간격 등 자세한 수치는 [`docs/DESIGN.md`](docs/DESIGN.md)를 보세요.

## 구조

```
roblox/
  build/GhostDiner.rbxlx     Studio 로 바로 여는 완성 파일 (Rojo 빌드 결과)
  default.project.json       Rojo 프로젝트 (폴더 → Roblox 서비스 매핑)
  src/shared/   ReplicatedStorage.GhostDiner  — 수치·데이터 (밸런스는 여기만 수정)
    Config        라운드·손님·조리·플레이어 기본 수치
    Recipes       재료·중간재료·요리, 썰기/합치기/익히기 규칙, 레시피 설명 생성
    CustomerTypes 손님 종류·외형·등장 가중치
    Waves         밤별 손님 수·간격·주문·인내심
    Upgrades      상점 항목과 가격·효과
  src/server/   ServerScriptService.GhostDinerServer
    Main          진입점 (지도 → 조리대 → 손님 → 저장 → 상점 → 게임 루프)
    MapBuilder    파츠로 휴게소 지도 조립, 조명(밤/낮), 충돌 그룹
    Stations      조리대 상태 기계 (상자/도마/조리대/냄비류/쓰레기통), 난동 파손·복구
    Customers     손님 NPC 조립·이동·인내심·서빙·난동
    Items         재료/요리 모양, 손에 드는 Tool
    GameLoop      대기 → 준비 → 밤 → 낮 → 폐업 흐름, 상태 복제
    Shop / Data / Remotes / GameState
  src/client/   StarterPlayerScripts.GhostDinerClient
    Main          HUD·패널·라벨·효과음 연결, 서버 알림 처리
    Hud / Panels(레시피·상점) / Labels(조리대·손님 라벨, 프롬프트 문구) / Sfx
  tests/        Roblox 없이 Luau CLI 로 도는 순수 로직 테스트 (레시피 도달 가능성, 웨이브, 업그레이드)
  build.sh      테스트 + 타입 검사 + 빌드
```

설계 원칙: 게임 상태는 서버가 `ReplicatedStorage.GhostDinerState`의 Attribute로 복제하고(늦게 들어온 사람도 즉시 동기화), 조리대·손님의 진행 바는 파츠 Attribute(`DoneAt`, `DeadlineAt` 등)를 클라이언트가 서버 시간으로 계산해 그립니다. 클라이언트가 서버에 보내는 것은 프롬프트 입력(로블록스 내장)과 상점 구매 요청뿐이라 치트가 어렵습니다.

## 개발자용

```bash
# 순수 로직 테스트 (luau CLI 필요: https://github.com/luau-lang/luau/releases)
LUAU_BIN=/path/to/luau tests/run.sh

# 테스트 + Roblox API 타입 검사 + .rbxlx 빌드
#   rojo, luau, luau-lsp 바이너리와 luau-lsp 저장소의 scripts/globalTypes.d.luau 를 한 폴더에 두고:
TOOLS_DIR=/path/to/tools ./build.sh

# Studio 와 실시간 동기화 (Rojo 플러그인 설치 후)
rojo serve default.project.json
```

## 알려진 제한 / 다음 작업

- 이 첫 베타는 **자동 검사(Roblox API 타입 검사, 순수 로직 테스트, Rojo 빌드)까지만** 거쳤습니다. Roblox Studio 실기동은 이 저장소 환경에서 할 수 없어 **사용자가 처음으로 실행**하게 됩니다. 문제가 보이면 Studio 의 **보기 > 출력** 창에 뜨는 빨간 줄을 그대로 알려 주세요.
- 애니메이션 없음(귀신·요괴는 떠다니므로 자연스럽게 보이도록 설계), 그래픽은 파츠 조립, 효과음은 로블록스 내장(rbxasset) 사운드.
- 저장: 최고 밤·누적 서빙·누적 코인·판 수 (플레이어별). 서버 전체 순위표는 아직 없습니다.
- 아이디어 후보: 화재 번짐 + 소화기, 단골 시스템(만족한 손님이 다음 밤에 팁 보너스), 요리사 스킨, 계절 메뉴, 글로벌 순위표, 두 번째 지도(야시장).
