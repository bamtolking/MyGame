# 냥체역학 (Cats Are Liquid)

말랑한 고양이를 떨어뜨려 같은 고양이끼리 합체시키는 물리 퍼즐입니다. 두 마리가 닿으면 한 단계 큰 고양이가 되고, 목표는 11단계 **우주뚱냥**입니다. 고양이가 상자 테두리 밖으로 2초 넘게 삐져나오면 끝납니다.

> 한 줄 소개: **"고양이는 액체다" 밈을 진짜 게임 규칙으로 만든 수박게임류 합체 퍼즐.**

- 서버, 회원가입, 결제, 광고 없음. 브라우저(휴대폰 포함)에서 바로 실행되는 HTML5 게임이고, Capacitor로 감싸 안드로이드·iOS 앱으로 낼 수 있게 구조를 나눠 두었습니다.
- 한국어/영어 지원 (기기 언어를 따라가고, 설정에서 바꿀 수 있음).
- 그림과 소리는 전부 코드로 그리고 합성합니다. 외부 이미지·음원 파일이 없습니다 (글꼴만 주아체를 내장).

## 바로 해 보기

1. **가장 쉬운 방법**: `play/index.html` 파일 하나가 게임 전체입니다. 휴대폰이나 PC 브라우저로 열면 바로 실행됩니다.
2. **개발 서버** (같은 Wi-Fi의 휴대폰에서 테스트): Node.js 22 설치 후
   ```bash
   cd nyang
   npm install
   npm run dev      # 터미널에 표시되는 http://<PC의 IP>:5173 주소를 휴대폰 브라우저로 열기
   ```
3. **빌드**: `npm run build` → `dist/`(정적 사이트, PWA) + `play/index.html`(단일 파일) + `play/artifact.html`(claude.ai 아티팩트용).

## 게임 요소

- **고양이 11단계**: 아깽이 → 치즈냥 → 고등어 → 턱시도 → 삼색이 → 샴 → 러시안블루 → 뱅갈 → 페르시안 → 메인쿤 → 우주뚱냥. 우주뚱냥 둘이 만나면 승천하며 보너스 1,000점.
- **연쇄 콤보**: 합체로 태어난 고양이가 1초 안에 또 합체하면 콤보. 점수 배율 최대 4배.
- **캣닢 공**: 가끔 나오는 특수 공. 처음 닿은 고양이를 한 단계 키워 줍니다 (뱅갈까지).
- **츄르 게이지와 능력 3종**: 점수를 얻으면 게이지가 차고, 가득 차면 능력이 충전됩니다.
  - 냥펀치: 고른 고양이 한 마리를 상자 밖으로 내보냄
  - 액체화: 3.5초 동안 모두 녹아 작아지고, 같은 고양이끼리 끌어당김
  - 흔들기: 상자를 흔들어 자리를 다시 잡음
- **집사 찬스**: 넘쳤을 때 한 판에 한 번, 위쪽 고양이를 치우고 이어서 하기.
- **오늘의 상자**: 날짜마다 모든 사람이 같은 순서의 고양이를 받고, 규칙 8종 중 하나가 걸립니다 (달나라 상자, 버터 바른 상자, 좁은 상자 등). 하루 한 판 기록, 공유 문구 제공.
- **도감, 최고 기록, 결과 카드**: 결과 화면에서 상자 모습이 담긴 이미지 카드와 공유 문구를 만듭니다.
- **이어하기**: 앱을 닫아도 그 판을 그대로 이어서 합니다.

## 구조

```
src/data/       수치 데이터 (고양이 11종, 규칙, 오늘의 상자 규칙 8종) — 밸런스는 여기만 고친다
src/sim/        시뮬레이션 (DOM 없음, 결정적): physics(원형 물리), game(규칙), daily, bot, rng
src/render/     캔버스: catdraw(말랑한 고양이), squish(맞닿은 면 계산), renderer(방·상자·크레인), fx(연출)
src/ui/         화면 흐름·HUD·입력·메인 루프, CSS, 아이콘, 내장 글꼴
src/platform/   저장(localStorage), 사운드(WebAudio 합성), 공유/진동 — 네이티브로 바꿀 때 여기만 교체
src/i18n.ts     한국어/영어 문자열
tests/          Vitest: 물리, 규칙, 다국어, 밸런스 스윕(봇)
scripts/        단일 파일 빌드, 모바일 e2e, 스토어 이미지 생성, 글꼴 서브셋
dev/            개발용 페이지 (고양이 갤러리, 스토어 이미지 그리기)
store/          스토어 등록용 아이콘·그래픽·스크린샷 (한국어/영어)
docs/           기획서, 출시 가이드, 스토어 문구, 개인정보처리방침, 테스트 결과
```

- 물리: 한 프레임(1/60초)을 8번 나눠 겹침을 밀어내는 위치 기반 방식. 접촉점 마찰로 고양이가 굴러가고, 합체한 고양이는 서서히 커집니다.
- 말랑한 모양: 보이는 반지름을 물리보다 7.5% 크게 잡고, 이웃과 겹치는 부분을 두 원의 근축(radical line)으로 잘라 떡처럼 맞닿은 면을 만듭니다. 벽·바닥에 닿으면 평평해집니다.
- 소환 순서는 시드로만 정해져서 플레이와 무관합니다. 오늘의 상자가 공정한 이유입니다.

## 명령

```bash
npm test             # 물리·규칙·다국어 테스트 + 밸런스 스윕 (약 1~2분)
npx vitest run tests/game.test.ts tests/physics.test.ts   # 규칙/물리만 (몇 초)
npm run balance      # 밸런스 스윕만 → docs/balance-results.md 갱신
npm run build        # 타입검사 + 빌드 + play/index.html
npm run e2e          # 헤드리스 크로미움으로 휴대폰·태블릿·가로·영어 화면 실기동 테스트 (e2e-out/)
npm run store-assets # 앱 아이콘, 스토어 그래픽, 캡션 스크린샷 다시 만들기
npm run font         # 게임에 쓰인 글자만 남긴 주아체 서브셋 다시 만들기 (원본 TTF 경로 필요)
```
