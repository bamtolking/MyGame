# 스토어 이미지

`npm run store-assets`로 다시 만든다.

- icon-1024.png: 앱스토어 아이콘 (불투명)
- icon-512-play.png: 구글 플레이 아이콘
- feature-1024x500-ko.png / -en.png: 구글 플레이 그래픽 이미지
- screenshots/{ko,en}/play-*.jpg: 구글 플레이 휴대폰 스크린샷 1080×1920
- screenshots/{ko,en}/ios67-*.jpg: 앱스토어 6.7인치 스크린샷 1290×2796
- raw/: 캡션 없는 원본 화면 1080×2340 (저장소에는 올리지 않음)
