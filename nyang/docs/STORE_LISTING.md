> 다른 회사 게임 이름(예: 특정 "OO게임")을 제목·키워드에 쓰면 심사에서 거절되거나 분쟁이 생길 수 있어 넣지 않았습니다.

- 카테고리: 게임 → 퍼즐 (앱스토어 보조 카테고리: 캐주얼)
- 연령: 전체이용가 / 4+
- 가격: 무료
- 연락처: `[지원 이메일을 입력하세요]`
- 개인정보처리방침: `[PRIVACY.md를 게시한 URL을 입력하세요]`

## 한국어

**앱 이름**: 냥체역학: 고양이 합체 퍼즐

**앱스토어 부제**: 말랑말랑 고양이 물리 퍼즐

**짧은 설명 (구글 플레이)**: 말랑한 고양이를 떨어뜨려 합체! 아깽이부터 우주뚱냥까지 키우는 물리 퍼즐

**프로모션 텍스트 (앱스토어)**: 매일 바뀌는 오늘의 상자! 모든 집사가 같은 순서의 고양이로 대결해요. 우주뚱냥까지 키울 수 있을까요?

**키워드 (앱스토어)**: 고양이,합체,퍼즐,물리,머지,냥,집사,귀여운,캐주얼,떨어뜨리기,연쇄,도감,오늘의상자

**자세한 설명**

```
고양이는 액체다. 이제 진짜로.

말랑말랑한 고양이를 상자에 떨어뜨려 보세요. 같은 고양이 두 마리가 닿으면 한 단계 큰 고양이로 합체! 아깽이, 치즈냥, 고등어, 턱시도, 삼색이… 11단계를 지나 전설의 우주뚱냥까지 키워 보세요.

■ 조작은 하나
화면을 끌어 위치를 정하고, 손을 떼면 쏙. 규칙은 한 줄, 한 판은 5~10분.

■ 진짜 말랑한 고양이
고양이들이 서로 눌리고, 벽에 붙어 납작해지고, 떨어질 땐 쭉 늘어나요. 합체하면 웃고, 상자가 넘칠 것 같으면 식은땀을 흘려요.

■ 연쇄 콤보
합체로 커진 고양이가 옆의 같은 고양이와 또 만나면 연쇄! 점수가 최대 4배가 돼요.

■ 능력 3종
• 냥펀치: 방해되는 고양이를 톡 날려 보내기
• 액체화: 모두 녹아내려 같은 고양이끼리 끌어당기기
• 흔들기: 상자를 흔들어 자리 다시 잡기
점수를 모으면 츄르 게이지가 차고 능력이 충전돼요.

■ 오늘의 상자
매일 새로운 규칙(달나라 상자, 버터 바른 상자, 좁은 상자…). 모든 집사가 같은 순서로 고양이를 받아요. 하루 한 판, 친구와 점수를 비교해 보세요.

■ 고양이 도감
11종 고양이를 모두 만나 보세요. 처음 만나는 고양이마다 발견 알림이 떠요.

■ 이런 분께 추천해요
• 떨어뜨려 합치는 퍼즐을 좋아하는 분
• 고양이를 사랑하는 모든 집사님
• 짧게 한 판씩 즐길 게임을 찾는 분

인터넷 없이도 플레이할 수 있고, 개인정보를 수집하지 않아요.
```

**App Store subtitle**: Squishy cat physics puzzle

**Promotional text (App Store)**: A new Daily Box every day, and everyone gets the same cats. Can you grow a Cosmic Chonk?

**Keywords (App Store)**: cat,cats,merge,drop,puzzle,physics,kitty,cute,chonk,casual,combo,daily,squishy

**Full description**

```
Cats are liquid. Now it's official.

Drop squishy cats into a cardboard box. When two matching cats touch, they merge into a bigger cat! Grow a Kitten into a Ginger, a Mackerel, a Tuxedo, a Calico… all the way up to the legendary Cosmic Chonk.

■ One-finger controls
Drag to aim, let go to drop. One rule, 5 to 10 minutes a game.

■ Truly squishy cats
Cats squish against each other, flatten on the walls and stretch as they fall. They smile when they merge and sweat when the box is about to overflow.

■ Chain combos
When a freshly merged cat meets another twin, that's a chain! Up to 4× points.

■ Three powers
• Paw Punch: boop an annoying cat out of the box
• Liquify: everyone melts and matching cats pull together
• Shake: shake the box so the cats settle into new spots
Scoring fills the treat meter and recharges your powers.

■ Daily Box
A new rule every day (Moon Box, Buttered Box, Narrow Box…). Everyone gets the same cats in the same order. One run per day, so compare scores with friends.

■ Cat-alog
Meet all 11 cats. Every new cat you find gets its own discovery moment.

■ Made for
• Fans of drop-and-merge puzzles
• Every cat lover
• Anyone looking for a quick game on the go

Plays offline. No personal data collected.
```
