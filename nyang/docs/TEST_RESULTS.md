## 단위 테스트 (`npx vitest run tests/game.test.ts tests/physics.test.ts`)

물리 (7)
- 한 마리가 떨어져 바닥에 멈춘다
- 무작위 45마리 더미가 상자 안에 가라앉는다 (겹침 1.5% 이하, 잔떨림 작음)
- 큰 고양이가 작은 고양이들을 뚫고 내려가지 않는다
- 빠르게 부딪혀도 서로 통과하지 않는다
- 마찰로 굴러간다 (미끄러짐 없이 v ≈ ωr)
- 같은 입력이면 결과가 완전히 같다 (결정성)
- 닿은 쌍을 합체 판정용으로 기록한다

규칙 (21)
- 같은 단계 둘 → 중간 지점에서 다음 단계 하나 + 점수 / 다른 단계는 합치지 않음
- 셋이 동시에 닿아도 합체는 한 번 (중복 사용 없음)
- 연쇄 합체에 콤보 배율 적용
- 우주뚱냥 둘 → 둘 다 사라지고 보너스
- 캣닢: 닿은 고양이 한 단계 업 / 뱅갈보다 크면 점수 100점만
- 떨어뜨리기 대기시간, 조준 범위 제한
- 소환 순서는 시드로만 정해짐 (플레이 방식과 무관) — 오늘의 상자 공정성
- 캣닢 공 출현 간격, 첫 4번은 작은 고양이만
- 테두리 위 2.2초(+유예) → 끝, 집사 찬스는 한 번만, 위쪽 40% 정리
- 능력 3종의 효과와 충전 개수, 츄르 게이지 충전
- 흔들기·액체화만으로는 판이 끝나지 않음 (회귀 테스트, 시드 6개)
- 액체화 중 끼인 고양이가 튕겨 나가지 않음 (회귀 테스트, 시드 80개)
- 평소 플레이에서 고양이가 상자 위로 멀리 날아가지 않음
- 저장 → 복원 후 똑같이 진행 / 깨진 저장 데이터는 거부
- 날짜별 오늘의 상자 시드·규칙이 안정적이고 60일 동안 6종 이상 나옴
- 한국어·영어 사전 키가 같고 치환이 동작함

추가 (v0.10)
- 피버: 게이지가 차면 시작, 점수 2배·준비 시간 절반, 시간이 끝나면 종료
- 황금 고양이: 합체 점수 3배, 소환 순서처럼 시드로만 정해지고 처음 6번은 안 나옴, 저장/복원에 포함
- 집사 레벨 계산, 첫 판에 레벨 2 도달, 해금 레벨이 겹치지 않고 Lv2~10은 매 레벨 보상
- 오늘의 상자 연속 기록 (날짜 넘김, 끊김, 월/연 경계)
- 오늘의 미션: 날짜별 고정, 쉬움·보통·어려움 하나씩, 진행·완료·전체 보너스, 두 언어 문구
- 배경음악 악보: 16마디, 음이름 해석, 멜로디가 F장조(+차용음) 안에 있고 강박 음이 코드와 거의 맞음

## 밸런스 스윕 (`npm run balance`)

봇이 한 판을 끝까지 합니다. 사람은 한 번 떨어뜨리는 데 2초 걸린다고 보고 판 길이를 추정했습니다.

| 조건 | 사람 속도 추정 판 길이 | 최고 단계 | 피버 |
|---|---|---|---|
| 능력 안 쓰는 봇 | 약 8분 | 페르시안~메인쿤 | 판당 6~7번 (떨어뜨림 37번마다) |
| 1초 앞을 계산하는 강한 봇 | 약 12분 | 대부분 우주뚱냥 | 판당 10번 |
| 능력 + 집사 찬스 사용 | 약 17분 | 모두 우주뚱냥 | 판당 14번 |
| 오늘의 상자 규칙 8종 | 7~9분 | 대부분 메인쿤 | 판당 5~7번 |

- 황금 고양이 합체는 판당 약 9번.

- 물리 한 스텝(1/60초, 하위 스텝 8번)은 고양이 40마리 안팎에서 평균 0.03ms (Node 기준).

## 브라우저 e2e (`npm run build && npm run e2e`)

화면: 휴대폰 390×844, 작은 휴대폰 360×640, 가로 844×390, 태블릿 768×1024 (이상 한국어), 휴대폰 390×844 (영어). 각 화면에서 확인한 것:

- 기기 언어를 따라 한국어/영어로 시작
- 타이틀의 레벨·미션·꾸미기 버튼이 화면 폭 안에 들어옴, 미션 3개 표시
- 잠긴 꾸미기는 못 고르고, 레벨이 오르면 상자 스킨을 바꿀 수 있음
- 게임 중에는 게임 음악, 끝나면 타이틀 음악
- 피버 게이지가 거의 찬 상태에서 황금 고양이 합체 → 냥냥 피버 시작
- 결과 화면에 얻은 경험치와 오늘의 미션 표시, 오늘의 상자 연속 기록 1일 시작
- 타이틀 → 게임 시작, 첫 안내 표시
- 터치 14번으로 떨어뜨리기, 합체와 점수, 끌어서 조준
- 액체화 시작·종료 후 마찰 복구, 흔들기, 냥펀치 조준 → 탭한 고양이 제거
- 일시정지 중 시간 정지, 계속하기
- 일시정지 후 저장된 판이 화면과 같고, 새로고침 후 "이어하기"로 이어짐
- 넘침 → 집사 찬스 → 계속 → 다시 넘침 → 결과 화면, 결과 카드 이미지(1080px), 공유(복사) 피드백
- 판이 끝나면 저장된 판 삭제, 타이틀에 최고 기록 표시
- 도감 11칸과 상세, 설정 토글, 언어 전환 후 복귀
- 오늘의 상자 소개 → 시작 → 결과 → 타이틀에 "완료" 표시 → 카운트다운
- HUD가 화면 안에 들어오는지, 페이지 오류 0

헤드리스 소프트웨어 렌더링에서 고양이가 가득 찬 상자의 프레임: 휴대폰 크기 57~60fps, 태블릿(1536×2048 픽셀) 34~44fps. 실제 기기는 GPU를 쓰므로 이 숫자와 다릅니다.
