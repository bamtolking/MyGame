# 심연의 군주 (ABYSS)

디아블로 스타일의 쿼터뷰(아이소메트릭) 핵앤슬래시 액션 RPG입니다. 브라우저(PC·휴대폰)에서 바로 실행되며 서버·회원가입·결제·광고가 없습니다.
이름·그림·이야기·수치는 모두 이 프로젝트에서 새로 만든 것이며, 장르의 핵심 재미(어두운 던전, 무작위 전리품, 성장, 보스)를 그대로 옮겼습니다.

> 잿빛마을 언덕 위 대성당 아래로 열린 심연. 12개 층을 내려가 네 명의 보스를 쓰러뜨리고 심연의 군주 말레가스를 처치하세요.

## 바로 실행하기

- **가장 쉬운 방법**: `abyss/play/index.html` 파일 하나가 게임 전체입니다. PC나 휴대폰 브라우저(Chrome/Safari)로 열면 바로 실행됩니다.
- **개발 서버** (Node.js 22):
  ```bash
  npm install
  npm run abyss:dev      # 표시되는 주소를 브라우저로 열기 (같은 Wi-Fi의 휴대폰에서도 접속 가능)
  ```
- **빌드**: `npm run abyss:build` → `abyss/dist/`(정적 사이트) + `abyss/play/index.html`(단일 파일)

휴대폰은 **가로 화면**을 추천합니다(세로도 지원).

## 조작

**PC**
- 왼쪽 클릭: 이동 / 공격 / 줍기 / 대화 / 계단 (누르고 있으면 계속) · Shift+클릭: 제자리 공격
- 오른쪽 클릭: 지정 기술(기술 창에서 선택) · `1`~`5`: 커서 방향으로 기술 · `WASD`/방향키: 이동 · `Space`: 커서 방향 공격
- `Q` 생명 물약 · `E` 마나 물약 · `T` 귀환 두루마리
- `I` 가방 · `C` 캐릭터 · `K` 기술 · `Tab`/`M` 지도 · `Alt` 아이템 이름 모두 보기 (`Z`: 항상 보기 전환) · `Esc` 메뉴
- 가방: 클릭하면 선택(버튼 표시), **더블클릭/우클릭**으로 장착·해제·판매(상점)·보관(보관함)

**모바일**
- 왼쪽 아래를 드래그: 이동(가상 조이스틱)
- 큰 버튼: 공격(가장 가까운 적 자동 조준, 조이스틱 방향 우선) · 작은 버튼 5개: 기술(누르고 있으면 반복)
- 가까운 아이템·사람·상자·계단이 있으면 금색 버튼이 떠서 한 번에 상호작용
- 화면 속 적/아이템/사람을 직접 탭해도 됩니다

## 구조

```
abyss/
  src/data/      수치 데이터(직업·기술, 아이템·속성·고유, 몬스터·보스, 구역·난이도·전리품 확률) — 밸런스는 여기만 수정
  src/sim/       시뮬레이션(순수 TS, DOM 없음): rng, dungeon(층/마을 생성), path(A*·흐름장·시야), items, stats,
                 combat(피해·죽음·전리품·투사체·범위), ai(몬스터 행동), bosses, skills, game(명령·이동·상점·저장)
  src/render/    Canvas 2D 아이소메트릭 렌더러: 절차적 타일 텍스처, 캐릭터 리그(장비에 따라 외형 변화), 소품, 파티클·주문 효과,
                 어둠/광원, 아이템 이름표, 자동 지도
  src/ui/        HUD(체력·마나 구슬, 기술 바), 패널(가방·캐릭터·기술·상점·보관함), 입력(마우스·키보드·터치), 메인 루프
  src/platform/  저장(localStorage + 검증 + 백업), 사운드: dsp(합성 도구) · sfx(효과음 레시피) · music(악기·적응형 음악) · audio(재생 엔진)
  tests/         규칙 테스트, 던전 연결성 테스트, 헤드리스 봇 밸런스 스윕
  scripts/       단일 파일 빌드, 헤드리스 Chromium 스크린샷/흐름 테스트
```

- 고정 시간 스텝(1/60초) 시뮬레이션. 같은 시드 + 같은 입력 = 같은 결과(테스트로 검증).
- 던전 생성 시 모든 바닥이 시작 지점과 연결되는지, 막는 소품이 길을 끊지 않는지 검사합니다.

## 명령

```bash
npm run abyss:test      # 규칙·던전 테스트 (약 3초)
npm run abyss:balance   # 봇이 3직업 × 3시드로 1~12층을 플레이 → abyss/docs/balance-results.md (약 1~2분)
npm run abyss:build     # 타입 검사 + 빌드 + play/index.html
npm run abyss:shots     # 헤드리스 Chromium으로 PC/휴대폰 화면 촬영 + 상점·장착·포탈·표석·사망·저장 흐름 확인 (e2e-out/)
```

구현 상태와 알려진 제한은 [`docs/STATUS.md`](docs/STATUS.md), 밸런스 결과는 [`docs/balance-results.md`](docs/balance-results.md)를 보세요.
