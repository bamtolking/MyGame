- 몬스터 21종 + 보스 4종(단계별 패턴), 챔피언·고유 몬스터와 속성 10종, 무리 각성·도주(타락자)·부활(주술사).
- 아이템 4등급, 기본 65종, 속성 40종(단계별), 고유 20종, 장착 비교 툴팁, 상점·판매·도박·공용 보관함.
- 성소 6종, 통/상자/석관, 귀환 두루마리 차원문(양방향), 순례자의 표석(웨이포인트), 난이도 3단계(보통/악몽/지옥).
- 어둠과 광원(영웅·횃불·용암·주문), 벽 투명화(영웅이 벽 뒤에 있을 때), 미니맵·전체 지도, 피해 숫자, 화면 흔들림, 유니크 드롭 광선.
- PC(마우스/키보드)와 모바일(조이스틱·자동 조준·상호작용 버튼) 조작, 저장/불러오기(검증·백업), 설정(음량·이펙트·피해 숫자·흔들림·이름표).

## 알려진 제한
- **사람이 직접 끝까지 플레이한 테스트는 아직 없습니다.** 밸런스는 봇 기준이며, 봇은 보스 공격을 피하지 않아 최종 보스에서 여러 번 죽습니다. 사람은 경고 원을 피할 수 있어 더 쉬울 것입니다.
- 실제 휴대폰(iOS Safari/Android Chrome)에서의 터치 감도·성능·소리는 확인하지 못했습니다(헤드리스 브라우저로만 확인). 헤드리스(GPU 없는 소프트웨어 렌더링, 1280×720)에서 최고 품질 약 35 FPS, 최저 품질 약 50 FPS였고, 느린 기기에서는 자동으로 품질을 낮춥니다.
- **효과음과 음악은 사람이 귀로 들어보며 다듬지 못했습니다.** 합성 결과는 수치(음량 균형, 깨진 값 없음)로만 검사했습니다. 거슬리는 소리가 있으면 `src/platform/sfx.ts`의 해당 항목 음량(`M(음량, …)`)을 조정하면 됩니다.
- 첫 입력(클릭/키) 때 소리를 합성하므로 제목 화면에서 1~2초 정도 CPU를 씁니다. 긴 소리(보스 처치 등)는 처음 쓰일 때 합성됩니다.
- 악몽·지옥 난이도는 수치 곡선만 적용되어 있고 봇으로 끝까지 검증하지 않았습니다.
- 인벤토리는 칸 크기가 모두 1칸입니다(디아블로 1/2의 테트리스식 크기 없음). 내구도·소켓·세트 아이템·용병·멀티플레이는 없습니다.
- 층을 다시 들어가면 새로 생성됩니다(귀환 차원문으로 돌아가는 경우만 같은 층 유지).
- 제목 글꼴(나눔명조)은 인터넷 연결 시 Google Fonts에서 받아오며, 오프라인이면 기본 명조체로 표시됩니다.
