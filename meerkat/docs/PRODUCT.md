# 미어캣 제품 전략서

> 한 줄: **“내 자세는 어떤 동물?” — 사진 두 장으로 AI가 체형을 재고, 물리치료사가 매일 교정 운동을 처방한다.**

## 1. 왜 이 앱인가

### 누구나 가진 문제
- 하루 대부분을 모니터와 스마트폰 앞에서 보내는 사무직·학생은 거의 모두 **거북목·라운드숄더·골반 불균형** 중 하나를 겪어요.
- “거북목 스트레칭”, “라운드숄더 교정”, “골반 교정”은 늘 검색 상위 키워드이고, 유튜브 자세 교정 채널은 꾸준히 인기예요.
- 헬스장·필라테스 센터의 **체형 분석 기기 + 교정 PT**는 회당 수만 원이지만, 대부분의 사람은 “내 자세가 얼마나 나쁜지”조차 모른 채 지내요.

### 기존 앱의 빈틈
| 기존 | 한계 | 미어캣 |
|---|---|---|
| 스트레칭 앱 | 남들과 똑같은 루틴, 효과를 확인할 수 없음 | 내 몸을 **측정**하고 결과에 맞춰 **처방** |
| 자세 알림 앱 | 알림만 옴, 교정 방법 없음 | 1분 리셋 + 4주 교정 프로그램 |
| 헬스장 체형 분석 기기 | 비싸고 센터에 가야 함 | 휴대폰 하나, 무료, 30초 |
| AI 운동 앱 | 헬스 위주, 자세 교정 전문성 부족 | **물리치료사**의 평가 기준·처방 논리 |

### 우리만의 무기: 대표가 물리치료사 겸 트레이너
1. **신뢰**: “현직 물리치료사가 설계” 한 줄이 건강 앱에서는 가장 강력한 설득 포인트예요.
2. **콘텐츠 엔진**: 대표가 직접 찍는 쇼츠·릴스(“30초 거북목 자가진단”)가 곧 광고예요.
3. **B2B 채널**: 대표의 회원, 동료 트레이너·치료사가 첫 유료 고객이 될 수 있어요.
4. **전문성의 해자**: 판정 기준(`src/analysis/norms.ts`)과 처방 규칙을 임상 경험으로 계속 다듬을 수 있어요.

## 2. 성장 구조 (이미 앱에 들어가 있음)

### 바이럴 루프: 동물 유형 + 자세 나이
```
스캔 → “나는 모니터 속 거북이형, 자세 나이 +9세” 결과 카드
     → 인스타 스토리·카톡 공유 (사진은 절대 안 들어감 → 부담 없이 공유)
     → 친구: “나도 해 볼래” → 설치
```
- MBTI처럼 **유형**으로 나누면 사람들은 자기 유형을 말하고 싶어 해요. 거북·새우·오리·플라밍고는 이미 한국인이 쓰는 표현(거북목, 새우등, 오리궁둥이, 짝다리)이라 설명이 필요 없어요.
- “자세 나이”는 숫자 하나로 충격과 재미를 줘요(혈관 나이·피부 나이처럼).

### 리텐션 루프: 측정 → 처방 → 재측정
```
매일: 5~15분 맞춤 루틴 (매일 조합이 바뀜) + 연속 운동 일수 🔥
근무 중: 1분 리셋 알림
매주: 재스캔 → 점수 그래프·전후 비교 → “12점 올랐어요 📈” → 다시 공유
4주: 거북이 → 미어캣 변신 (유형이 바뀌는 순간이 최고의 공유 순간)
```
- 난이도는 “쉬웠어요/힘들었어요” 응답으로 자동 조절돼요.
- 통증 기록은 루틴에 반영돼 “나를 아는 앱”이 돼요.

## 3. 수익 모델

| 단계 | 무료 | 프리미엄 (예: 월 6,900원 / 연 49,000원) |
|---|---|---|
| 스캔 | 월 2회 | 무제한 + 전후 비교 |
| 루틴 | 5분 기본 루틴 | 10·15분, 통증 부위 집중, 4주 프로그램 |
| AI 카메라 코치 | 체험 1회 | 무제한 |
| 리포트 | 결과 카드 | 상세 리포트 PDF 저장 |

**B2B “미어캣 프로”** (트레이너·물리치료실·필라테스)
- 전문가 모드(이미 들어가 있음: 원시 측정값, 센터·회원 이름 기록)를 확장해 회원별 스캔 관리, 센터 로고 리포트, 운동 숙제 전송.
- 체형 분석 기기(수백만 원) 대신 태블릿 하나 → 월 구독(예: 29,000~99,000원).

**기업 복지**: 사무직 대상 “4주 거북목 탈출 챌린지” 패키지.

> 결제는 스토어 인앱 결제(구글 플레이 결제 / Apple IAP)로 붙이는 걸 권장해요. RevenueCat 같은 서비스를 쓰면 두 스토어를 한 번에 관리할 수 있어요.

## 4. 출시 전략

1. **비공개 테스트 (2~3주)**: 대표의 회원 30~50명 → 실제 사진으로 판정 기준 보정, 운동 반응 확인.
2. **콘텐츠 선공개**: “내 자세 동물 테스트” 릴스·쇼츠 10편 (앱 화면 녹화 + 대표 해설).
3. **정식 출시**: 한국 먼저 → 반응 좋으면 영어권(영어 UI 이미 완성), 일본(猫背·ストレートネック 수요 큼).
4. **ASO 키워드**: 거북목, 자세교정, 체형분석, 일자목, 라운드숄더, 골반교정, 스트레칭, 목 통증, 허리 통증, 자세 측정.

### 핵심 지표
- 설치 → 첫 스캔 완료율 (목표 60%+)
- 스캔 → 첫 운동 시작률, 결과 카드 공유율
- D1 / D7 / D30 유지율, 주간 재스캔율
- 무료 → 유료 전환율

## 6. 위험과 대응

| 위험 | 대응 |
|---|---|
| **의료기기 규제** | “진단·치료” 표현을 쓰지 않고 “측정·분석·참고용”으로 표현(앱 전체 문구 반영됨). 식약처 「의료기기와 개인용 건강관리(웰니스) 제품 판단 기준」에 맞춰 웰니스 앱으로 포지셔닝. 출시 전 문구 한 번 더 검토 권장. |
| 측정 정확도 | 사진 기반 추정의 한계를 리포트에 명시, 같은 조건 재촬영 안내. 판정 기준을 파일 하나로 분리해 전문가가 보정. 추후 임상 측정과 비교 연구(ICC) → 신뢰도 마케팅. |
| 안전 | 위험 신호(마미 증후군·흉통·척추동맥 증상 등) 체크 시 운동 차단, 통증 강도별 동작 제외, 운동 후 통증 증가 경고. |
| 개인정보 | 모든 처리가 기기 안에서 — 서버·계정 없음. 스토어 개인정보 라벨 “수집하지 않음”. |
| 경쟁사 모방 | 대표의 임상 콘텐츠·브랜드(동물 캐릭터)·커뮤니티로 차별화, B2B로 락인. |
