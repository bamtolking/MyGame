## 자세한 설명
```
🐢 내 자세는 어떤 동물일까?

정면과 옆모습, 사진 두 장이면 끝.
AI가 30초 만에 거북목 각도부터 골반 높이까지 12가지 자세 지표를 측정하고,
현직 물리치료사가 설계한 맞춤 교정 운동을 매일 처방해 드려요.

━━━━━━━━━━━━━━━━━━━━━━
📸 30초 AI 체형 분석
━━━━━━━━━━━━━━━━━━━━━━
• 휴대폰을 세워 두고 음성 안내대로 서 있으면 자동 촬영 (혼자서도 OK)
• 거북목(머리 전방 각도) · 라운드숄더 · 등 굽음 · 허리 곡선
• 어깨·골반 높이 차이 · 몸통 치우침 · X/O다리 · 무릎 과신전
• 물리치료 자세 평가의 기준인 ‘수직선(plumb line) 분석’을 AI로 재현

🐢🦐🦆🦩 나의 체형 유형 + 자세 나이
• 모니터 속 거북이형, 책상 앞 새우형, 엉덩이 쏙 오리형, 짝다리 플라밍고형…
• 목표는 꼿꼿한 ‘미어캣형’!
• 자세 나이로 한눈에 확인하고, 결과 카드로 친구와 공유 (사진은 절대 포함되지 않아요)

🧑‍⚕️ 물리치료사가 설계한 맞춤 처방
• 풀기 → 늘리기 → 깨우기 → 통합, 임상에서 쓰는 교정 순서 그대로
• 스캔 결과·통증 부위·생활 습관에 맞춰 매일 5·10·15분 루틴을 새로 구성
• 운동 48가지, 3D 시범 애니메이션, 방법·코칭 포인트·흔한 실수까지

🎙️ 따라만 하면 되는 운동 플레이어
• 음성 코칭과 자동 타이머, 세트·휴식 자동 진행
• AI 카메라 코치가 스쿼트·벽 천사 등의 횟수를 세고 자세를 확인
• “쉬웠어요/힘들었어요”에 따라 난이도 자동 조절

📈 변화를 숫자로
• 매주 재스캔 → 자세 점수 그래프와 전후 비교
• 연속 운동 일수, 운동 달력, 통증 변화 기록

💼 사무실 1분 리셋
• 앉아서 하는 목·어깨·허리·손목 리셋
• 근무 시간 자세 리셋 알림

🛡️ 안전하게
• 운동 전 위험 신호 체크, 통증 강도에 따라 무리한 동작 자동 제외
• 운동 후 통증 변화 확인

🔒 사진은 기기 밖으로 나가지 않아요
• 모든 AI 분석은 휴대폰 안에서만. 회원가입도, 서버 전송도 없어요.

※ 미어캣은 자세 관리를 돕는 웰니스 앱이며 의료기기가 아닙니다.

```

Meerkat is a wellness app, not a medical device.
