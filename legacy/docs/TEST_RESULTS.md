## 2. 밸런스 스윕 — `npm run balance` (봇 5전략 × 6시드, 보통, 1배속)
결과 표: `docs/balance-results.md` (요약: 공격 위주 6/6 승리(생명 6~20), 제어+공격 4/6, 경제 선투자 5/6, 빠른 혼합 합성 3/6, 확정 합성 대기 4/6). 완주 14.4~30분, 첫 신화 웨이브 10~37(대개 11~16), 첫 영웅 웨이브 3~9.
- 해석: 무조건 섞어 합치는 전략이 가장 불리하고, 신화를 만들지 않으면 후반(수집왕)에서 자주 실패. 봇은 즉시 최적 배치를 하므로 사람은 이보다 어렵게 느낄 수 있음.
- 초기 유닛만 두고 아무것도 하지 않으면 10웨이브에서 패배.
