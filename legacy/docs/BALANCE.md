# 밸런스 데이터 (첫 베타, 보통 난이도)

모든 값은 `src/data/*.ts`에 있으며 UI(강화 시트·확률 시트·유닛 패널)에 그대로 표시됩니다.

## 소환
| 항목 | 값 |
|---|---|
| 기본 확률 | 일반 70% / 희귀 25% / 영웅 4.5% / 전설 0.5% (신화 0%) |
| 종류 | 등급 추첨 후 8종 균등 |
| 불운 보정 | 영웅 미만 12회 연속 → 다음 소환 영웅 95% / 전설 5%. 영웅 이상이 나오면 카운터 0 |
| 운명 조각 | 일반 등급 소환마다 1개. 5개로 다음 소환 종류 지정(등급 확률·보정은 그대로) |
| 비용 | 30 + 2×(지금까지 소환 수), 최대 100 |
| 시작 | 골드 110, 생명 20, 고정 지원: 일반 태엽 사수 + 일반 폭죽 너구리 |

## 합성
- 같은 등급 3개 → 한 단계 위 1개. 종류가 같으면 확정, 섞이면 무작위 종류. 전설은 승급 없음.
- 등급 피해 배율: 일반 1 / 희귀 2.6 / 영웅 6.5 / 전설 15 (3개 합산 대비 87% / 83% / 77% → 자리 효율은 오르고 총 화력은 소폭 감소, 대신 보조 효과 상승).
- 등급별 보조 효과: 폭발 반경 45/53/61/69, 연결 3/4/5/6, 감속 30/36/42/48%, 부식 4/7/12/20 dps, 끌기 26/32/38/44, 정비사 버프 15/20/25/30%, 두꺼비 수입 4/10/22/45.
- 사거리 +0/8/16/24. 판매가 10/30/80/200.

## 경제
- 웨이브 보상 30 + 4×웨이브 (상인 길드 인장 +15%). 조기 시작: 남은 초 × 2.
- 위험한 추가 주문(15/25/35 웨이브 전 대기 중 선택): +90/140/200 골드, 조각 +3/4/5. 거절 시 손해 없음.
- 공방 과열(12/22/32): 무작위 자리 3곳 4초 예고 후 25초간 피해 +40%.
- 강화: 공격력 45+25×단계(최대 12), 공격 속도 60+35×단계(최대 8), 생명 90+60×단계(최대 5).
- 스킬: 포격 반경 60, 피해 140×(1+0.08×웨이브), 보스 35%, 60초. 냉각 반경 70, 잡몹 2초 빙결(재적용 4초 제한), 보스 40% 감속 2초, 50초.
