# 달빛 퇴마단 (Moonlit Exorcists) — 알파 v0.1

**한 손으로 즐기는 요괴 퇴마 MMORPG.** 조선풍 달밤의 고을에서 도깨비·물귀신·달걀귀신·저승사자·구미호를 쓸어버립니다.
이동만 하면 공격과 부적(스킬)은 자동. 화면 가득 몰려오는 요괴 떼를 여럿이 함께 쓸어 담는 **"뱀서라이크 손맛 + MMO 사회성"** 게임입니다.

> 한 문장: **지하철에서 엄지 하나로, 모르는 사람과 함께 요괴 떼를 쓸어버리는 MMORPG.**

- 진짜 멀티플레이 서버(Node.js + WebSocket, 서버 권위형) — 같은 채널의 사람들이 실시간으로 함께 사냥
- 서버가 없어도 되는 **오프라인 체험 월드**: 같은 서버 코드가 브라우저 안에서 돌아가고, AI 동료 6명(이름표에 **AI** 표시)이 함께 사냥
- 파일 하나(`play/index.html`)로 휴대폰에서 바로 실행. 에셋 파일 없음(그림·소리 전부 코드로 생성)

기획 의도와 "왜 대박날 수 있는가"는 [`docs/DESIGN.md`](docs/DESIGN.md), 구현/미구현 목록은 [`docs/STATUS.md`](docs/STATUS.md), 테스트·밸런스·부하 결과는 [`docs/TEST_RESULTS.md`](docs/TEST_RESULTS.md)에 있습니다.

## 바로 해보기 (비개발자용)

1. **가장 쉬운 방법 — 오프라인 체험**: `play/index.html` 파일 하나가 게임 전체입니다. 휴대폰/PC 브라우저(Chrome, Safari)로 열면 됩니다.
2. **친구와 온라인으로 (같은 Wi-Fi)**: Node.js 22.18 이상을 설치하고
   ```bash
   cd mmorpg
   npm install
   npm run build      # 클라이언트 빌드 (dist/ + play/index.html)
   npm start          # 게임 서버 실행 → http://localhost:8080
   ```
   터미널에 뜬 주소의 `localhost`를 PC의 IP로 바꿔(예: `http://192.168.0.10:8080`) 휴대폰 브라우저로 열고 **🌐 온라인 접속**을 누르세요. 여러 대가 접속하면 같은 채널에서 서로 보입니다.
3. 인터넷에 공개하려면 클라우드 서버(VM)에서 같은 명령을 실행하고 HTTPS 리버스 프록시(예: Caddy/Nginx)를 앞에 두면 됩니다. 서버 설정은 아래 환경 변수로 바꿉니다.

## 조작

| 동작 | 휴대폰 | PC |
|---|---|---|
| 이동 | 화면 아무 곳이나 누르고 드래그 (떠 있는 조이스틱) | WASD / 방향키 (마우스 드래그도 가능) |
| 공격·부적 | 자동 | 자동 |
| 필살기 | 오른쪽 아래 큰 원 버튼(충전되면 빛남) | Space |
| 자동 사냥 | AUTO 버튼 (조이스틱을 움직이면 해제) | — |
| 가방/부적/퀘스트/지도 | 오른쪽 메뉴 | B / T / Q / M |
| 채팅·감정표현 | 왼쪽 아래 💬 😀 | Enter |
| NPC(대장장이·부적상·게시판·무당) | 마을에서 NPC를 탭 | 클릭 |

## 게임 한눈에

- **직업 3종**: 검객(근접·흡혈·회오리 베기), 궁사(원거리·치명타·화살비), 무녀(범위·치유·대굿 — 쓰러진 동료를 즉시 부활)
- **부적 8종 × 5단계**: 칼바람(회전 칼날), 도깨비불(유도탄), 뇌전(연쇄 번개), 서리(감속 폭발), 결계(장판), 파마(관통), 방울(파티 치유), 금강(파티 보호막). 부적 칸은 Lv1/3/7/12에 열리고 **같은 부적 3장 → 한 단계 합성**
- **지역 4곳 + 마을 + 월드 보스 제단**: 도깨비 숲(Lv1–8) → 물안개 늪(8–14) → 폐사찰(14–20) → 구미호 골짜기(20–29). 지역 사이는 절벽·숲 경계로 막혀 있고 길(관문)로만 이어집니다
- **지역 보스 4종**(금방망이 대장·늪의 이무기·저승사자·구미호)과 **핏빛 달 월드 보스 불가사리**(정해진 시간마다 채널 전체 이벤트, 참여자 전원 보상)
- **함께하면 이득**: 근처에서 잡힌 요괴는 근처 모두에게 경험치·전리품(각자 따로)이 들어갑니다(뺏기 없음). 쓰러지면 동료가 곁에 2초 서 있으면 부활
- 이야기 퀘스트 19개(길 찾기 화살표가 관문을 따라 안내), 반복 현상금, 장비(무기·갑옷·노리개 × 5등급, 랜덤 옵션, +10 강화), 황금 도깨비, 요괴 떼 습격

## 구조

```
src/shared/   서버·클라이언트 공용: 상수, 데이터(직업·요괴·지역·부적·장비·퀘스트), 절차적 월드 생성, 이동/충돌, 이진 프로토콜, A* 길찾기
src/server/   서버 권위 시뮬레이션(순수 TS, Node/브라우저 겸용): world(20Hz 틱), ai·bosses, combat, director(스폰), progress(보상·퀘스트),
              worldboss, actions(검증된 명령), session(관심 영역·스냅샷·상태 diff), server(채널·접속·저장), bots(AI 동료)
src/server/node/main.ts   Node 진입점: HTTP(정적 파일 + /api/info) + WebSocket(/ws) + 파일 저장
src/client/   브라우저: net(WebSocket / 페이지 내 오프라인 서버), game(보간·예측·이벤트), render(캔버스·절차적 스프라이트·지형 청크·조명·이펙트), ui(HUD·시트·조이스틱), audio
tests/        vitest 규칙·통합 테스트, 헤드리스 플레이 시뮬레이터(밸런스)
scripts/      단일 파일 빌드, 밸런스 스윕, 부하 테스트, Playwright e2e
```

핵심 설계:
- **서버 권위형**: 클라이언트는 "조이스틱 방향(정수)"과 메뉴 명령만 보냅니다. 전투·드랍·경제는 전부 서버가 계산하고, 모든 명령을 검증합니다(속도 핵 방지 토큰 버킷, 채팅 필터, 요청 빈도 제한).
- **네트워크**: 20Hz 시뮬레이션, 10Hz 이진 스냅샷(개체당 9바이트, 관심 영역만), 이벤트/상태는 변경분만 JSON. 내 캐릭터는 클라이언트 예측 + 서버 재조정(같은 이동 코드를 양쪽에서 실행해 1/8px까지 일치), 다른 개체는 140ms 보간.
- **오프라인 모드도 같은 코드**: 브라우저 안에서 `GameServer`를 그대로 돌리고 가짜 연결로 붙습니다. 그래서 오프라인에서 되는 것은 온라인에서도 됩니다.

## 명령

```bash
npm test            # 규칙·통합(실제 WebSocket 서버 포함)·스모크 테스트 38개 (약 11초)
npm run build       # 타입 검사 + 빌드 + play/index.html(단일 파일)
npm start           # 게임 서버 (PORT=8080)
npm run balance     # 밸런스 스윕: 3직업 × 2시드 × 180분 플레이 시뮬레이션 → docs/balance-results.md (약 2분)
npm run load        # 부하 테스트 (예: node scripts/loadtest.ts 160 60, node scripts/loadtest.ts ws 60 25)
npm run e2e         # 헤드리스 Chromium: 휴대폰 화면 3종 오프라인 플레이 + 브라우저 2개 온라인 동시 접속
```

서버 환경 변수: `PORT`(8080) · `CHANNELS`(2, 채널당 최대 80명) · `BOTS`(0, 온라인 채널에 AI 동료 추가) · `SEED`(월드 시드) · `DATA_DIR`(./server-data, 캐릭터 저장) · `WB_INTERVAL`(600초, 월드 보스 간격) · `WB_FIRST`(240초) · `NAME`(서버 이름) · `STATIC_DIR`(./dist)

## 스토어 출시까지 남은 것 (요약)

이 저장소는 **플레이 가능한 알파**입니다. 구글 플레이/앱스토어 출시에는 네이티브 포장(Capacitor 또는 TWA), 로그인(구글/애플/게스트 이전), 운영 서버·모니터링, 결제(치장·시즌패스), 전문 아트·사운드, 실기기·사람 대상 테스트가 필요합니다. 단계별 계획은 [`docs/DESIGN.md`](docs/DESIGN.md)의 "출시 로드맵"을 보세요.
