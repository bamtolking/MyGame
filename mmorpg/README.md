# 달빛 퇴마단 (Moonlit Exorcists) — 알파 v0.3

**한 손으로 즐기는 요괴 퇴마 MMORPG.** 조선풍 달밤의 고을에서 도깨비·물귀신·달걀귀신·저승사자·구미호를 쓸어버립니다.
이동만 하면 공격과 부적(스킬)은 자동. 화면 가득 몰려오는 요괴 떼를 여럿이 함께 쓸어 담는 **"뱀서라이크 손맛 + MMO 사회성"** 게임입니다.

> 한 문장: **지하철에서 엄지 하나로, 모르는 사람과 함께 요괴 떼를 쓸어버리는 MMORPG.**

- 진짜 멀티플레이 서버(Node.js + WebSocket, 서버 권위형) — 같은 채널의 사람들이 실시간으로 함께 사냥
- 서버가 없어도 되는 **오프라인 체험 월드**: 같은 서버 코드가 브라우저 안에서 돌아가고, AI 동료 6명(이름표에 **AI** 표시)이 함께 사냥
- 파일 하나(`play/index.html`)로 휴대폰에서 바로 실행. 에셋 파일 없음(그림·소리 전부 코드로 생성)
- **v0.3 직업 10종 · 가로 화면**: 검객·궁사로 시작해 레벨·첫 보스·핏빛 달로 무녀·도사·창술사·수문장·자객·포수·악사·화공이 하나씩 열리고, 마을 신당 무당에게서 전직합니다. 직업마다 전용 그림(11프레임)·기본 공격·필살기 연출·효과음. 화면은 항상 가로 — 세로로 잠긴 휴대폰에서는 게임이 알아서 90° 돌아갑니다 — 아래 "직업 10종" 참고
- **v0.2 그래픽·사운드 개편**: WebGL 렌더러(빛 번짐·색 조명·충격파 왜곡·색수차·필름 그레인), 고해상도 캐릭터/요괴 애니메이션, 타격 정지·넉백·흰 번쩍임·용해 소멸, 필살기 컷인·연타 콤보·보스 등장 타이틀, 국악 퓨전 적응형 배경음과 합성 효과음 46종 — 아래 "그래픽 · 사운드" 참고

기획 의도와 "왜 대박날 수 있는가"는 [`docs/DESIGN.md`](docs/DESIGN.md), 구현/미구현 목록은 [`docs/STATUS.md`](docs/STATUS.md), 테스트·밸런스·부하 결과는 [`docs/TEST_RESULTS.md`](docs/TEST_RESULTS.md)에 있습니다.

## 바로 해보기 (비개발자용)

1. **가장 쉬운 방법 — 오프라인 체험**: `play/index.html` 파일 하나가 게임 전체입니다. 휴대폰/PC 브라우저(Chrome, Safari)로 열면 됩니다.
2. **친구와 온라인으로 (같은 Wi-Fi)**: Node.js 22.18 이상을 설치하고
   ```bash
   cd mmorpg
   npm install
   npm run build      # 클라이언트 빌드 (dist/ + play/index.html)
   npm start          # 게임 서버 실행 → http://localhost:8080
   ```
   터미널에 뜬 주소의 `localhost`를 PC의 IP로 바꿔(예: `http://192.168.0.10:8080`) 휴대폰 브라우저로 열고 **🌐 온라인 접속**을 누르세요. 여러 대가 접속하면 같은 채널에서 서로 보입니다.
3. 인터넷에 공개하려면 클라우드 서버(VM)에서 같은 명령을 실행하고 HTTPS 리버스 프록시(예: Caddy/Nginx)를 앞에 두면 됩니다. 서버 설정은 아래 환경 변수로 바꿉니다.

## 그래픽 · 사운드 (v0.2)

**화면**
- **WebGL 렌더러**(WebGL2, 안 되면 WebGL1): 스프라이트를 아틀라스에 모아 한 번에 그리고, 장면·빛·발광 세 층을 합성합니다. 달밤의 푸른 주변광 위에 석등·한옥 창·신당·달빛 나무·도깨비불이 색 있는 빛을 내고, 이펙트는 어둠 속에서 빛나며 **빛 번짐(블룸)** 이 퍼집니다.
- 화면 효과: 폭발·필살기의 **충격파 왜곡**, 큰 타격의 **색수차**, 분할 색보정, 비네트(체력이 낮으면 맥동), 쓰러지면 흑백, 핏빛 달 색조, 필름 그레인.
- **해상도**: 모든 그림을 기기 화면 배율(최대 2.5배)로 다시 그려 선명하게. 그래픽 설정 **고화질 / 보통 / 저사양**, 느리면 자동으로 해상도를 낮춤. WebGL이 없는 기기는 같은 그림을 **Canvas2D**로 그립니다(빛 번짐·왜곡 없음).
- **아트**: 직업별 11프레임 자세(대기·깜빡임·걷기 4·공격 3단·피격), 요괴 18종 걷기/기 모으기/돌진 프레임, 달빛 윤곽광·그림자·발밑 음영 후처리, 나무 흔들림, 반딧불·단풍·늪 안개·꽃잎 같은 지역별 분위기 입자.

**타격감**
- 기본 공격: 검객은 먹 번짐 + 빛 초승달 베기(좌우 번갈아), 궁사는 빛 꼬리 화살, 무녀는 회전하는 부적탄과 분홍 폭발.
- 맞은 요괴: **넉백 스프링**, 흰 번쩍임, 찌그러짐, 불꽃 튐, 치명타는 별빛 + 짧은 **히트스톱**(화면 정지) + 줌 펀치. 쓰러진 요괴는 빛나는 테두리로 **용해**되고 먹물 자국·혼이 남습니다.
- 카메라: 트라우마 방식의 부드러운 흔들림(+미세 회전), 이동 방향으로 살짝 앞서 보기. 설정에서 흔들림 끄기 가능.
- 부적: 푸른 불꽃 유도탄, 하늘에서 내리꽂는 번개(그을음 자국), 얼음 파편과 서리 육각, 관통 빛창, 방울 음표, 금강 육각 방패.
- 필살기: 전체 화면 **컷인**(초상 + 붓글씨 기술명), 마법진·빛기둥·충격파. 레벨업 빛기둥, 보스 등장 **타이틀 카드**, 연타 **콤보 카운터**(50/200 연타에서 색이 바뀜).

**소리** (전부 실행 중에 합성, 별도 스레드에서 렌더링)
- 효과음 63종(v0.3에서 새 직업 공격음 7·필살기 7·전직 차임·먹물·로켓 등 17종 추가): 베기 2종, 타격(일반·치명·화살·마법), 번개·서리·방울·금강, 직업별 필살기, 폭발·내려찍기·포효, 레벨업·전설 획득·퀘스트 완료 등. 위치에 따라 좌우로 들리고 멀면 작아집니다. 잔향·압축기·필살기 때 배경음 덕킹.
- 배경음: 지역마다 다른 **12/8 국악 퓨전** 곡(평조/계면조 5음계, 장구·북·태고·징, 가야금·거문고, 대금·해금·태평소). 마을은 잔잔하게, 요괴가 몰리거나 맞으면 북이 들어오고, 보스 근처에서는 보스 곡으로 바뀝니다.

## 구조

```
src/shared/   서버·클라이언트 공용: 상수, 데이터(직업·요괴·지역·부적·장비·퀘스트), 절차적 월드 생성, 이동/충돌, 이진 프로토콜, A* 길찾기
src/server/   서버 권위 시뮬레이션(순수 TS, Node/브라우저 겸용): world(20Hz 틱), ai·bosses, combat, director(스폰), progress(보상·퀘스트),
              worldboss, actions(검증된 명령), session(관심 영역·스냅샷·상태 diff), server(채널·접속·저장), bots(AI 동료)
src/server/node/main.ts   Node 진입점: HTTP(정적 파일 + /api/info) + WebSocket(/ws) + 파일 저장
src/client/   브라우저: net(WebSocket / 페이지 내 오프라인 서버), game(보간·예측·히트스톱·이벤트 연출), ui(HUD·시트·조이스틱·컷인)
              render/  world(카메라·정렬·조명·오버레이) · gl(WebGL 아틀라스·합성·블룸·후처리) · paint(그리기 인터페이스·Canvas2D 대체) · fx(이펙트·입자) · anim(넉백·자세) · terrain · art/(캐릭터·요괴·소품·이펙트 텍스처·UI 아이콘)
              audio/   synth(DSP) · sfx(효과음 레시피) · kit(국악 타악기·현악기) · music(적응형 배경음) · engine(버스·잔향·공간화) · synth.worker(백그라운드 렌더)
tests/        vitest 규칙·통합 테스트, 헤드리스 플레이 시뮬레이터(밸런스)
scripts/      단일 파일 빌드, 밸런스 스윕, 부하 테스트, Playwright e2e
```

핵심 설계:
- **서버 권위형**: 클라이언트는 "조이스틱 방향(정수)"과 메뉴 명령만 보냅니다. 전투·드랍·경제는 전부 서버가 계산하고, 모든 명령을 검증합니다(속도 핵 방지 토큰 버킷, 채팅 필터, 요청 빈도 제한).
- **네트워크**: 20Hz 시뮬레이션, 10Hz 이진 스냅샷(개체당 9바이트, 관심 영역만), 이벤트/상태는 변경분만 JSON. 내 캐릭터는 클라이언트 예측 + 서버 재조정(같은 이동 코드를 양쪽에서 실행해 1/8px까지 일치), 다른 개체는 140ms 보간.
- **오프라인 모드도 같은 코드**: 브라우저 안에서 `GameServer`를 그대로 돌리고 가짜 연결로 붙습니다. 그래서 오프라인에서 되는 것은 온라인에서도 됩니다.

```bash
npm run balance     # 밸런스 스윕: 10직업 × 2시드 × 180분 플레이 시뮬레이션 → docs/balance-results.md (약 6분)
node scripts/classbench.ts   # 직업 벤치마크: 같은 레벨·장비로 무리 사냥/단일 대상/버티기 → docs/class-bench.md (몇 초)
npm run load        # 부하 테스트 (예: node scripts/loadtest.ts 160 60, node scripts/loadtest.ts ws 60 25)
npm run e2e         # 헤드리스 Chromium: 휴대폰 화면 3종 오프라인 플레이(WebGL 고화질·보통, Canvas2D 저사양) + 브라우저 2개 온라인 동시 접속
npm run dev         # 개발 서버. /dev/art.html 에서 모든 스프라이트·이펙트 텍스처를 한 장으로 볼 수 있음
```

서버 환경 변수: `PORT`(8080) · `CHANNELS`(2, 채널당 최대 80명) · `BOTS`(0, 온라인 채널에 AI 동료 추가) · `SEED`(월드 시드) · `DATA_DIR`(./server-data, 캐릭터 저장) · `WB_INTERVAL`(600초, 월드 보스 간격) · `WB_FIRST`(240초) · `NAME`(서버 이름) · `STATIC_DIR`(./dist)
