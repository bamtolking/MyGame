# 구현 상태 (v0.2.0-alpha.1)

## 구현되어 자동 테스트/헤드리스 브라우저로 동작 확인된 것

**서버·네트워크**
- Node.js 게임 서버: HTTP(클라이언트 정적 제공, `/api/info`, `/health`) + WebSocket `/ws`, 20Hz 고정 틱, 뒤처지면 최대 5틱 따라잡기.
- 채널(기본 2개, 채널당 80명), 접속 시 사람이 가장 많은 채널로 자동 배정, 같은 캐릭터 중복 접속 시 이전 연결 종료.
- 서버 권위: 이동 입력(정수 조이스틱 값)만 받고 속도 핵 방지(토큰 버킷), 모든 명령 검증(없는 아이템·잘못된 칸·마을 밖 강화·미발견 신당 이동 등 거부), 초당 요청 제한, 채팅/이름 필터, AI 사칭 이름 거부.
- 이진 스냅샷 10Hz(플레이어·요괴 각 9바이트, 관심 영역 760px, 최대 350마리), 이벤트/개인 상태는 변경분 JSON. 클라이언트 예측 + 서버 재조정(입력 번호 확인), 다른 개체 보간.
- 저장: 캐릭터별 JSON 파일(원자적 쓰기), 60초 주기 + 접속 종료 시 + 서버 종료(SIGINT/SIGTERM) 시. 오프라인은 localStorage(+백업본), 백업 코드 내보내기/불러오기.

**게임**
- 절차적 월드(192×192 타일): 마을(한옥·달빛 나무·NPC 4명·성벽과 관문), 도깨비 숲·물안개 늪·폐사찰·구미호 골짜기, 월드 보스 제단, 신당 5곳(발견 후 순간이동), 지역 경계는 길로만 통과(테스트로 검증).
- 직업 3종, 기본 공격 3종, 필살기 3종, 부적 8종×5단계(자동 시전·합성·구매·판매), 장비 3부위×5등급·랜덤 옵션·강화·자동 판매·가방 가득 참 처리, 전투력.
- 일반 요괴 12종(추격·돌진·원거리·자폭·도망), 정예(3%), 황금 도깨비, 지역 보스 4종(패턴 5~6개), 월드 보스 불가사리(예고 1분 → 토벌 최대 5분, 참가자 전원 보상, 피해 순위).
- 모든 강한 공격은 바닥 경고 후 판정, 시전자가 죽으면 취소, 탄막은 한 발동당 1회만 피격.
- 공유 처치 보상(근처 생존자 전원, 마을 안·쓰러진 사람 제외, 그룹 보너스 상한 +80%), 쓰러짐 15초 → 동료 곁 2초 부활 또는 가까운 발견 신당에서 부활, 무녀 필살기 즉시 부활.
- 이야기 퀘스트 19개 + 반복 현상금(250마리), 길 찾기 화살표(A* 경로), 지역 진입 배너·위험 경고, 레벨업/전설/보스/월드 보스 공지.
- AUTO 자동 사냥(서버의 AI가 이야기를 따라 사냥, 조이스틱을 움직이면 해제). AI 동료(오프라인 6명: 3명은 내 곁, 3명은 각 지역) — 부활시켜 주고 월드 보스에 모임.

**클라이언트**
- **WebGL 렌더러**(v0.2): 스프라이트 아틀라스(2048² 최대 4장) + 층별 일괄 그리기(장면·빛·발광), 색 조명 맵(½ 해상도), 블룸(¼·⅛ 해상도), 충격파 왜곡 최대 4개, 색수차, 분할 색보정·하이라이트 압축·비네트·흑백(쓰러짐)·화면 번쩍임·필름 그레인. WebGL2 → WebGL1 → **Canvas2D 대체 렌더러**(같은 그리기 인터페이스, 곱하기 조명) 순으로 자동 선택, WebGL 컨텍스트를 잃으면 새로 만듦.
- 그래픽 설정 고화질/보통/저사양(렌더 배율 2.5/1.75/1.25, 블룸 2단/1단/없음, 입자 수 상한), 느리면 자동 배율 하향. 기존 "저사양 모드" 설정은 저사양으로 이어받음.
- 절차적 아트(v0.2): 캐릭터 뼈대 자세 11프레임 × 3직업, NPC 4종, 요괴 18종(걷기·기 모으기·돌진 프레임, 불꽃 요괴는 발광), 소품 11종 × 변형, 한옥, 이펙트 텍스처 37종(초승달 베기·먹 번짐·부적·엽전·봉인 도장·팔괘 마법진 등). 화면 배율로 다시 그리고 윤곽광·음영 후처리. UI 아이콘도 같은 그림.
- 타격감(v0.2): 넉백 스프링·흰 번쩍임·찌그러짐, 공격 3단 자세, 치명타/정예·보스 처치 히트스톱(보간 시계를 늦췄다가 따라잡음), 트라우마 카메라 흔들림·미세 회전·줌 펀치, 용해 소멸(빛나는 테두리), 먹물 자국·그을음·균열 자국, 혼 흡수, 필살기 컷인, 콤보 카운터, 보스 타이틀 카드, 지역별 분위기 입자, 가려진 캐릭터 앞 나무·한옥 반투명.
- 지형: 색 지도 확대(부드러운 경계) + 상세 청크(최대 1.75배 해상도, 40개) 캐시, 핏빛 달 색조, 경고 장판(원/선, 룬·危 표시), 적 탄막, 전리품 흡수, 피해 숫자(겹치면 일반 숫자 생략), 이름표 겹침 방지.
- HUD(초상·체력·보호막·경험치·전투력·금화, 퀘스트 추적+화살표, 미니맵, 메뉴 배지, 필살기 원형 게이지 + 부적 칸 호, AUTO, 보스 체력바, 월드 보스 배너 + 제단 이동, 공지, 토스트, 채팅 로그), 시트(가방·장비 비교·대장간·부적·퀘스트/기록·지도/신당 이동·접속자·채팅·도감·설정).
- 떠 있는 조이스틱(터치/마우스), 키보드, NPC 탭, 세로/가로 레이아웃, 노치 안전 영역, 적응형 해상도(FPS가 낮으면 자동으로 렌더 배율 하향), 저사양 모드.
- **소리(v0.2)**: 모든 소리를 실행 중 합성(Web Worker에서 렌더, 안 되면 메인 스레드에서 조금씩). 효과음 46종(Karplus-Strong 현, 바이쿼드 필터, 징·종 배음, 잔향 임펄스), 위치 기반 좌우·거리 감쇠, 압축기, 필살기·레벨업 때 배경음 덕킹. 배경음은 지역별 12/8 국악 퓨전 6곡(평조/계면조, 장구·북·태고·징, 가야금·거문고, 대금·해금·태평소)이 강도 0~3단으로 겹겹이 바뀜(마을 0, 사냥 1, 요괴 떼·피격 2, 보스 3).

## 알려진 제한 / 미구현

- **실기기·사람 플레이 테스트를 하지 않았습니다.** 확인은 자동 테스트, AI 대리 플레이 밸런스 시뮬레이션, 헤드리스 Chromium(소프트웨어 렌더링)뿐입니다. 실제 iOS/Android의 터치감·발열·배터리·오디오는 미검증.
- 계정은 기기에 저장된 무작위 토큰(게스트)뿐입니다. 로그인·기기 이전(온라인)·비밀번호 없음. 토큰을 잃으면 온라인 캐릭터에 접근할 수 없습니다.
- 저장소는 JSON 파일(서버 1대용). 여러 서버에 나누려면 DB가 필요합니다. 채널은 한 프로세스 안에 있습니다.
- 파티/길드/거래/우편/랭킹/PvP/던전 없음. 친구 초대·귓속말 없음. 신고/차단 없음(단어 필터만).
- 결제·광고·치장 상점 없음(설계만: `docs/DESIGN.md`).
- 스토어용 네이티브 포장(Capacitor/TWA), 푸시 알림, 서비스 워커(오프라인 캐시) 없음. PWA manifest만 있음.
- 그림·소리는 전부 코드 생성(치비 스타일). 캐릭터 외형 커스터마이징 없음.
- **그래픽은 헤드리스 Chromium의 소프트웨어 WebGL(SwiftShader)로만 확인했습니다.** 실제 휴대폰 GPU에서의 FPS·발열·메모리(아틀라스 최대 64MB + 화면 버퍼)는 미검증. 고화질이 기본값이고 느리면 자동으로 배율을 낮춥니다.
- **소리는 사람이 스피커로 듣고 조율하지 않았습니다.** 자동 테스트는 모든 소리가 유한값·클리핑 없음·충분한 음량인지까지만 확인합니다.
- 제목·숫자 글꼴(Black Han Sans, 나눔붓글씨, 나눔명조)은 Google Fonts에서 받으므로 인터넷이 없으면 시스템 글꼴로 보입니다.
- 한국어만 지원.
- 레벨 30 이후 성장은 장비 파밍·강화·부적 합성뿐입니다(1차 콘텐츠 약 3시간).
- 네트워크 사용량 약 12KB/s. 델타 압축 미적용.
- 온라인에서 AI 동료는 기본 꺼짐(`BOTS` 환경 변수로 켤 수 있고, 켜면 이름표에 AI 표시).

## 다음 작업 제안

3. 게스트 → 구글/애플 로그인 연결, DB 저장, 신고/차단.
4. Capacitor 포장 + 스토어 등록 자료(스크린샷·영상), 치장 상점·시즌 패스.
