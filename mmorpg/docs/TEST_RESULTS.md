## 2. 밸런스 스윕 — `npm run balance` (3직업 × 2시드 × 180분, 약 2분)

전체 표: [`balance-results.md`](balance-results.md). 이야기를 따라가는 AI가 "사람" 역할(AI 동료 6명과 함께, 오프라인 설정과 동일).

| 지표 | 목표 | 결과(6회) |
|---|---|---|
| Lv10 도달 | 약 20분 | 20~35분 |
| Lv20 도달 | 약 80분 | 80~95분 |
| Lv30 도달 | 2.5~3시간 | 135~155분 |
| 이야기 19장 완료 | 3시간 안 | 6/6 완료 |
| 첫 지역 보스 | 10분 안팎 | 2.3~7.3분 |
| 3시간 동안 쓰러짐 | 적게 | 6~15회 (주원인: 성난 장승 돌진, 불가사리, 여우 무녀) |
| 불가사리 토벌 성공 | 대부분 성공 | 119/120 |
| 3시간 누적 금화 | 강화 +10 한 벌 ≈ 30만 | 49만~59만 |

튜닝 과정에서 고친 것(시뮬레이션이 찾아낸 문제):
- 경험치 곡선이 너무 완만해 Lv30이 1시간 만에 도달 → 곡선 조정(초반은 빠르게, Lv18 이후 가파르게).
- 반복 현상금이 60마리마다 끝나 금화·경험치의 대부분을 차지 → 250마리, 보상은 현재 레벨 필요 경험치의 10%.
- **도깨비 숲(Lv1~8) 바로 옆이 구미호 골짜기(Lv20~)라 초보 옆에 고레벨 요괴가 스폰되어 전멸** → 지역 경계에 벽을 세우고 길로만 통과, 스폰은 플레이어가 서 있는 지역만.
- 검객이 구미호의 부채꼴 탄막에 여러 발 동시에 맞아 한 번에 사망(3시간 27회) → 한 발동당 1회만 피격(→ 0~2회).
- 보스 근접 접촉 피해 과다, AI 동료 수만큼 보스 체력이 너무 빨리 증가 → 접촉 피해 ×0.6·간격 ×1.5, 인원당 +50%.
- 월드 보스 내려찍기를 사람 반응 속도로는 피할 수 없음 → 예고 1.1초→1.5초, 반경 230→210.

## 4. 브라우저 실기동 — `npm run e2e` : 47/47 통과

- 휴대폰 390×844, 작은 폰 360×640, 가로 844×390 각각: 타이틀 → 캐릭터 생성(궁사) → 마을(AI 동료 6명) → **실제 터치 드래그로 이동** → 30초 사냥(레벨업·처치·퀘스트 진행) → 가방·부적·퀘스트·지도·메뉴 시트 열기/닫기 → 채팅 왕복 → AUTO 자동 사냥 동작·조이스틱으로 해제 → 새로고침 → 이어하기로 같은 레벨 복원. **콘솔/페이지 오류 0.** FPS 46~52(적응형 해상도 적용, 소프트웨어 렌더 기준).
- 온라인: 빌드된 클라이언트를 실제 서버가 제공, 브라우저 2개가 각자 캐릭터를 만들어 접속 → 서로 보임(사람 2명), 채팅이 건너감, 한쪽 이동이 다른 쪽 화면에 25px 이내로 보임(보간 지연 포함), 오류 0.

## 5. 이 과정에서 테스트가 잡아낸 버그 (수정 완료)

- 마을 부활 지점 위에 한옥이 놓여 있음 → 한옥 이동.
- 신당 주변을 비우는 처리가 지역 경계 벽을 뚫음 → 같은 지역 타일만 비우도록.
- 접속 후 1초 동안 채팅이 "너무 빠릅니다"로 거절됨 → 쿨다운 초기값 수정.
- 마을 안에 서 있기만 해도 성벽 밖 처치 경험치를 받음 → 마을 안은 공유 보상 제외.
- 열린 시트가 사냥 중 초당 수 회 다시 그려져 닫기 버튼이 흔들리고 입력 중인 글자가 지워짐 → 시트별 관련 값만, 400ms 간격, 입력 중엔 갱신 안 함.
- HUD가 390px 폭에서 겹침, 클래스 카드에 CSS 클래스 충돌 → 레이아웃 재구성.
