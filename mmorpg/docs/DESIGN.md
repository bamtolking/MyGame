# 달빛 퇴마단 — 기획서 (알파 기준)

## 1. 왜 이 게임인가 — 대박 가설

"대박"은 아무도 보장할 수 없습니다. 이 기획은 아래의 **검증 가능한 가설**에 베팅합니다. 출시 전 테스트에서 하나라도 틀리면 방향을 바꿔야 합니다.

| 가설 | 근거 | 이 게임에서의 답 |
|---|---|---|
| 모바일에서 가장 강한 손맛은 "화면 가득 몰려오는 적을 쓸어버리는 것"이다 | 뱀파이어 서바이버류(서바이버라이크)가 PC·모바일에서 연달아 흥행한 장르 | 이동만 하면 공격·부적이 자동, 한 화면 수십~백 마리 요괴 |
| 사람들은 MMO의 "함께"를 원하지만, 경쟁·뺏기·파티 모집은 귀찮아한다 | 모바일 MMORPG 이탈의 큰 원인이 막보기·스틸·파티 스트레스 | **근처에서 잡히면 근처 모두가 보상**(전리품은 각자), 파티 버튼 없음, 곁에 서면 부활, 무녀 필살기는 동료 즉시 부활 |
| 한국 모바일 RPG 유저는 자동 사냥·전투력·강화를 기대한다 | 국내 상위 매출 MMORPG의 공통 문법 | AUTO(이야기를 따라가는 자동 사냥), 전투력 숫자, 실패 없는 +10 강화 |
| 한국 설화 요괴는 지금 세계적으로 통하는 소재다 | 도깨비·구미호·저승사자를 다룬 K-드라마/애니메이션의 해외 흥행 | 도깨비불·달걀귀신·물귀신·장승·이무기·구미호·불가사리, 갓·한복·홍살문·석등 |
| 텅 빈 서버는 MMO를 죽인다 | 신작 MMO의 초반 동시접속 부족 → 이탈 악순환 | 오프라인에서도 AI 동료 6명이 함께(이름표 **AI** 표시, 사람인 척하지 않음), 온라인은 사람이 가장 많은 채널로 자동 배정 |
| 짧은 세션이 모바일 리텐션의 핵심이다 | 출퇴근·대기 시간 플레이 | 현상금 1~2분, 핏빛 달 월드 보스 정해진 간격, 첫 보스까지 10분 안팎 |

## 2. 핵심 루프

```
[이동만 한다] → 요괴 떼 자동 처치 → 경험치·금화·장비·부적
     ↑                                   ↓
 새 지역(관문) ← 레벨·전투력 ← 장착 · 부적 합성(3장→1단계) · 대장간 강화
     ↑                                   ↓
 지역 보스 · 핏빛 달 불가사리(채널 전체) ← 동료와 함께하면 보상↑, 쓰러져도 서로 일으킴
```

- 1분 루프: 요괴 떼 → 필살기 충전 → 필살기로 한 번에 쓸기 → 금화·경험치가 날아와 박히는 연출
- 10분 루프: 현상금 완료, 이야기 퀘스트, 황금 도깨비, 요괴 떼 습격, 핏빛 달 월드 보스
- 1시간 루프: 부적 합성·강화로 새 지역 관문 통과, 지역 보스 토벌
- 3시간(1차 콘텐츠 끝): Lv30, 구미호 토벌, 이야기 19장 완료 → 현상금·월드 보스·장비 파밍

## 3. 시스템 요약

- **직업 3종**: 검객(근접 부채꼴 베기, 흡혈 2.5%, 받는 피해 감소 14%, 필살기 회오리 베기) / 궁사(원거리 단일, 치명 14%, 화살비) / 무녀(폭발 부적, 치유 +30%, 대굿 = 광역 피해 + 치유 + 즉시 부활)
- **부적 8종 × 5단계**: 자동 발동. 칸은 Lv1/3/7/12에 해금. 같은 부적 3장 → 1단계 합성. 부적상에서 금화(무작위) 또는 달빛 조각(지정)으로 구매
- **장비**: 무기·갑옷·노리개, 5등급(일반→전설), 등급 수만큼 랜덤 옵션 11종, 45개 연속 영웅 미만이면 영웅 확정(보정), +10까지 실패 없는 강화(금화 소모 = 경제 싱크), 가방이 차면 가장 싼 것 자동 판매
- **지역**: 원형 대륙 중앙의 달빛 마을(안전) + 도깨비 숲 고리 + 늪/폐사찰/골짜기 부채꼴. 지역 경계는 절벽·숲·폐허 벽이고 **길(관문)로만** 넘어감 → 초보가 실수로 고레벨 지역에 들어가지 않음. 들어가면 권장 레벨 경고
- **스폰 감독(director)**: 플레이어마다 주변 밀도를 유지, 근처 동료 수만큼 요괴 떼가 커짐, 80~120초마다 포위 습격, 화면 밖에서만 등장, 플레이어가 있는 지역의 요괴만 등장
- **보스**: 모든 강한 공격은 바닥 경고(원/선)가 먼저 차오르고 그 순간 안에 있어야만 맞음. 부채꼴·원형 탄막은 한 발동당 한 번만 피격. 지역 보스는 근처 인원에 따라 체력이 늘고(1명당 +50%), 월드 보스는 참가자 전투력으로 체력을 정하고 피해는 최대 체력 비율(저레벨도 참여 가능)
- **소셜**: 채팅(필터), 감정표현 8종 말풍선, 접속자 목록(AI 표시), 레벨10 단위·전설 획득·보스 토벌 채널 공지

## 6. 위험 요소 (정직하게)

- **밸런스는 AI 대리 플레이 기준**입니다. 실제 사람은 더 잘 피하거나, 더 헤맵니다. 1단계 사람 테스트가 필수.
- **데이터 사용량**: 클라이언트당 약 12KB/s(시간당 약 45MB). 모바일 데이터 사용자에게 부담일 수 있음 → 델타 압축·원거리 개체 저빈도 전송으로 절반 이하로 줄일 여지.
- **서버 비용**: Node 한 프로세스가 약 160명(채널 2개)을 틱 p99 15ms로 처리(부하 테스트). 수만 명 규모는 다중 프로세스·로비·DB가 필요.
- **콘텐츠 소모**: 1차 콘텐츠는 약 3시간. 시즌 업데이트 속도가 리텐션을 좌우.
- **그래픽·소리**: v0.2에서 WebGL 조명·빛 번짐·타격감 연출과 국악 퓨전 적응형 음악을 넣었지만, 그림은 여전히 코드로 그린 치비 스타일이고 소리도 합성음입니다. 스토어 첫인상(아이콘·스크린샷·영상)을 위해 전문 일러스트(키 아트·캐릭터 원화)와 사운드 디자이너의 다듬기가 필요하고, 실기기 GPU에서 발열·배터리를 먼저 확인해야 합니다.
- **스토어 정책**: 채팅이 있으므로 신고/차단, 연령 등급, 개인정보 처리방침 필요.
