# 와르르! 철거왕: 한 발의 기적 (웹 베타)

한 발의 커터볼로 밧줄을 끊고, 추를 떨어뜨리고, 시소를 돌리고, 공을 굴려
구조물을 무너뜨리는 **물리 퍼즐** 게임입니다. 세로 화면 · 모바일 우선 · 20개 스테이지.
서버·회원가입·결제·광고 없이 브라우저(휴대폰 포함)에서 그대로 실행됩니다.

> 한 문장: **한 발의 선택이 눈에 보이는 연쇄 반응을 만들고, 실패하면 다른 지점을 노려보고 싶으며, 성공하면 왜 성공했는지 이해되는 게임.**

작업명이며 기존 게임의 캐릭터·명칭·이미지·코드를 복제하지 않은 독자적 구현입니다.

## 바로 해보기 (비개발자용)

- **가장 쉬운 방법**: `play/index.html` 파일 하나가 게임 전체입니다. 휴대폰이나 PC의 브라우저(Chrome/Safari)로 이 파일을 열면 바로 실행됩니다. (메신저·메일로 파일을 보내 휴대폰에서 열어도 됩니다.)
- 인터넷 연결이나 설치가 필요 없습니다.

## 필요한 환경 (개발용)

- Node.js 22 이상 (개발 서버·빌드·테스트용). 게임 자체는 Node가 필요 없습니다.
- 최신 브라우저(모바일 Chrome/Safari, PC Chrome/Edge/Firefox).

## 설치와 실행

```bash
npm install          # 의존성 설치 (matter-js 등)
npm run dev          # 개발 서버 → 터미널에 표시되는 http://localhost:5174 를 브라우저로 열기
npm run typecheck    # 타입 검사
npm test             # 규칙·물리·저장·스테이지 검증 테스트 (Vitest, 약 1초)
npm run validate     # 20개 스테이지 전체를 실제 물리로 재생 검증 → docs/LEVEL_VALIDATION.md 갱신
npm run build        # 타입검사 + 정적 빌드(dist/) + 단일 파일(play/index.html) 생성
npm run e2e          # 헤드리스 Chromium으로 휴대폰 3종 뷰포트 실기동 (스크린샷 e2e-out/)
```

### PC에서 실행

`npm run dev` 실행 후 터미널에 나오는 **http://localhost:5174** 를 PC 브라우저로 엽니다.
개발 서버를 끄면 이 주소는 열리지 않습니다.

### 휴대폰에서 접속

이 저장소가 **원격/클라우드 환경**에서 실행 중이라면, 그 환경의 `localhost`는 휴대폰에서 그대로 열리지 않습니다. 다음 중 하나를 사용하세요.

1. **파일 전송(가장 확실)**: `npm run build` 후 생긴 `play/index.html` 하나를 휴대폰으로 보내 브라우저로 엽니다. 서버가 필요 없습니다.
2. **같은 Wi-Fi(개발 서버가 사용자 PC일 때)**: `npm run dev`가 표시하는 `http://<PC의 LAN IP>:5174` 주소를 같은 Wi-Fi의 휴대폰 브라우저로 엽니다. PC 방화벽에서 5174 포트 허용이 필요할 수 있습니다.

공개 배포(외부 인터넷 게시)는 하지 않았습니다. 필요하면 별도 승인 후 진행하세요.

## 조작

- **발사**: 화면 왼쪽 아래 **발사대**를 손가락(또는 마우스)으로 누른 채 **반대 방향으로 당겼다가 놓습니다.** 당긴 방향의 반대로 커터볼이 날아갑니다. 점선은 초기 궤적 미리보기입니다.
- 아주 짧게 당기거나, 발사대에서 손을 떼지 않고 화면 밖으로 나가면 **발사가 취소**됩니다. 상단·하단 버튼 터치는 발사로 처리되지 않습니다.
- **다시 시작**(하단 왼쪽): 구조물·밧줄·탄 수·목표가 처음 상태로 완전히 복원됩니다.
- **힌트**(하단 오른쪽): 1단계는 핵심 장치 강조, 2단계는 대략적 발사 방향을 보여줍니다. 무료입니다.
- **일시정지**(상단 오른쪽 ⏸): 물리·판정·연출·시간이 모두 멈춥니다. 화면을 벗어나면 자동 정지합니다.
- **≡**(상단 왼쪽): 스테이지 목록으로.

## 목표와 규칙

- **철거(넘어뜨리기)**: 노란 줄무늬 테두리에 "철거" 표시가 있는 블록을 충분히(약 50° 이상) 쓰러뜨립니다.
- **떨어뜨리기**: 목표를 화면에 표시된 초록 낙하 구역(구덩이)에 떨어뜨립니다.
- **보호상자**: 파란 안전 구역이 표시된 상자입니다. 커터볼로 직접 맞히거나 상자 중심이 안전 구역을 벗어나면 실패합니다.
- 별은 최대 3개입니다. 목표를 모두 달성하고 보호물을 지키면 별을 얻고, 더 적은 발사로 해결할수록 높은 평가를 받습니다.

## 구조

```
src/data/       스테이지·물리·재질 데이터 (밸런스는 여기만 수정)
  physics.ts      고정 시간 스텝·중력·발사·판정 기준값
  materials.ts    재질별 밀도·마찰·반발·구름 저항
  levels/         스테이지 20개(L01~L20)와 작성 도우미(util.ts)
  solutions.ts    각 스테이지의 검증된 해결 입력(각도·정규화 세기)
src/sim/        시뮬레이션(순수 TS, DOM 없음)
  world.ts        matter-js 물리 월드 하나(블록·공·경사면·밧줄·힌지 생성)
  session.ts      상태 기계·발사·밧줄 스윕 절단·목표/보호 판정·안정 감지·결과
  launcher.ts     당김↔발사 입력, 조준 미리보기(엔진과 같은 적분)
  judge.ts        넘어뜨리기/떨어뜨리기/보호 이탈 판정(순수 함수)
  geometry.ts     선분 거리·교차 등 기하 유틸
  lint.ts         스테이지 데이터 규칙 검사
src/render/     Canvas 2D 렌더러·절차적 그래픽·파티클(물리에 관여하지 않음)
src/platform/   로컬 저장(검증·백업), WebAudio 절차적 효과음
src/ui/         화면 전환·게임 루프·터치 입력·HUD·결과·튜토리얼
tests/          Vitest: 물리 안정성·세션 규칙·저장·스테이지 재생
scripts/        해법 격자 탐색(solve)·상태 추적(describe)·전체 검증(validate)·단일파일 빌드·Chromium e2e
docs/           검증 기록·테스트 결과·개발 노트
```

- **물리 월드는 matter-js 하나만** 사용합니다. 같은 물체를 두 엔진으로 중복 계산하지 않습니다.
- 고정 시간 스텝(1/60초)으로 시뮬레이션합니다. 화면 갱신 속도와 무관하게 결과가 일정합니다.
- 판정용 물리와 시각 효과용 난수를 분리했습니다. 시각 효과가 물체의 초기 위치·결과를 바꾸지 않습니다.

## 스테이지 데이터 위치와 수정

- 스테이지: `src/data/levels/L01.ts` ~ `L20.ts`. 좌표는 540×960 설계 좌표계(바닥 윗면 y=900)입니다.
- 스테이지를 수정하면 `version`을 올리고 `src/data/solutions.ts`의 해당 해법도 다시 확인하세요(`npm run validate`).
- 물리·판정 기준값: `src/data/physics.ts`, 재질 수치: `src/data/materials.ts`.

## 저장과 초기화

- 저장 정책: **웨이브/물리 진행 중 상태는 저장하지 않습니다.** 게임을 닫았다가 돌아오면 현재 스테이지를 처음부터 다시 시작합니다. 스테이지별 최고 별·최소 사용 탄 수·해금 진행도·설정만 브라우저에 저장됩니다.
- 저장 초기화: 타이틀 또는 설정 화면의 **저장 초기화** 버튼. 사생활 보호 모드 등 저장이 불가능한 환경에서는 기록이 유지되지 않으며, 그 사실을 화면에 안내합니다.

## 현재 상태 요약

- 20개 스테이지 전부 **실제 물리 재생으로 검증**되었습니다(`npm run validate` → 20/20). 검증 내역은 `docs/LEVEL_VALIDATION.md`.
- 자동 테스트(로직·물리·저장)와 헤드리스 Chromium 모바일 뷰포트 실기동을 통과했습니다. 자세한 내용과 한계는 `docs/TEST_REPORT.md`, `docs/DEVELOPMENT_NOTES.md`를 보세요.
- **실제 휴대폰 기기 테스트와 사람 플레이 테스트는 수행하지 않았습니다.**
