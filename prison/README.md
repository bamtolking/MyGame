# 감옥 설계자 (첫 베타)

프리즌 아키텍트 스타일의 **교도소 건설·경영 시뮬레이션**입니다. 빈 부지에 벽을 세우고, 방(감방·식당·주방·운동장·샤워실·의무실·휴게실·작업장·독방·사무실)을 지정하고, 직원(교도관·요리사·작업반·의사)을 고용해 수감자를 받아 운영합니다. 수감자의 7가지 욕구를 채우지 못하면 싸움·탈주·폭동이 일어납니다.
싱글 플레이, 서버·회원가입·결제·광고 없음. 브라우저(휴대폰 포함)에서 실행되는 HTML5 게임입니다.

> 한 문장: **벽 한 칸, 문 하나의 위치가 탈주를 결정하는 터치 기반 교도소 경영.**

## 바로 실행하기 (비개발자용)

1. **가장 쉬운 방법**: `play/index.html` 파일 하나가 게임 전체입니다. 휴대폰이나 PC 브라우저(Chrome/Safari)로 그 파일을 열면 바로 실행됩니다.
2. **개발 서버(같은 Wi-Fi의 휴대폰에서 테스트)**: Node.js 22 설치 후
   ```bash
   cd prison
   npm install
   npm run dev        # 터미널에 표시되는 http://<PC의 IP>:5173 주소를 휴대폰 브라우저로 열기
   ```
3. **빌드**: `npm run build` → `dist/`(정적 사이트)와 `play/index.html`(단일 파일) 생성.

세로 화면 우선이며 가로 화면에서는 도구 모음이 오른쪽으로 이동합니다.

## 시작 방법 두 가지

- **새 게임 — 빈 부지**: 아무것도 없는 땅에서 시작. 🎯 목표(7개 장)가 순서를 안내합니다. 작업반 2명이 이미 고용되어 있습니다.
- **새 게임 — 빠른 시작**: 대기실·주방·식당·감방 6개·샤워실·운동장과 교도관 2, 요리사 1이 준비된 작은 교도소. 08:00에 첫 수감자 버스가 도착합니다.

## 조작

- **선택 도구(👆)**: 탭으로 수감자·직원·방·물건 정보 보기, 한 손가락 드래그로 화면 이동, 두 손가락으로 확대·축소. PC에서는 마우스 휠 확대.
- **건설(🧱)**: 벽·울타리·문·감옥문·철거. 드래그한 사각형에 적용되며, 벽·울타리는 3×3 이상이면 **테두리만** 그립니다. 비용은 계획 즉시 차감되고 작업반이 와서 짓습니다. 계획 취소는 전액, 철거는 50% 환불.
- **구역(🟦)**: 방 종류를 칠합니다(즉시·무료). 벽으로 나뉜 연결된 칸이 한 방이 됩니다.
- **물건(🛏)**: 침대·변기·벤치·식탁·배식대·조리대·냉장고·샤워기·의료침대·TV·책장·작업대·책상·역기. 탭은 1개, 드래그는 범위 채우기.
- **직원(👮)**: 고용 버튼, 직원 관리 시트(해고), 진압대 요청($1,500, 24시간).
- **관리(📋)**: 수감 접수(자동/수동, 보안 등급), 일과표(24시간 편집), 목표, 보고서(재정·사건·위험 요약), 비상 봉쇄, 기록.
- **상단**: 자금 · 수감자/수용 · 날짜 시각 · ⏸ · 속도(1×→2×→4× 순환) · 🎯 목표 · ≡ 설정. 화면 오른쪽 🔒는 보안 보기(외부와 이어진 취약 구역을 빨갛게 표시), 🗺는 전체 보기.

## 핵심 규칙

- **방 유효 조건**: 최소 크기 + 필수 물건 + **밀폐**(외부와 연결되지 않음). 방 이름 앞 ⚠를 탭하면 부족한 것을 알려줍니다.
- **보안**: 벽·울타리는 모두 막습니다. 일반 문은 누구나(탈주자 포함) 통과, **감옥문**은 직원과 질서 있는 이동만 통과. 빨간(취약) 칸에 서 있는 수감자는 탈주를 시도할 수 있고, 교도관이 추격해 잡으면 6시간 징벌(독방 또는 감방).
- **욕구**: 배고픔·피로·위생·운동·여가·자유·불안 → 기분 → 분노. 분노가 높으면 싸움/탈주, 분노한 수감자가 25% 이상이면 폭동. 비상 봉쇄와 진압대로 대응.
- **경제**: 자정마다 수감자 1명당 보조금(최소 $110·일반 $160·최고 $240), 직원 급여(교도관 90·요리사 60·작업반 45·의사 130/일), 식재료 $3/인분, 작업장 노동 $14/시간·명, 사무실 보조금 +10%. 탈주 벌금 $1,500·평판 -8, 사망 $2,500·-10. 자금 -$8,000 이하 파산, 평판 0 해임.
- **목표 7장**: 기초 공사 → 첫 수감자 → 감방동 → 질서(최고 보안 해금) → 복지와 노동 → 대형 교도소 → 명예 교도소장(엔딩, 계속 플레이 가능).

## 구조

```
src/data/      수치 데이터(방·물건·구조물·직원·일과·경제·목표·이름) — 밸런스는 여기만 수정
src/sim/       시뮬레이션(순수 TS, DOM 없음): grid(보안 분석·방 인식·A*), build(건설 작업), prisoner(욕구·행동·사고),
               staff(교도관·요리사·작업반·의사), incidents(싸움·제압·폭동), economy(접수·출소·정산), objectives, engine(고정 스텝·행동)
src/render/    Canvas 2D 렌더러(카메라, 절차적 물건/인물 그리기, 보안 오버레이, 밤, 화면 밖 사건 표시)
src/ui/        입력(터치 드래그·핀치), 도구 모음, 시트/정보 카드, App(HUD·루프·저장)
src/platform/  저장(검증·백업·내보내기), WebAudio 절차적 효과음
tests/         Vitest: 규칙(보안·방·길찾기·건설·수감자), 시뮬레이션, 봇(빈 부지에서 자동 건설) 밸런스
scripts/       단일 파일 빌드, Playwright(Chromium) 휴대폰 뷰포트 e2e
docs/          설계, 구현 상태, 테스트 결과
```

- 고정 시간 스텝(1/20s). 배속은 스텝 횟수만 바꾸므로 결과가 같습니다. 판정용 난수(sfc32, 상태 저장)로 같은 시드 + 같은 입력 = 같은 결과(테스트로 검증).
- 게임 시간: 1시간 = 15초(1×), 하루 6분. 4×에서 하루 1.5분.
- 저장: 게임 시간 1시간마다·일시정지·시트 열기·앱 전환 시 전체 상태를 localStorage에 기록하고 읽어서 검증. 내보내기/불러오기 문자열 지원.

## 명령

```bash
npm test          # 규칙 + 시뮬레이션 + 봇 밸런스 (약 10초)
npm run build     # 타입검사 + 빌드 + play/index.html
npm run e2e       # 헤드리스 Chromium으로 휴대폰 뷰포트 3종 실기동 테스트 (스크린샷 e2e-out/)
```

자세한 설계는 `docs/DESIGN.md`, 구현/미구현 목록은 `docs/STATUS.md`, 테스트 결과는 `docs/TEST_RESULTS.md`를 보세요.
