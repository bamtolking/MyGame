# 구현 상태 (v0.2.0-beta)

## 구현되어 실제 작동 확인된 것 (자동 테스트 + 헤드리스 Chromium 실기동)
- 44×44 격자, 도로·출입구, 벽/울타리/일반 문/감옥문, 철거·취소·환불, 드래그 사각형(벽·울타리는 테두리), 작업반이 실제로 걸어가서 짓는 건설, 접근 불가 작업 표시(⛔)와 갇힌 직원 구출.
- 방 11종(감방·대기실·식당·주방·운동장·샤워실·의무실·휴게실·작업장·독방·사무실)과 물건 14종. 방 인식(연결 칸), 유효성(크기·필수 물건·밀폐) 검사와 이유 표시, 보안 보기 오버레이.
- 수감자: 3등급(최소·일반·최고), 7가지 욕구, 기분·분노, 성향(폭력·탈주), 일과표 기반 행동(수면·식사·샤워·운동·휴게·노동·감금), 침대 배정, 대기실 대체, 형기·출소, 탈주 시도·추격·제압·징벌(독방/감방), 싸움·부상·사망, 폭동과 진압.
- 직원 4종(교도관·요리사·작업반·의사) + 진압대(임시), 고용·해고, 급여, 순찰·조리(식사 재고)·치료.
- 경제: 보조금·급여·식재료·건설·노동·벌금·보상, 자정 정산 로그, 보고서(오늘 예상·어제·통계·위험 요약), 파산·해임 종료.
- 목표 7장(조건 진행도, 보상, 최고 보안 해금, 엔딩 후 계속 플레이), 상황 힌트, 비상 봉쇄, 진압대 요청.
- 터치 입력: 탭/드래그/두 손가락 핀치, 마우스 휠. 정보 카드(수감자 욕구 막대·따라가기, 직원 해고, 방 문제, 작업 취소, 철거). 시트 7종(목표·일과표·직원·수감·보고서·설정·도움말·기록·내보내기).
- 렌더링: 절차적 물건·인물, 상태 아이콘, 밤낮, 싸움 표시, 화면 밖 사건 화살표, 방 이름/경고, 계획 유령·진행 막대. 휴대폰 3종 뷰포트에서 60fps.
- 저장: 매 게임 시간·일시정지·시트·백그라운드 시 전체 스냅샷, 읽기 검증·백업, 내보내기/불러오기, 이어하기(일차·인원·자금 표시), 기록(최장 일수 등).
- 효과음(WebAudio 절차적), 설정(볼륨·격자·효과 줄이기·힌트·미니맵·진동·성적표 카드·튜토리얼 재시작).

## 베타 2에서 추가된 것
- **프리셋 10종**(감방 블록 6실·대기실·주방+식당·샤워실·운동장·의무실·휴게실·작업장·독방 3실·사무실): 손가락을 따라오는 미리보기(겹침 빨강·비용), 한 번에 배치. 드래그 건설 중 칸 수·비용·불가 칸 표시. ↶ 되돌리기(15초).
- **7단계 튜토리얼**(빈 부지): 조건 충족 시 자동 진행, 바로가기 버튼, 건너뛰기. 완료 여부는 브라우저에 저장.
- **난이도 3종**, **정책 3종**(식사 품질·징벌 시간·감방 수색), **수감자 성향 5종**(정보 카드·명단 표시), **터널 탈주 + 감방 수색**(수동 6시간 쿨다운·정기 수색·순찰 발견·밤 힌트), **돌발 사건 10종**(선택지 모달, 조건부·최근 3개 제외), **일일 성적표 S~D**(카드·보고서 7일·평판 반영), **업적 14종**, **감방 품질**(6칸 이상·책장).
- UI: 미니맵(탭 이동), 아침까지 빨리 감기(사건 시 자동 정지), 카테고리 배지(작업 수·인력 부족·사건), 선택한 방 윤곽, 실내 바닥 패턴·벽 윤곽·걷기 흔들림·욕구 말풍선, 진동 알림, 시트 슬라이드 애니메이션, 타이틀 난이도 선택·업적.
- 저장 버전 2 (버전 1 저장은 자동 이행).

## 알려진 제한 / 미구현
- **실기기·사람 플레이 테스트 미수행**: 검증은 자동 테스트와 헤드리스 Chromium(390×844, 360×640, 844×390)뿐입니다. 실제 iOS Safari/Android Chrome의 터치·오디오·성능은 미검증입니다.
- 방이 완전히 닫힌 뒤 그 안에 물건을 계획하면 작업반이 접근할 수 없습니다(⛔ 표시). 문을 먼저 지어야 합니다. 벽에 갇힌 **직원**은 입구로 구출되지만, 갇힌 **수감자**는 그 자리에 머뭅니다.
- 배관·전기·터널 탈주·밀수품·면회·교육·연구(관료) 시스템은 없습니다. 감옥문은 교도관이 직접 열어주는 방식이 아니라 "질서 있는 이동만 통과" 규칙으로 단순화했습니다.
- 물건은 모두 통과 가능(1칸, 서서 사용). 방 안 가구 배치가 동선을 막지 않습니다.
- 지도는 1개 크기(44×44), 확장 구매 없음. 무한 모드·난이도 선택 없음(7장 완료 후 계속 플레이는 가능).
- 시트를 열면 시뮬레이션이 멈춥니다(설계 선택). 정보 카드는 멈추지 않습니다.
- 봇 기준 밸런스: 빈 부지에서 8일 내 4장 도달, 10일차 수감자 ~29명·기분 63~69. 6·7장(수감자 30/45, 감방 40)은 사람 플레이로 검증하지 않았습니다. 사건 선택지·정책 조합의 체감 난이도도 봇(항상 1번 선택)으로만 확인했습니다.
- 터널은 발견되기 전까지 보이지 않습니다(설계 의도). 갇힌 **수감자**는 여전히 그 자리에 머뭅니다.
- PWA manifest/service worker 없음. 스토어 등록·게시 안 함. Capacitor 등으로 감쌀 수 있도록 플랫폼 코드는 `src/platform/`에 분리.
