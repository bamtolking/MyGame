# 가방이 무기다: 팩 앤 블래스트 (웹 베타)

제한된 5×5 가방에 장비를 배치하고, 상하좌우 인접 효과로 조합을 만든 뒤, 장비 구성대로 진행되는 짧은 자동 전투로 고철 괴물을 상대하는 모바일 우선 웹 게임입니다.
12개 전투 구간(4·8 정예, 12 보스), 장비 12종, 적 5종 + 보스 1종. 로그인·서버·결제·광고 없음. 진행 상황은 브라우저에 자동 저장됩니다.

> 한 문장: **가방 배치를 바꾸면 전투가 실제로 달라지고, 새 장비를 얻으면 다시 정리하고 싶어지는 게임.**

## 1. 필요한 실행 환경

- **Node.js 22** (LTS). https://nodejs.org 에서 설치. 설치 확인: 터미널에서 `node --version`
- PC와 휴대폰이 **같은 Wi-Fi**에 있어야 휴대폰으로 접속할 수 있습니다.
- 브라우저: Chrome / Safari 최신 버전 (모바일 포함).

## 2. 의존성 설치 (처음 한 번)

```bash
npm install
```

(`package-lock.json`에 버전이 고정되어 있습니다. 정확히 같은 버전으로 설치하려면 `npm ci`.)

## 3. 개발 서버 실행 (PC + 휴대폰)

```bash
npm run dev
```

터미널에 다음과 같이 표시됩니다.

```
  ➜  Local:   http://localhost:5173/
  ➜  Network: http://192.168.x.x:5173/
```

- **PC에서 확인**: 브라우저로 `http://localhost:5173/packblast/` 를 엽니다. (F12 → 기기 도구 모음으로 휴대폰 크기 확인 가능)
- **휴대폰에서 확인**: 휴대폰 브라우저에서 `http://<Network에 표시된 IP>:5173/packblast/` 를 엽니다. 예: `http://192.168.0.12:5173/packblast/`
  - 휴대폰에서는 PC의 `localhost` 주소가 열리지 않습니다. 반드시 Network 줄의 IP를 쓰세요.
  - `npm run dev`는 이미 `--host` 옵션이 켜져 있어 같은 네트워크에서 접속할 수 있습니다.
  - 접속이 안 되면: (1) 같은 Wi-Fi인지, (2) PC 방화벽이 5173 포트를 막는지(Windows는 처음 실행 시 "네트워크 액세스 허용" 대화상자에서 허용), (3) 공용 Wi-Fi의 기기 간 격리 기능이 켜져 있지 않은지 확인하세요.
  - **개발 서버(터미널)를 종료하면 휴대폰에서 더 이상 접속할 수 없습니다.**
- 외부(다른 네트워크)에서 접속하려면 별도 배포가 필요합니다. 이 저장소는 공개 배포를 하지 않았습니다.

## 4. 서버 없이 파일 하나로 실행

`npm run build` 후 생성되는 `play/packblast.html` 파일 하나가 게임 전체입니다. 이 파일을 휴대폰으로 보내(메신저·메일·클라우드) 브라우저로 열면 서버 없이 실행됩니다.
(일부 브라우저는 파일 직접 열기에서 저장소를 제한할 수 있습니다. 그 경우 개발 서버 방식을 쓰세요.)

## 5. 테스트·검사·빌드 명령

```bash
npm run typecheck        # TypeScript 타입 검사
npm run test:packblast   # 팩 앤 블래스트 로직·전투·경제·저장 테스트 + 밸런스 실험 (약 10초)
npm run balance:packblast  # 밸런스 실험만 → docs/packblast-balance.md 갱신
npm run e2e:packblast    # 개발 서버를 켠 상태에서, 헤드리스 Chromium으로 휴대폰 뷰포트 3종 실기동 (스크린샷 e2e-out/packblast/)
npm run build            # 타입검사 + 두 게임 빌드(dist/) + 단일 파일(play/index.html, play/packblast.html)
npm test                 # 두 게임의 모든 테스트 (기존 게임 밸런스 스윕 포함, 2~3분)
```

## 6. 저장 초기화

- 게임 안: 타이틀 → **설정** → **저장 초기화** (두 번 확인).
- 수동: 브라우저 개발자 도구 → Application → Local Storage → `packblast_save_v1` 삭제.

## 7. 주요 조작 (터치만으로 가능)

- **장비 놓기**: 작업대(아래 칸)의 장비를 누름 → 가방 칸을 누름(초록/빨강 미리보기) → **같은 자리를 다시 누르거나 "배치 확정"**. 드래그해서 놓아도 됩니다.
- **회전**: 장비 선택 중 **↻ 회전**. 90도씩, 모양은 기준 칸에서 정규화되어 어긋나지 않습니다.
- **가방 속 장비 누르기**: 이동 · 회전 · 합성 · 작업대로 · 분해 메뉴와 **연결 상태**(노란 ✓ / 회색 ×와 이유)가 표시됩니다.
- **합성**: 같은 종류·같은 등급 2개 → 한 등급 위 (최대 3등급, 모양 유지). 가방과 작업대 사이에서도 가능.
- **회복**: 정비마다 1회, 부품 6으로 최대 체력의 20%.
- **가방 닫고 출발**: 공격 무기가 최소 1개 가방에 있어야 합니다. 작업대에 장비가 남아 있으면 분해 환급액을 보여주고 확인합니다(취소하면 정리 화면으로).
- **전투**: 자동 진행. **⚡ 긴급 충격파**(전투마다 1회: 밀어내기 + 짧은 보호), **1×/2×** 배속, **⏸** 일시정지. 화면을 벗어나면 자동 일시정지.
- **보상**: 후보 3개 중 1개(합성 가능 · 지원 대상 표시). 새로고침은 보상마다 1회, 부품 3.
- **이어하기**: 정리·보상 단계의 확정 행동은 즉시 저장. **전투 중 나가면 그 전투 시작 시점부터 재도전**합니다.

## 8. 인접 효과 요약

| 지원 장비 | 대상 태그 | 효과 |
|---|---|---|
| 배터리 | 기계 (기관총·레이저·드론) | 공격 간격 -18/26/34%. 과열 무기는 열도 빨리 쌓임 |
| 냉각기 | 과열 (기관총·레이저) | 열 방출 +60/95/135% |
| 탄약상자 | 탄도 (기관총·산탄총·폭탄) | 4/3/2발마다 추가 탄 (추가 탄은 다시 발동하지 않음) |
| 공명 렌즈 | 에너지 (레이저·드론) | 적중 시 근처 다른 적 1명에게 40/55/70% 연쇄 (원본 공격당 1회) |

같은 종류 지원이 여러 개 붙으면 가장 강한 하나만, 다른 종류는 함께 적용됩니다. 대각선은 인접이 아닙니다.

# 대박수비대: 합성 대폭주 (첫 베타)

랜덤 소환 · 합성 · 배치 타워 디펜스. 도깨비 야시장의 보물 창고를 40웨이브 동안 지킵니다.
싱글 플레이, 서버·회원가입·결제·광고 없음. 브라우저(휴대폰 포함)에서 실행되는 HTML5 게임입니다.

> 한 문장: **뽑힌 것은 운이지만, 무엇을 남기고 어디에 놓고 언제 합칠지는 실력인 디펜스.**

## 바로 실행하기 (비개발자용)

1. **가장 쉬운 방법**: `play/index.html` 파일 하나가 게임 전체입니다. 휴대폰이나 PC 브라우저(Chrome/Safari)로 그 파일을 열면 바로 실행됩니다.
   - 휴대폰으로 보내려면 파일을 메신저·메일로 전송한 뒤 브라우저로 열거나, 아래 개발 서버를 이용하세요.
2. **개발 서버(같은 Wi-Fi의 휴대폰에서 테스트)**: Node.js 22 설치 후
   ```bash
   npm install
   npm run dev        # 터미널에 표시되는 http://<PC의 IP>:5173 주소를 휴대폰 브라우저로 열기
   ```
3. **빌드**: `npm run build` → `dist/`(정적 사이트)와 `play/index.html`(단일 파일) 생성.

세로 화면 우선이며 가로 화면에서는 레이아웃이 재배치됩니다. 첫 진입 → 3·2·1 카운트다운 → 즉시 소환·전투.

## 조작

- **소환**: 하단 소환 버튼. 결과는 대기석(3칸)에 들어가고 자동으로 선택됩니다.
- **배치/이동**: 유닛 탭 → 빈 자리(초록) 탭. 유닛이 있는 자리를 탭하면 **자리 교환**. 드래그도 가능. 재배치 무료, 같은 유닛 연속 이동은 1.5초 대기.
- **합성**: 합성 버튼 → 등급 탭에서 3개 선택(같은 종류 ×3 = 확정 승급, 섞으면 무작위 종류). 잠근 유닛은 자동 선택에서 제외되고 소모 시 경고.
- **신화**: 신화 버튼에서 4개 레시피의 보유/부족 재료 확인, "재료 잠금"으로 예약. 공방 핵(보스 처치 보상) 1개 필요. 전장 최대 2기, 중복 불가.
- **강화**: 공격력(+6%/단계, 12단계), 공격 속도(+4%, 8단계), 기지 생명(+3, 5단계).
- **스킬**: 💥 포격(범위 피해, 보스엔 35%), ❄ 냉각(잡몹 2초 빙결, 보스 40% 감속). 버튼 탭 → 전장 탭으로 지정, 다시 탭하면 취소. 재사용 60초/50초.
- **속도/일시정지**: 상단 1×/2× 버튼, ⏸. 화면을 벗어나면 자동 일시정지.
- **웨이브 대기**: 웨이브 사이 7초. "바로 시작" 버튼은 남은 초 × 2골드 보너스.

## 구조

```
src/data/      수치 데이터(유닛·적·웨이브·유물·신화·경제·확률·맵) — 밸런스는 여기만 수정
src/sim/       시뮬레이션(순수 TS, DOM 없음): rng, state, roster(소환/합성/조합/이동), combat, engine(웨이브/이벤트/스킬/스냅샷)
src/render/    Canvas 2D 렌더러, 절차적 스프라이트, 파티클
src/ui/        HTML HUD·시트·입력·메인 루프
src/platform/  저장(검증·백업·내보내기), WebAudio 절차적 사운드
tests/         Vitest: 규칙/확률/경제 검증, 헤드리스 봇 밸런스 스윕
scripts/       단일 파일 빌드, Playwright(Chromium) 모바일 뷰포트 e2e
docs/          밸런스 표, 구현 상태, 테스트 결과
```

- 고정 시간 스텝(1/60s) 시뮬레이션. 배속은 스텝 횟수만 바꾸므로 프레임 수와 무관하게 결과가 같습니다.
- 판정용 난수(sfc32, 시드·상태 저장)와 시각 효과용 난수를 분리. 같은 시드 + 같은 입력 = 같은 결과(테스트로 검증).
- 저장: 각 웨이브 시작 시점(및 유물 선택 시점)의 전체 스냅샷을 localStorage에 기록하고 읽어서 검증. 실패 시 "저장 실패"로 표시. 내보내기/불러오기 문자열 지원. 이전 저장은 `_bak`에 백업.
