# 구현 상태 (v0.1.0-beta.1)

## 구현되어 실제 작동 확인된 것 (자동 테스트 + 헤드리스 Chromium 실기동)
- 맵 1개 "도깨비 야시장": 긴 직선 + 굽은 구간 + 하단 골목(경로가 여러 번 지나는 구간), 배치 지점 23개, 경로/출구 한 화면 표시, 카메라 이동 없음.
- 40웨이브, 10/20/30/40 보스 4종(깃발왕·장갑수레·시간도둑·탐욕의 수집왕) 각각 다른 패턴. 마지막 보스는 처치해야 승리, 통과 시 즉시 패배.
- 기본 유닛 8종 × 일반/희귀/영웅/전설, 신화 4종(레시피·공방 핵). 상호작용: 얼음+번개 전도, 산성+폭죽 추가 폭발, 자석+범위, 정비사 버프(최대값만·상한).
- 일반 적 8종 + 보물 운반꾼, 소개 힌트, 분열 개체 보상 중복 없음, 통과 피해 규칙.
- 유물 10종(보스 후 3택1, 선택 중 정지), 돌발 이벤트 3종(운반꾼·공방 과열·위험한 추가 주문), 수동 스킬 2종(터치 지정·취소·범위 미리보기).
- 소환 확률/불운 보정/운명 조각 종류 지정, 확률·보정 상태 UI 표시, 소환 연출 간소화 옵션.
- 합성(확정/무작위, 잠금·즐겨찾기, 잠금 재료 경고, 원자적 처리), 재배치(탭·드래그, 교환, 재사용 대기, 투사체·대기시간 악용 불가), 판매, 대기석 3칸, 만석 시 소환 차단.
- 강화 3종, 경제 표 공개, 조기 시작 보너스, 두꺼비 수입 상한.
- 1×/2×, 일시정지, 백그라운드 자동 정지, 3·2·1 카운트다운, 고정 시간 스텝.
- 저장: 웨이브 시작/유물 선택 시점 스냅샷(유닛·재화·유물·시드·난수·보정 카운터 포함), 읽기 검증, 백업, 내보내기/불러오기, 판 ID·보상 1회, 버전 불일치 처리.
- 결과 화면: 실제 기록 기반(도달 웨이브, 피해 기여 상위, 기지 피해 적, 신화/유물) + 기록 기반 힌트. 도감·칭호·빌드 기록.
- 절차적 스프라이트(유닛 8종×등급 장식, 신화 4종, 적 14종), 파티클, 흔들림/플래시(감소 옵션), 병합 피해 숫자, WebAudio 효과음·배경음(개별 볼륨).
- 세로 우선 + 가로 레이아웃, 노치/안전 영역, 44px 이상 터치 영역, 확대·스크롤 방지.

## 알려진 제한 / 미구현
- **실기기·사람 플레이 테스트 미수행**: 검증은 자동 테스트와 헤드리스 Chromium(모바일 뷰포트 390×844, 360×640, 844×390)뿐입니다. 실제 iOS Safari/Android Chrome의 터치·오디오·성능은 미검증입니다.
- 난이도는 "보통"만 있습니다(어려움 미구현, 버튼도 없음).
- 합성/신화/강화/확률 시트를 열면 전투가 멈춥니다(설계 선택). 유물 선택도 정지.
- 유닛 정보 패널이 전장 하단을 덮습니다(버튼 외 영역은 터치가 통과되어 그 아래 자리도 배치 가능).
- 완주 시간: 봇 기준 1배속 14~30분(대부분 17~24분)으로 목표(15~20분)보다 다소 깁니다. 2배속으로 단축 가능. 추가 조정 필요.
- 이어하기는 "최근 웨이브 시작 시점"으로 복귀합니다(웨이브 중간 상태는 저장하지 않음).
- 추가 맵, 무한 모드, 협동, 장비, Android/iOS 네이티브 패키징은 없습니다. 브라우저 게임과 플랫폼 코드는 분리되어 있어(`src/platform/`) 이후 Capacitor 등으로 감쌀 수 있습니다.
- 설치형 웹앱(PWA manifest/service worker) 미포함. 스토어 등록·공개 게시는 하지 않았습니다.
