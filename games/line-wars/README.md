# 라인워즈: 군단의 충돌 (LINE WARS: LEGION CLASH) — 베타 0.1

병력을 **편성표에 구매·배치**하면 **정해진 시간마다 자동으로 출격**하고, 살아남은 병력은 전장에 남아 다음 부대와 합류합니다.
상대가 실제로 출격시킨 조합을 보고 **편성과 배치를 바꾸면 다음 출격의 전선이 달라지는** 것이 핵심입니다.
스타크래프트 유즈맵의 이름·외형·에셋은 사용하지 않았고, 모든 그래픽과 소리는 코드로 생성됩니다.

- 실행 환경: 휴대폰 브라우저(가로 화면), PC 브라우저. 온라인 서버 없음, 오프라인 AI 대전.
- 기술: TypeScript + Vite + 자체 Canvas2D 렌더러. 시뮬레이션(권위 상태)과 렌더링/UI가 완전히 분리되어 Node에서 헤드리스로 수천 판 자동 대전이 가능합니다.

## 1. 휴대폰에서 실행하는 방법

### 방법 A. GitHub Pages로 열기 (권장, 저장소 소유자가 1회 설정)
1. GitHub 저장소 → **Settings → Pages**.
2. *Build and deployment* 에서 Source: **Deploy from a branch**, Branch: **이 브랜치**, Folder: **/docs** 선택 후 Save.
3. 1~2분 뒤 표시되는 주소(예: `https://<계정>.github.io/MyGame/`)를 휴대폰 브라우저로 엽니다.
4. iPhone Safari: 공유 → **홈 화면에 추가**. Android Chrome: 메뉴 → **홈 화면에 추가** (PWA, 전체화면·오프라인 캐시).

> 이 문서를 작성한 세션은 Pages를 켜지 않았습니다(공개 배포는 별도 승인 사항). 위 설정은 소유자가 직접 해야 합니다.

### 방법 B. 파일 하나로 열기
`docs/linewars-single.html` 한 파일에 게임 전체가 들어 있습니다. 휴대폰에 파일을 옮겨 브라우저로 열면 됩니다(카카오톡/메일로 보내 저장 후 열기). 이 방식은 서비스워커(오프라인 캐시)만 비활성화됩니다.

### 방법 C. 개발용 서버
```bash
npm install
npm run dev        # 같은 Wi-Fi의 휴대폰에서 http://<PC IP>:5173 접속
npm run build      # docs/ 에 정적 빌드 + docs/linewars-single.html 생성
```

### 조작 (가로 화면 기준)
- 시작 화면: **빠른 대전(1v1) · 팀 전투(3v3) · 연습(튜토리얼) · 프로필 · 설정**. 진행 중 저장 경기가 있으면 **이어하기**.
- 경기 시작 후 20초 **편성 시간** → 3·2·1 카운트다운 → 첫 출격. 이후 1v1은 25초마다, 팀전은 A→B→C 15초 간격(같은 사령관 45초)으로 출격.
- 하단 바: 크레딧 · 초당 수입 · 다음 출격 · 인구수 · **편성 / 연구 / 상대 / (팀) / 비상 방어포 / ⏸**.
- 편성 화면: 왼쪽 병종 카드 탭 → 격자의 빈 칸 탭 = 배치(연속 구매 기본 켜짐). 배치된 병력 탭 → **이동**(무료) / **취소**(미출격 100% 환급) 또는 **판매**(출격 후 70%).
  격자 오른쪽이 전방, 위·아래 행이 전장의 위·아래 출격 위치입니다. 편성 중에도 경기 시간과 출격 타이머가 보이고 전투는 멈추지 않습니다.
- 전장: 드래그 이동, 두 손가락 확대·축소(PC는 휠). **아군 기지 / 전선 / 적 기지** 버튼, **−/+** 줌. 직접 움직이면 자동 추적이 꺼지고 **전선**을 누르면 다시 켜집니다. 병력을 탭하면 정보와 사거리가 표시됩니다.
- 비상 방어포: 팀당 경기 중 1회. 버튼 → 붉은 영역(아군 기지 근처)을 탭 → 1.5초 경고 후 반경 120에 피해 130 + 3초 둔화. 팀전에서는 사람만 결정합니다.
- ⏸: 일시정지(계속 / 설정 / 저장하고 메뉴로 / 항복). 앱이 배경으로 가면 자동으로 정지·저장됩니다.

## 2. 구현된 것 / 구현되지 않은 것

### 구현됨 (실제로 실행·검증)
- 병력 구매 → 편성표 스냅샷 → 주기 출격 → 이동·타기팅·공격(선딜/발사/명중/후딜) → 피해·방어·보호막 → 사망 → 경제 성장 → AI 대응 → 거점·본진 파괴 → 승패·무승부 → 결과 분석 → 재시작 → 저장/복원.
- 진영 2개, 병종 16개(진영별 8개, 모두 다른 무기 방식: 연사·단발 포탄·부채꼴·곡사 광역·대공 추적탄·투하 폭탄·관통 빔·수리·보호막).
- 8×6 편성판(전방/후방·위/아래가 실제 출격 위치에 반영, 적은 좌우 반전), 인구수 1~4·상한 60.
- 1v1(25초), 3v3(15초 교대·45초 재출격, 같은 전장에서 합류), 생존 병력 합류(복제·체력 초기화 없음).
- 전장 2400×1000: 후방 출격 지점 → 본진 → 전방 거점, 중앙 중계소 점령(+8% 수입, 8초 점령·경합 표시), 거점 파괴 전 본진 무적 표시.
- 12분부터 연장전(건물 피해 30초마다 +50%), 15분 본진 체력 비율 판정, 동시 파괴·비율 동일 시 무승부(동시 판정, 좌우 순서 편향 없음).
- 경제: 크레딧 단일 자원, 시작 400, 기본 수입 4/초, 경제 연구 8단계(가격·증가 수입·회수 시간 표시), 기술 1~3단계, 공격/방어/지원 업그레이드 3단계(다음 출격부터 적용). 판매 70%·취소 100%, 반복 조작으로 돈이 늘지 않음(테스트로 검증).
- AI 쉬움/보통/어려움: 같은 자원·같은 정보(상대의 *실제 출격* 부대만 봄), 반응 지연·예산 제한, 저축(기술/경제/고급 병종), 인구 상한 근처에서 저급 병력을 팔아 상위 병종으로 교체, 어려움은 팀 역할 분담(전열/대공/포병·경제). 팀전 아군 AI에게 대공 지원·전열 보강·경제 투자 주의 요청 가능.
- 상대 정보: 적 사령관별 최근 출격 조합·직전 출격 대비 변화·위협 요약·현재 생존 병력. 아직 출격하지 않은 편성 변경은 비공개.
- 전투 규칙: 지상 전용 무기는 공중 불가, 광역은 실제 위치·반경 판정, 투사체 도착 시점에 피해, 사망 대상 추적 중단, 치유 총량·중첩(수리기 2대) 제한, 보호막 총량·지속시간 제한, 둔화 지속시간, 최소 사거리, 측면침투기의 가장자리 우회 경로, 활공사수·투척병의 치고 빠지기, 부대 응집(빠른 병력이 혼자 앞서지 않음), 겹침 분리·건물 밀어내기·정지 감지 복구.
- 모바일 UI: 가로 기준, 44px 터치 영역, 안전 영역, 오른쪽 위 고정 닫기 버튼, 패널 위 탭이 전장으로 새지 않음, 세로 회전 안내(데이터 유지), 640×360·844×390 검증.
- 아트/연출: 병종별 절차적 실루엣(보병·방패·포차·지원기·항공기), 포신 회전·바퀴·다리·기체 기울기·엔진, 무기별 다른 발사 연출, 공중 그림자·고도, 아군(밝은 외곽선+실선 링)/적(어두운 외곽선+점선 링), 손상 병력만 체력바(설정 변경 가능), 거점 파괴·방어포에만 화면 흔들림/섬광(설정으로 끔), 절차적 효과음·배경음.
- 첫 경험: 연습 모드 8단계 상황별 안내(배치 → 자동 출격 확인 → 적 조합 관찰 → 광역 대응 → 폭격기 등장 → 대공 보강), 대본형 교관 AI(같은 자원 규칙).
- 결과: 승패·시간·진영·경제/기술/업그레이드 투자·병종별 피해/흡수/지원/격파/손실·양측 최종 조합·**기록 기반 개선 포인트 최대 3개**(근거 없는 원인은 말하지 않음).
- 장기 보상: 진영 숙련도, 칭호 6종, 배지 7종, 아군 색상 4종, 편성 프리셋 저장·시작 시 적용. 계정 성장으로 병종 능력치는 변하지 않음.
- 저장: 설정·진행도·진행 중 경기(병력·투사체·타이머·자원·AI 상태·난수 상태 전체) 로컬 저장, 버전 확인·손상 시 안전 폐기.
- PWA: manifest + 서비스워커(앱 셸 캐시). Capacitor 패키징을 고려한 구조(정적 파일만).

### 구현되지 않음 / 범위 밖 (정직한 상태)
- 온라인 PvP, 친구 초대, 글로벌 랭킹, 계정 서버, 실제 광고·결제 — **없음**. 어디에도 온라인처럼 보이는 메뉴를 두지 않았습니다.
- 안드로이드 APK / iOS 빌드 — **만들지 않음**. 웹(PWA)만 완료. Capacitor 래핑은 이후 작업입니다.
- 지형 장애물·미로, 두 번째 전장 — 없음(첫 버전은 개방 전장).
- **실기기 미검증**: 실제 휴대폰에서는 검증하지 못했습니다. 헤드리스 Chromium(모바일 뷰포트·터치 에뮬레이션)으로만 확인했습니다.

| 질풍 vs 질풍 / 철갑 vs 철갑 (좌우 편향 확인) | 10+10 | 6:4 / 4:6 (편향 없음) | 12.7 / 10.0분 |

한계·솔직한 평가
- 경기 시간이 목표(10~15분)의 상단에 몰려 있고, 인구 상한(60)에 도달한 두 AI가 중앙에서 교착해 **15분 시간 판정으로 끝나는 비율이 30~50%**입니다. 연장전 배율을 더 키우거나 인구 상한을 낮추는 조정 여지가 있습니다.
- "어려움 vs 보통"의 격차가 크지 않습니다(16판 중 8:6:2). 난이도 간 차이는 주로 반응 속도·경제·조합 다양성에서 나며, 사람이 상대할 때는 체감 차이가 더 크지만 추가 조정이 필요합니다.
- 플레이 재미는 자동 대전 승률로 검증되지 않습니다. 사람이 플레이하며 "상대를 보고 바꾼 편성이 다음 출격에서 전선을 바꾸는지"를 확인하는 것은 실기기 플레이 이후 과제입니다.
- 소총6 vs 투척3 시나리오는 의도(광역 우세)와 다릅니다. 투척병은 밀집 편성 상대로만 확실히 우세합니다.

## 5. 코드 구조
```
src/core/data      병종·진영·밸런스 데이터
src/core/sim       state(상태 정의) · commands(구매/판매/이동/연구 검증·적용) · match(출격 스케줄·전투·경제·건물·중계소·방어포·승패·직렬화)
                   spatial(공간 분할) · combat(피해 공식) · analysis(결과 개선 포인트)
src/core/ai        난이도별 AI, 팀 조율, 튜토리얼 대본
src/render         renderer(카메라·보간·미니맵) · sprites(절차적 스프라이트) · fx(객체 풀 효과) · audio(절차적 사운드)
src/ui             app(화면·게임 루프·입력·HUD·결과) · panels(편성/연구/상대/팀) · tutorial
src/persist        로컬 저장
tools              headless(자동 대전) · balance(상성 실험실) · stress(부하) · e2e/fps(Playwright) · postbuild(단일 파일)
tests              핵심 규칙 테스트
docs               빌드 결과(GitHub Pages용) + linewars-single.html
```
명령은 검증 후 상태에 적용되며(`applyCommand`), 시뮬레이션은 고정 시간 간격(50ms)으로 진행하고 렌더링은 두 틱 사이를 보간합니다. 피해는 모든 판정을 모은 뒤 한꺼번에 적용해 좌우 처리 순서가 결과에 영향을 주지 않습니다.
