## 2. 핵심 게임 규칙 (구현 기준)

- **시간**: 게임 시간 기준 고정 스텝 1/60초. 일시정지·시트·능력 선택·종료 상태에서는 `step` 이 아무것도 하지 않는다. 긴 프레임은 최대 6스텝까지만 처리하고 나머지는 버린다(누적 즉사 방지). 백그라운드 전환 시 자동 일시정지 후 사용자 확인으로 재개.
- **이동**: 조이스틱 벡터를 정규화해 대각선 속도 동일. 축 분리 충돌로 벽·상자더미·닫힌 문·경계를 통과하지 않는다. 대시 0.18초/속도 640(≈115px), 무적 0.16초, 재사용 4초(경량 프레임 −0.5/−1.0초). 대시 중 조이스틱 무시, 연타 중복 불가, 무게 무관.
- **피격**: 피격 반경 11px(그림 ≈28px). 피격 후 0.55초 피해 중복 방지. 보호막이 먼저 소모. 체력 0 → 즉시 `status='dead'`, 같은 스텝의 탈출 완료보다 우선.
- **자동 공격**: 사거리 안에서 벽(#)에 가리지 않는 가장 가까운 적. 현재 타깃이 유효하면 유지. 상자더미(o)는 이동만 막고 시야·탄환은 통과.
- **무기**: 소총(단일 대상, 관통 코어로 관통), 산탄총(6발 부채꼴, 한 발사 = 원본 공격 1회, 여러 탄이 같은 적에 명중 가능, 밀쳐내기), 전기 지팡이(즉시 타격 후 2회 연결, 같은 적 재연결 없음, 감쇠 0.75). 강화 1단계 = 3구역 완료, 2단계 = 5구역 진입 (`flags.tier` 로 중복 방지). 수치 `TIER_DMG`, 외형·효과음 변화.
- **능력 8종** 최대 2단계, 1·3·5구역 완료 후 3택1 (`abilityOffer` 는 저장되어 재추첨 불가, `flags.abilityPicked` 로 1회 보장). 충격탄 폭발은 `src='shock'` 로 다시 폭발·서리를 만들지 않는다. 서리는 갱신만(하한 0.6, 보스 0.88).
- **전리품**: 고철 3/12, 전자부품 2/16, 희귀 유물 2/40. 가방 30(+2×수납 보강 2단계). 획득 반경 40(+자기장 반지), 벽 너머 획득 없음. 무게 초과분은 바닥에 남고(`blocked`) 공간이 생기면 다시 끌려온다. 감속: 적재율 60% 이하 0, 100%에서 12%(경량 프레임 −50/−90%). 버린 물건은 옆 바닥 유효 위치에 떨어지고 **자동으로 끌려오지 않으며 직접 밟아야** 다시 줍는다(재획득 통계 미집계).
- **구역**: 등장표는 시간 또는 처치 수 조건이며, 처치 조건은 직전 등장 후 최소 6초(어려움 4.5초) 간격을 지킨다. 생성은 플레이어에서 170px 이상 떨어진 지점 중 가장 먼 곳과 가장 가까운 허용 지점에 0.8초 예고 후 등장(협공). 목표 = 등장표 적 전부 처치(경보·추격·소환 적은 `noLoot` 로 집계·드롭 제외). 완료 시 기본 회복 10(+회복 장치), 구역당 1회. 문은 완료 후 열리고 이동하면 돌아올 수 없다.
- **탈출**: 2·4구역 패드(반경 82)에서 완료 후 명시적 요청 → 8초. 밖으로 나가면 정지, 들어오면 이어서. 취소·재요청해도 추격 적 예약(`escape.waves`)은 한 번뿐. 완료는 그 스텝의 피해 처리 후 생존 시. 6구역은 보스 처치 후 최종 출구 3초, 추격 없음. 보스 보상은 바닥 전리품(탈출 시 정산).
- **이벤트**: 경보 금고(3·5구역 확정, 4구역 50%): 확인창 → 개방 1회 → 추가 적(전리품 없음). 통로 붕괴(4구역, 처치 7): 3초 경고 후 x→벽, y→바닥, 위에 있던 대상은 가장 가까운 바닥으로 이동(즉사 없음), 붕괴 전후 연결성은 테스트로 검증. 정비 드론(3·5구역 70%): 전자부품 2 또는 고철 3 ↔ 체력 30, 1회, 보관 재화 미사용.
- **정산**: `settleRun(blob, state)` 가 출정 ID 기준 1회만 보관 재화에 반영하고 기록을 남긴다. 결과 화면 재진입·새로고침으로 재지급되지 않는다. 저장 실패 시 결과 화면에 실패를 표시하고 재시도 버튼을 둔다.
- **저장 시점**: 구역 진입, 목표 완료(능력 제시 포함), 능력 선택 후. 전투 중 상태는 저장하지 않는다. 스냅샷은 상태 전체 직렬화(체력·전리품·능력·시드·난수·플래그가 같은 시점).

## 7. 다음 작업자를 위한 현재 상태와 남은 문제

- 사람 플레이·실기기 테스트가 아직 없다. 자동 봇은 즉시 최적 이동을 하므로 사람은 더 어렵게 느낄 수 있다. 우선 확인할 것: 조이스틱 반경(46)·데드존(8)·카메라 앞보기(36)의 손맛, 1구역 길이(봇 26초, 목표 45~60초), 보스 부채꼴 피해 30이 과한지.
- 봇 기준: 무회피 봇(적에게 붙는 초보자 근사)이 1~4구역에서 구역당 10~42 피해. 회피 봇은 거의 무피해. 전기 지팡이 봇은 보스에게 자주 사망(사거리 200 < 부채꼴 165+ 접근 필요) — 사람이 거리를 유지하면 다르지만 지팡이의 보스전 보정(예: 연결 시 소량 감속·사거리 220)을 검토.
- 조기 탈출 가치 100~150, 중간 340~390, 최종 450~600(가방 30 상한, 유물 15개 = 600). 산탄총 해금 320 은 조기 탈출 3회 또는 중간 탈출 1회. 후반이 항상 이득인지(사망 위험 대비)는 사람 테스트 필요.
- 알려진 사소한 문제: 미니맵은 탐색 여부와 무관하게 전체 지도를 보여준다(의도적 단순화). 붕괴 후 카메라를 재설정해 순간 이동처럼 보일 수 있다. 상자더미(o) 위로 탄환이 지나가지만 그림상 높이가 낮게 보이지 않을 수 있다.
- 조작 관련 훅: `window.__app.debug` (dirTo/jumpZone/setHp/summary) 는 e2e 전용이며 게임 규칙에 영향이 없다. 배포 시 제거하려면 `app.ts` 의 `debug` 와 `main.ts` 의 `__app` 노출을 지우면 된다.
