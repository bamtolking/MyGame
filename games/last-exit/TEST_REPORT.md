# 테스트 보고서 — 털고 튀어!: 라스트 엑시트 (v0.1.0-beta.1, 2026-09-17)

**실기기(안드로이드·iOS)와 사람 플레이 테스트는 수행하지 않았습니다.** 아래는 이 저장소 안에서 자동으로 재현되는 결과이며, 브라우저 확인은 헤드리스 Chromium(휴대폰 뷰포트·터치 에뮬레이션)으로 한 것입니다. 실행 환경은 원격 리눅스 컨테이너(Node 22.22, Chromium 1194)입니다.

## 3. 봇 밸런스 주행 — `npm run test:runs` (3시드 × 경로 A/B/C × 무기 3종 × 회피/무회피 + 어려움), 결과표 `docs/balance-results.md`

봇은 흐름장으로 최단 이동하고, 회피 봇은 예고에 대시하며, 무회피 봇은 적에게 붙는 초보자 근사입니다. **재미 검증이 아니라 수치 범위 확인**입니다.

해석
- 조기 탈출(≈120)로 산탄총 해금(320)까지 3회. 중간 탈출 1회(≈360)로도 가능. 후반 최대는 가방 상한(유물 15개 = 600)에 걸린다.
- 회피 봇은 1~5구역에서 거의 무피해라 실제 위험도는 사람 플레이로 확인해야 한다. 무회피 봇 기준으로는 4구역까지 살아남지만 여유가 크지 않다.
- 보스는 봇 기준 가장 위험한 구간이며 지팡이(사거리 200)가 불리하다. 부채꼴 피해를 30→24, 방사형 10 으로 낮췄다. 사람 기준으로 억울한 죽음이 되는지 확인 필요.

## 4. 브라우저 실기동 — `npm run e2e` (헤드리스 Chromium, 터치 에뮬레이션, 개발 서버 대상)

뷰포트 390×844 / 360×800 / 430×932 각각에서 다음을 실제 터치 입력으로 수행하고 확인했습니다 (총 88개 확인 항목 통과, 콘솔·페이지 오류 0, 60 FPS).

1. 타이틀 → 출정 준비 → 시드 7로 출정 시작.
2. 레이아웃: 대시·가방·상단 UI 겹침 없음·화면 안, 버튼 44px 이상.
3. 조이스틱 드래그로 이동(Δx≈80px/0.5초), 놓으면 즉시 정지.
4. 가방 버튼 → 시트 열림·전투 정지, 닫으면 재개. 버튼 터치가 이동 입력으로 새지 않음.
5. 대시 버튼 연타 → 1회만 발동.
6. 일시정지 중 게임 시간 정지. 백그라운드 전환(visibilitychange) 시 자동 일시정지·이동 입력 해제.
7. 1구역 정리(12/12 처치) → 능력 선택 시트 → 1개 선택 → 저장됨.
8. 상자·전리품 회수 → 문 앞 "다음 구역으로 / 되돌아올 수 없음" 버튼 → 확인창 → 2구역 진입·스냅샷 저장.
9. 새로고침 → "이어하기 (2구역 · 구역 2 진입)" → 복원(처치 0, 체력 100, 전리품 가치 유지).
10. 2구역 정리 → 탈출 지점 → "탈출 요청 / 가치 ◆104 확보" → 추격 적 등장 중 8초 버팀 → 탈출 성공 → 결과 화면.
11. 보관 재화 = 전리품 가치, 정산 기록 1회, 새로고침 후 재화 유지·종료된 출정 미복구.
12. (390×844) 새 출정 → 6구역 점프(디버그) → 보스 등장·공격 예고 표시 → 체력 3으로 설정 → 사망 → 결과(잃은 것/유지된 것) → 보관 재화 유지.

스크린샷: `docs/screenshots/` (타이틀, 가방, 전투·정리 완료, 능력 선택, 문 확인, 탈출 선택, 탈출 중 추격, 탈출 성공 결과, 해금, 보스 예고, 사망 결과, 360px 탈출 화면, 430px 전투).

## 5. 수정한 오류 (개발 중 발견)
- 구역 진입 배너 2회 표시 → 1회.
- 봇 주행에서 1구역이 12초 만에 끝남 → 처치 조건 등장표에 최소 간격 6초(어려움 4.5초) 추가.
- 적이 한쪽 생성 지점에서만 나와 카이팅으로 무피해 → 가장 먼 지점 + 가장 가까운 허용 지점 협공, 추적자·질주자·사수 속도 상향.
- 보스가 강화 소총에 20초 만에 사망 → 체력 900→2000(어려움 2400).
- 버린 물건이 자동으로 다시 끌려와 무한 버리기/줍기 반복·통계 부풀림 → 버린 물건은 직접 밟아야 재획득, 재획득은 통계 미집계.
- 탈출 준비 바가 경고문과 겹침 → 상단 바 안으로 이동, 알림 영역을 상단 바 높이에 맞춰 배치.
- 360px 폭에서 일시정지 버튼 잘림 → 상태 칩 말줄임, 버튼 고정 폭.
- 탈출 지점 글자가 캐릭터와 겹침 → 패드 하단으로 이동.

## 7. 알려진 제한
- 전투 중 저장 없음(구역 진입 시점 복원). 로컬 저장이므로 부정행위 방지는 없음.
- 미니맵은 전체 지도를 항상 보여줌(탐색 여부 미반영).
- 붕괴 직후 카메라가 재설정되어 순간 이동처럼 보일 수 있음.
- 전기 지팡이는 보스전에서 봇 기준 생존율이 낮음(사람 테스트 후 사거리·연결 보정 검토).
- `window.__app.debug` 훅은 테스트용이며 규칙에 영향이 없지만 배포 시 제거 권장.
