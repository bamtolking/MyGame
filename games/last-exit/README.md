# 털고 튀어!: 라스트 엑시트 (웹 베타)

한 손 조작 탑다운 탈출 액션. 무기를 고르고 6개 구역을 내려가며 전리품을 챙기고, **살아서 탈출해야만** 보관 재화가 됩니다.
싱글 플레이, 서버·로그인·결제·광고 없음. 휴대폰 브라우저에서 바로 실행되는 HTML5 게임입니다.

> 한 문장: **체력 35%, 가방은 묵직한데 다음 구역에 희귀 금고가 보인다. 지금 튈까, 한 구역만 더 갈까?**

## 1. 필요한 환경

- **플레이만 할 때**: 최신 Chrome / Safari (iOS 15+, Android Chrome). 설치 불필요.
- **개발 서버·빌드·테스트**: Node.js 22 (`node -v` 로 확인), npm 10.

## 2. 가장 쉬운 실행 방법 (파일 하나)

`play/index.html` 파일 하나가 게임 전체입니다. 이 파일을 휴대폰이나 PC 브라우저로 열면 바로 실행됩니다.
(메신저·메일·클라우드로 휴대폰에 보낸 뒤 "브라우저로 열기"를 선택하세요. 일부 앱 내장 브라우저는 파일 열기를 막으므로 Chrome/Safari로 여세요.)

## 3. 개발 서버로 실행 (같은 Wi-Fi의 휴대폰에서 테스트)

```bash
cd last-exit
npm install          # 처음 한 번, 의존성 설치
npm run dev          # 개발 서버 시작 (포트 5174)
```

터미널에 다음처럼 표시됩니다.

```
➜  Local:   http://localhost:5174/
➜  Network: http://192.168.x.x:5174/
```

- **PC**에서는 `http://localhost:5174/` 를 엽니다.
- **휴대폰**에서는 `localhost` 가 아니라 **Network 줄의 주소**(PC의 IP)를 입력합니다. 휴대폰과 PC가 같은 Wi-Fi에 있어야 하고, PC 방화벽이 5174 포트를 막고 있으면 열어야 합니다.
- 개발 서버를 끄면(터미널 종료) 휴대폰에서도 접속할 수 없습니다.
- 외부 인터넷 공개(호스팅)는 이 저장소에 포함되어 있지 않습니다. `npm run build` 로 만든 `dist/` 폴더를 정적 호스팅에 올리면 됩니다.

## 4. 명령 모음

```bash
npm run dev          # 개발 서버
npm run typecheck    # 타입 검사만
npm test             # 규칙 테스트 + 지도 검증 + 봇 밸런스 주행 (약 20초)
npm run test:rules   # 규칙 테스트만 (2초)
npm run test:runs    # 봇 밸런스 주행만 → docs/balance-results.md 갱신
npm run build        # 타입 검사 + 빌드 → dist/ 와 play/index.html
npm run e2e          # 헤드리스 Chromium 실기동 (개발 서버가 켜져 있어야 함, 스크린샷 e2e-out/)
npm run check:singlefile  # play/index.html 을 file:// 로 열어 실행되는지 확인
```

## 5. 조작

| 동작 | 휴대폰 | PC |
|---|---|---|
| 이동 | 화면 아래쪽 빈 곳을 누른 채 끌기 (누른 자리에 조이스틱이 생김) | WASD / 방향키 |
| 공격 | 자동 (사거리 안·시야가 닿는 가장 가까운 적) | 자동 |
| 대시 | 오른쪽 아래 큰 버튼 (0.18초 이동, 짧은 무적, 재사용 4초) | 스페이스 |
| 상호작용 | 가운데 아래에 나타나는 버튼 (상자·탈출 요청·다음 구역·드론) | E |
| 가방 | 오른쪽 "가방" 버튼 (열면 전투 정지, 버리기 가능) | B |
| 일시정지 | 오른쪽 위 ⏸ | Esc |

## 6. 한 판의 흐름

무기 선택 → 1구역(전투·상자) → 능력 선택 → 2구역 → **탈출 or 계속** → 3구역 → 능력 → 4구역 → **탈출 or 계속** → 5구역 → 능력 → 6구역 보스 → 최종 탈출 → 정산·저장 → 다음 출정

- 구역의 적을 모두 처치하면 출구가 열립니다. 떠나면 되돌아올 수 없습니다.
- 2·4구역의 탈출 지점에서 "탈출 요청" 후 8초를 버티면 전리품이 확정됩니다. 추격 적이 옵니다.
- 출정 중 전리품은 **미확정**입니다. 사망하면 이번 전리품만 잃고, 이전에 보관한 재화·해금·수납 보강은 유지됩니다.
- 보관 재화로 산탄총(◆320)·전기 지팡이(◆520)·수납 보강(◆160/◆260)을 해금합니다. 기본 소총은 무료이며 입장료는 없습니다.

## 7. 이어하기 정책

- **전투 중 종료·새로고침**: 현재 구역 **진입 시점**부터 재도전 (그 구역에서 얻은 전리품·진행은 되돌아감).
- **구역 완료·능력 선택 후**: 확정한 선택과 상태가 저장됨.
- **탈출·사망 확정 후**: 결과가 저장되고, 종료된 출정은 복구되지 않음. 결과 화면을 다시 열어도 재화가 다시 지급되지 않음.

## 8. 저장 초기화

거점 → 설정 → "저장 데이터 초기화". 브라우저의 로컬 저장소(`localStorage`)만 사용하며, 서버로 전송되는 데이터는 없습니다.
저장이 손상되면 백업에서 복구를 시도하고, 실패하면 안내 후 초기화합니다.
