## 3. 브라우저 실기동 — `npm run e2e` (헤드리스 Chromium 1194, 터치 에뮬레이션, 스크린샷 `e2e-out/`)

### 솔로 (390×844 세로, 844×390 가로)
타이틀 → 이름 입력 → 혼자 하기 → 소환 5회(골드 100→0, 유닛 5) → 캔버스 유닛 탭(패널 표시) → "이동" 후 빈 자리 탭(이동 확인) → 드래그로 다른 자리(이동 확인) → 2배속 25초 전투(라운드 2, 처치 32, 60 FPS) → 조합/강화 시트 열고 닫기 → 소환 레벨 업그레이드(Lv2) → 일시정지(시간 정지 확인) → 몬스터 80마리 주입 → 탈락 결과 화면 → 처음으로. **콘솔/페이지 오류 0.**

### 협동 — WebSocket 서버 (방장 390×844, 친구 360×780)
방 만들기(코드 발급, netKind=ws) → 친구가 `?room=코드` 링크로 참가 → 로비 인원 2명 → 방장 시작 → 둘 다 게임 화면(mode=multi) → 카운트다운 후 둘 다 라운드 1 → 상단 탭에 "나 / 친구" 라운드·몬스터 수 표시 → 방장이 팀 시트에서 100G 전송(친구 골드 +100 확인) → 친구 이모티콘이 방장 화면 토스트로 표시 → 친구가 방장 판 관전(원격 스냅샷 유닛 5·몬스터 표시) → 30초 후 두 클라이언트 모두 라운드 2(동기화, 60/60 FPS) → 친구 탈락 주입 → 방장 탭에 "탈락", 친구에게 관전 오버레이 → 방장도 탈락 → 둘 다 결과 화면·팀 결과표 → "같은 방에서 다시" → 둘 다 로비 → 두 번째 게임 시작(둘 다 라운드 1 진행) → 방장 나가기(서버 모드에서는 방이 유지되어 친구는 계속 진행). **오류 0.**

### 협동 — P2P (로컬 PeerServer + 실제 WebRTC DataChannel)
위와 같은 흐름을 정적 호스팅(서버 감지 실패 → P2P 자동 선택)에서 반복. 방장 브라우저가 방을 운영하고 친구는 코드로 접속. 골드 전송·이모티콘·관전·라운드 동기화·탈락·결과·다시하기 모두 동일하게 통과. 방장이 나가면 친구에게 "연결이 끊겼습니다" 오버레이. **오류 0** (정적 호스팅에서 서버 감지용 `/api/ping` 404는 의도된 동작이라 제외).
