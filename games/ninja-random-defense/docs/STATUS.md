# 구현 상태 (v0.2.0-beta.1)

## 구현되어 자동 테스트·헤드리스 브라우저로 확인된 것
- 랜덤 디펜스 핵심 규칙: 고리 길을 도는 몬스터, 80마리 한도 탈락, 25초마다 라운드(40개), 보스 60초 제한, 마지막 보스 처치 시 승리.
- 소환(5속성×4등급, 레벨별 확률), 확정 합성/무작위 합성/자동 합성, 전설 3종 조합 → 신화 4종, 판매, 이동(탭·드래그·교환), 소환 레벨·공격력 강화.
- 속성 효과: 범위(화염), 감속(얼음, 보스 상한), 연쇄(번개), 고속 단일(질풍), 기절(대지, 면역·보스 배율). 신화 고유 효과(오라 감속, 보스 배율 등).
- 협동 멀티(최대 4명): 방 코드, 로비, 공유 라운드 시계(호스트 기준), 각자 자기 판, 상단 탭으로 친구 판 관전(2Hz 스냅샷 + 위치 보간), 골드 보내기, 이모티콘, 탈락 후 관전, 팀 결과표, 같은 방에서 다시 하기, 끊긴 참가자 자리 유지 + 같은 기기 재접속.
- 연결 방식 2가지가 같은 방 코드 로직(`src/net/room.ts`)을 공유:
  - P2P(PeerJS): 서버 없이 방장 브라우저가 방을 운영. 기본값.
  - 전용 서버(`server/index.ts`, Node 22 + ws): 정적 파일 + `/ws`. `npm run server`, Dockerfile 포함.
- 모바일 UI: 세로/가로 레이아웃, 44px 이상 터치 영역, 안전 영역, 시트(조합·강화·팀·도움말·메뉴), 토스트·배너, 절차적 닌자 스프라이트·이펙트, WebAudio 효과음, 설정·기록 저장(localStorage), PWA manifest(홈 화면 추가).
- 솔로: 1×/2×, 일시정지, 백그라운드 자동 정지. 멀티: 백그라운드 복귀 시 최대 90초 따라잡기.
- 단일 파일 빌드 `play/index.html`, GitHub Pages 배포 워크플로.

## 알려진 제한 / 미구현
- **실기기·사람 플레이 테스트 미수행.** 검증은 vitest(68개)와 헤드리스 Chromium(휴대폰 뷰포트, 터치 에뮬레이션)뿐입니다. 실제 iOS Safari/Android Chrome의 오디오·성능·WebRTC 연결은 미검증입니다.
- P2P는 공용 PeerJS 시그널 서버(0.peerjs.com)에 의존합니다. 서버가 불안정하거나 일부 통신사/공유기(대칭 NAT)에서는 연결이 안 될 수 있습니다(TURN 서버 없음). 방장이 화면을 끄거나 다른 앱으로 가면 라운드 시계가 멈춥니다. 안정성이 필요하면 전용 서버를 쓰세요.
- 멀티에서 각자의 판은 자기 기기에서 계산합니다(클라이언트 신뢰). 친구끼리 협동용이며 치트 방지는 없습니다.
- 게임 중간 저장/이어하기 없음(실시간 진행 게임 특성). 설정과 기록만 저장.
- 난이도 1종, 맵 1종. 대전(몬스터 보내기) 모드 없음.
- 관전 화면에는 공격 이펙트가 없고 유닛·몬스터·체력만 표시됩니다.
- 스토어 등록·네이티브 패키징 없음(`src/platform/`이 분리되어 있어 Capacitor 등으로 감쌀 수 있음).
