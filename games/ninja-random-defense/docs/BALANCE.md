# 밸런스 데이터 (v0.2 베타)

모든 수치는 `src/data/*.ts`에 있고 게임 안 시트(강화·조합·유닛 패널)에 그대로 표시됩니다.

## 판·라운드
| 항목 | 값 |
|---|---|
| 판 | 8×6칸, 바깥 고리 길(둘레 1200px), 안뜰 6×4 = 24자리 |
| 몬스터 한도 | 80마리 (살아 있는 수가 80이면 탈락) |
| 라운드 | 40개, 25초 간격 (몬스터는 라운드가 끝나도 남아 계속 돔) |
| 일반 라운드 | 20마리, 0.45초 간격 (`brute` 라운드는 12마리) |
| 보스 라운드 | 10·20·30·40. 보스 1 + 들개 8. 보스는 60초 안에 처치해야 함 (실패 시 탈락). 마지막 보스 처치 = 승리 |
| 몬스터 체력 | `18·r·1.085^r + 10` (r=1: 30, 10: 417, 20: 1837, 30: 6200, 40: 18800) |
| 종류 | 들개(기본 ×1.0, 50px/s) · 질주(r%10=4,7: ×0.6, 82px/s) · 거한(r%10=2,5,8: ×2.0, 40px/s, 12마리) · 보스(×10, 30px/s) |

## 경제
| 항목 | 값 |
|---|---|
| 시작 골드 | 100 (소환 5회) |
| 소환 | 20골드 고정 |
| 라운드 보상 | 25 + 3r |
| 처치 골드 | 1 + ⌊r/8⌋ (보스 100×⌈r/10⌉) |
| 판매 | 일반 8 / 희귀 25 / 영웅 80 / 전설 260 / 신화 800 |
| 소환 레벨 | Lv1→5, 비용 120/260/520/1000 |
| 공격력 강화 | +8%/단계, 15단계, 비용 60+45·단계 |
| 골드 보내기(협동) | 최소 10, 수수료 없음 |

## 유닛 (일반 기준, 등급 배율 ×1 / ×3.3 / ×11 / ×36, 사거리 +0/8/16/28)
| 속성 | 공격 | 주기 | 사거리 | 효과 |
|---|---|---|---|---|
| 화염 | 9 | 1.0s | 105 | 반경 40(+8/등급) 범위 60% 피해 |
| 얼음 | 7 | 0.9s | 110 | 감속 25%(+8%/등급, 최대 55%) 2초. 보스 최대 30% |
| 번개 | 8 | 1.1s | 115 | 2(+1/등급)연쇄, 70 안, 연쇄마다 70% |
| 질풍 | 4 | 0.35s | 120 | 단일, 매우 빠름 |
| 대지 | 16 | 1.6s | 100 | 기절 0.4(+0.1/등급)초, 같은 적 2.5초 면역, 보스 25% |

같은 속성·등급 3개 → 다음 등급 같은 속성(확정). 3개 합산 대비 110%/111%/109%라 합성이 항상 이득이며 자리도 절약. 등급이 달라도 같은 등급 3개면 무작위 속성으로 승급(무작위 합성).

## 봇 시뮬레이션 (`npm run balance`)
헤드리스 봇(0.5초마다 소환·확정 합성·조합·강화·자리 부족 시 무작위 합성/판매) 6시드 기준:

| 정책 | 평균 도달 | 40라운드 방어 | 첫 영웅 | 첫 전설 | 첫 신화 |
|---|---|---|---|---|---|
| greedy(강화 없음) | 40.3 | 2/6 | R1~6 | R5~12 | R14~17 |
| balanced | 40.7 | 4/6 | | | |
| upgrade(강화 우선) | 40.8 | 5/6 | | | |
| idle(유닛 5개 방치) | 12 | 0/6 | | | |

- 봇은 즉시 최적 합성·배치를 하므로 사람은 이보다 어렵습니다. 마지막 보스(체력 18800×10, 60초)가 실질적인 벽입니다.
- 10라운드 보스(체력 4170)는 총 DPS 약 300 이상이면 잡힙니다(고리를 도는 보스에는 사거리 커버리지 때문에 명목 DPS의 25~40%만 들어감).
- 방치하면 보스 10 제한시간에서 탈락합니다. 몬스터 80마리 한도는 처치 속도가 생성 속도보다 느린 상태가 3~4라운드 이어져야 도달합니다.
