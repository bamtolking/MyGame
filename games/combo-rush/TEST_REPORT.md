## 3. 수정한 오류 (개발 중 발견)
1. 공병 지원 반경(74)이 칸 간격(90)보다 작아 아무도 지원받지 못함 → 96 으로 조정.
2. 레이저가 앞선 적만 조준해 직선 구간 관통 이점이 없음 → 가장 많은 적을 관통하는 방향 조준으로 변경.
3. 합성·이동 직후 유닛 메뉴가 열린 채 남아 후보 줄이 가려짐 → 자동 선택 해제.
4. 맵 정보가 없는 손상 체크포인트로 제목 화면에서 예외 → 읽기 검증 강화 + 제목 화면에서 복원 시도 후 실패 시 삭제·안내.
5. "적 입구" 라벨이 화면 밖으로 잘림 → 화면 안쪽으로 이동.
6. 유닛 메뉴가 열릴 때 하단 패널 높이가 바뀌어 전장이 흔들림 → 하단 패널 고정 높이.
7. 가로 화면에서 힌트가 새로고침 버튼과 겹침 → 가로 레이아웃 재배치.
8. 봇 밸런스 결과 파일이 이전 게임의 docs/ 에 쓰임 → 경로를 game/docs/ 로 고정, 이전 파일 원복.
