# 합체방어대: 콤보 러시 (웹 베타)

선택형 랜덤 소환 · 합성 · 배치 전략 디펜스. 작은 기계와 정령을 소환해 합치고, 서로 다른 능력을 연결(연계)해 18웨이브의 고철 벌레와 보스 2종을 막습니다.
휴대폰 브라우저에서 바로 플레이하는 **웹 베타**입니다. 서버·로그인·결제·광고 없이 브라우저 로컬 저장만 사용합니다. Android APK / iOS 앱은 아직 만들지 않았습니다.

> 이 저장소에는 게임이 두 개 있습니다.
> - **새 게임 「합체방어대: 콤보 러시」** → `game/` 폴더. 루트의 `npm run dev / test / build` 가 이 게임을 대상으로 합니다.
> - 이전 게임 「대박수비대: 합성 대폭주」 → 루트의 `index.html`, `src/`, `tests/`, `scripts/`, `docs/`, `play/` 에 그대로 보존. `npm run legacy:dev` 로 실행합니다(권한 정책상 파일 이동이 불가능해 폴더 구조를 바꾸지 않았습니다).

## 1. 필요한 환경

- Node.js 22 (개발 환경은 v22.22.2, npm 10 으로 확인)
- 브라우저: Chrome / Safari 최신 버전 (휴대폰 포함)
- 인터넷은 `npm install` 때만 필요합니다. 게임 자체는 외부 자원을 쓰지 않습니다.

## 2. 설치

```bash
npm install
```

## 3. 개발 서버 실행 (PC + 같은 Wi-Fi 의 휴대폰)

```bash
npm run dev
```

터미널에 두 주소가 뜹니다.

```
➜  Local:   http://localhost:5173/        ← PC 브라우저에서 여는 주소
➜  Network: http://<PC의 IP>:5173/        ← 휴대폰 브라우저에서 여는 주소
```

- **휴대폰에서는 `localhost` 주소가 열리지 않습니다.** 반드시 `Network:` 줄의 IP 주소를 입력하세요.
- PC 와 휴대폰이 **같은 Wi-Fi(같은 네트워크)** 에 있어야 합니다.
- 개발 서버를 끄면(터미널 종료) 휴대폰에서도 접속이 끊깁니다.
- 접속이 안 되면 PC 방화벽에서 5173 포트(Node.js)를 허용해야 할 수 있습니다. 외부 인터넷에 공개하려면 별도 배포(정적 호스팅)가 필요하며 이 저장소는 그 설정을 포함하지 않습니다.
- PC 의 IP 확인: Windows `ipconfig` → IPv4 주소, macOS `시스템 설정 > 네트워크`, Linux `hostname -I`.

### 개발 서버 없이 휴대폰에서 열기

`npm run build` 를 하면 `game/play/index.html` 파일 하나에 게임 전체가 들어갑니다. 이 파일을 메신저/메일로 휴대폰에 보내 브라우저로 열면 서버 없이 실행됩니다(오프라인 가능).

## 4. 테스트

```bash
npm run typecheck   # TypeScript 타입 검사
npm test            # 규칙·연계·저장·밸런스(봇) 테스트 전부 (약 1분)
npm run test:rules  # 규칙·연계·저장 테스트만 (수 초)
npm run balance     # 봇 밸런스 시뮬레이션만 → game/docs/balance-results.md 갱신
npm run e2e         # 헤드리스 Chromium 으로 휴대폰 뷰포트 3종 실기동 (빌드 후 실행, 스크린샷 game/e2e-out/)
```

`npm run e2e` 는 Chromium 실행 파일이 필요합니다. 기본 경로는 `/opt/pw-browsers/chromium-1194/chrome-linux/chrome` 이며 `CHROME_PATH` 환경변수로 바꿀 수 있습니다.

## 5. 배포용 빌드

```bash
npm run build       # 타입검사 → dist/ (정적 사이트) → game/play/index.html (단일 파일)
npm run preview     # dist/ 를 로컬에서 확인
```

`dist/` 폴더를 아무 정적 호스팅(GitHub Pages, Netlify 등)에 올리면 됩니다. 상대 경로로 빌드되어 하위 경로에서도 동작합니다.

## 6. 저장 초기화

- 게임 안: 제목 화면 **설정 → 저장 초기화 → 모두 삭제**.
- 브라우저: 개발자 도구 콘솔에서 `localStorage.removeItem('combo_rush_meta'); localStorage.removeItem('combo_rush_run')`.
- 저장 항목: 설정, 튜토리얼 완료, 해금(맵 B·어려움), 연계 도감, 기록, 진행 중인 게임의 **웨이브 시작 시점 체크포인트**.

## 7. 게임 요약

- 후보 3개 중 하나를 골라 빈칸에 배치(25골드). 배치 후 후보가 갱신됩니다. 한 판 무료 새로고침 2회, 이후 12골드.
- 같은 종류·같은 등급 2기 → 합성(1→2→3등급). 3등급은 공격 방식이 바뀝니다. 판매는 실제 투입 골드의 60%.
- 유닛 8종: 화염봇, 기름분사기, 회오리 정령, 빙결술사, 레이저병, 번개코일, 폭탄병, 동력공병.
- 연계 6종: 점화 폭발(기름+화염), 집속 폭격(회오리+폭탄), 빙결 관통(빙결+레이저), 냉각 연쇄(빙결+번개), 화염 회오리(회오리+화염), 과충전 광선(공병+레이저). 처음 발견한 연계는 도감에 기록됩니다.
- 맵 2개(초록 작업장 → 클리어 시 고철 협곡 해금), 난이도 2개(보통 → 클리어 시 어려움 해금), 18웨이브, 9웨이브 중간 보스, 18웨이브 최종 보스.
- 이어하기: **게임을 닫았다가 돌아오면 마지막 웨이브 시작 시점부터 다시 진행**합니다.
