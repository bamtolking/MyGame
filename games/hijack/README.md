# 갈아타!: 바디 하이재킹 (웹 베타 0.1.0-beta.1)

죽기 직전 적의 몸을 빼앗아 살아남고, 상황에 맞는 적의 몸을 갈아타며 보안 시설을 돌파하는 세로 화면 탑다운 액션.
싱글 플레이, 서버·로그인·결제·광고 없음. 브라우저(휴대폰 포함)에서 실행되는 HTML5 게임입니다.

> 이 폴더(`galaata/`)는 저장소 안의 독립 프로젝트입니다. 상위 폴더의 `대박수비대`와는 별개입니다.

## 바로 실행하기 (비개발자용)

1. **가장 쉬운 방법**: `play/index.html` 파일 하나가 게임 전체입니다(120KB). 이 파일을 휴대폰으로 보내(메신저·메일·클라우드) Chrome/Safari로 열면 실행됩니다.
   - 안드로이드 Chrome: 파일을 열면 바로 실행됩니다. 기록은 그 브라우저의 저장소에 남습니다.
   - iOS: "파일" 앱 미리보기는 자바스크립트를 실행하지 않습니다. 개발 서버 주소로 접속하거나, 아래 아티팩트 링크를 쓰세요.
2. **개발 서버(같은 Wi-Fi의 휴대폰에서 테스트)**: PC에 Node.js 22 설치 후
   ```bash
   cd galaata
   npm install
   npm run dev        # 터미널에 표시되는 http://<PC의 IP>:5173 주소를 휴대폰 브라우저로 열기
   ```
   `localhost:5173`은 PC 안에서만 열립니다. 휴대폰에서는 반드시 PC의 IP 주소(예: `http://192.168.0.12:5173`)를 쓰고, 개발 서버를 켜 둔 상태여야 합니다.
3. **빌드**: `npm run build` → `dist/`(정적 사이트)와 `play/index.html`(단일 파일)이 다시 만들어집니다.

## 명령

```bash
npm run dev         # 개발 서버 (--host: 같은 네트워크에서 접속 가능)
npm run typecheck   # 타입 검사
npm test            # 규칙·전투·구역 테스트 (헤드리스 봇 포함, 약 5초)
npm run build       # 타입검사 + 빌드 + play/index.html
npm run e2e         # 헤드리스 Chromium(휴대폰 뷰포트 3종)으로 실기동 + 스크린샷 (e2e-out/, docs/screenshots/)
```

## 조작

- **이동**: 화면 왼쪽 아래를 드래그(가상 조이스틱, 손을 댄 곳이 중심). 손을 떼면 멈춤.
- **공격**: 오른쪽 아래 큰 주황 버튼. **누르고 있으면 연속 공격**. 조준은 자동: 조이스틱 방향의 적 → 나를 공격 중인 적 → 가까운 적 순. 적이 없으면 스위치·금 간 벽(폭탄만)을 조준.
- **스킬**: 보라 버튼. 몸마다 다름(아래 표).
- **빙의**: 위쪽 큰 버튼. 빙의 가능한 적 옆에서 누르면 그 몸을 빼앗음. 버튼 색: 회색=대상 없음, 흰 테두리=후보 있음(더 가까이), 청록 점멸=지금 가능.
- **상호작용(조작)**: 초록 버튼. 패널·수리 단자·과부하 단자 옆에서.
- **일시정지**: 오른쪽 위 ⏸. 화면을 벗어나면 자동 정지.
- PC: WASD/방향키 이동, J 공격, K 스킬, L(또는 F) 빙의, E 상호작용, P/Esc 일시정지.

## 몸 갈아타기 규칙

| 규칙 | 값 |
|---|---|
| 빙의 가능 조건 | 적 체력 **35% 이하** 또는 **기절**(정비병 감전 100 누적) |
| 표시 | 머리 위 흰 다이아몬드 + 흔들리는 윤곽. 사거리 안이면 청록색 + "빙의 가능" |
| 빙의 거리 | 약 2칸(72px). 가장 가까운 후보 자동 선택 |
| 빙의 후 체력 | 그 몸의 **남은 체력 유지**, 단 **최소 45%까지 이식 회복** |
| 안정도 | 새 몸 최대치로 시작. 시간(초당 1.4~2.2)과 피해(피해량×0.45~0.7)로 감소. 0 → 붕괴(초당 최대체력 18% 손실). 붕괴 중에도 빙의 가능 |
| 재사용 대기 | 빙의 후 1.75초. 빙의 직후 0.7초 무적 |
| 마지막 기회 | 체력 0이 되어도 약 3.5칸 안에 후보가 있으면 1초간 슬로모션. 그 안에 빙의하면 생존 |
| 빙의 불가 | 보스(코어 잠금 표시), 포탑, 보호막 노드 |
| 기본 몸 | 침입자는 안정도 없음(붕괴 없음). 빙의하면 침입자 몸은 사라지고 돌아올 수 없음 |

## 한 판 구조 (5~8분 목표)

1. **침입 구역**: 정찰병 → 방패병(포탑 통로+패널) 또는 폭탄병(금 간 벽 지름길). 폭탄병을 죽이면 지름길이 없다.
2. **포탑 통로**: 방패병 정면 돌파 / 정찰병 질주 강행 / 정비병 과부하 단자로 포탑 정지. 통과 보상: 수리 단자.
3. **균열 벽과 스위치**: 폭탄병으로 벽 파괴 / 저격병(또는 폭탄병 폭발)으로 구덩이 건너 스위치. 침입자·정찰병만으로는 못 나감.
4. **연속 갈아타기**: 봉쇄 구역, 3차 경비. 3차까지 온 뒤 경비 1명 이하(또는 시간 경과)면 출구 개방. 금 간 벽 뒤 수리 단자.
5. **감시 코어**: 보스. 66%에서 보호막(좌우 노드 파괴 필요, 포탑·폭탄병·저격병 소환), 33%에서 돌진 후 코어 노출(피해 2.5배). 코어는 빙의 불가.

패배: 조종 중인 몸이 죽고 근처에 빙의 가능한 몸이 없을 때. 승리: 보스 처치.

## 저장·이어하기·초기화

- 저장 대상: 설정, 기록(도전 횟수·클리어·최고 시간·최고 도달·최장 생존·누적 빙의·몸별 사용 시간), 몸 도감, 도전과제 10개, 튜토리얼 완료, 어려움 해금, **체크포인트(구역 시작 시점의 몸·체력·안정도)**.
- 이어하기 정책: **런 도중 종료 시 현재 구역 시작 지점부터 재개**(체력·안정도는 최소 50%까지 보정). 구역 중간 상태는 저장하지 않습니다. 패배 화면의 "이 구역부터 재도전"도 같은 체크포인트를 씁니다.
- 어려움 모드: 한 번 클리어하면 설정에서 켤 수 있음(적 피해 1.35배, 안정도 감소 1.3배).
- **저장 초기화**: 설정 → "저장 데이터 초기화" → 확인. (브라우저 저장소 `localStorage`의 `galaata_v1` 키)
- 저장소를 쓸 수 없는 환경(시크릿 모드 등)에서는 화면 아래에 경고가 뜨고 이번 세션에만 기록됩니다.

src/ui/        앱(화면·루프·런·체크포인트·튜토리얼), HUD, 입력(조이스틱·버튼), 화면 마크업
