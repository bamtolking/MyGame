# DEVELOPMENT_NOTES — 갈아타!: 바디 하이재킹

다음 작업자를 위한 상태 설명. 모든 명령은 `galaata/` 안에서 실행.

## 실행 명령
- `npm install` → `npm run dev`(개발 서버, `--host`) / `npm run typecheck` / `npm test` / `npm run build`(→ `dist/`, `play/index.html`) / `npm run e2e`(헤드리스 Chromium 실기동, 스크린샷)

## 환경 장치 규칙
| 장치 | 글리프 | 규칙 |
|---|---|---|
| 금이 간 벽 | `X` | 체력 50. 폭발(`breaksWalls`)만 피해. 투척 폭탄 30(2발), 과부하 폭탄 70(1발). 부서지면 바닥 |
| 원거리 스위치 | `1`/`2`/`3` → 문 `A`/`B`/`C` | 플레이어 편 투사체·폭발이 반지름 18 안에 닿으면 켜짐(1회). 자동 조준이 적이 없을 때 스위치를 잡음 |
| 문 패널 | `!`/`@`/`$` → 문 `A`/`B`/`C` | 상호작용 1초 채널 |
| 문 | `A`/`B`/`C` | 잠금 종류는 스위치/패널/웨이브/과부하 중 자동 판정. 잠금이 없으면 처음부터 열림 |
| 포탑 | `^v<>` | 체력 45, 사거리 215, 3점사(같은 볼리). 태그 `corridor`는 과부하 단자로 정지. 타일은 경로 탐색에서 벽 취급 |
| 수리 단자 | `R` | 1회. 정비병 즉시 전체 회복·안정도 +40 / 그 외 2.5초 채널 후 체력 35%·안정도 +20 |
| 과부하 단자 | `O` | 정비병만 1.5초 채널. 구역의 `overload` 설정대로 포탑 정지·문 개방 |
| 소환구 | `V` | 읽는 순서대로 `v0..`. 웨이브·보스 소환 위치(0.9초 예고 링) |
| 출구 | `E` | 열린 상태에서 밟으면 구역 통과 |
| 보스/노드/포탑 위치 | `Z`/`N`/`T` | 5구역 전용 |

## 구현 완료
- 핵심 흐름: 이동 → 전투 → 적 약화 → 빙의(마지막 기회 포함) → 새 몸 무기·스킬 → 장치 돌파 → 연속 갈아타기 → 보스 → 결과 → 재도전(구역부터/처음부터).
- 몸 6종(무기·스킬·안정도 모두 다름), 포탑, 보스(3단계), 장치 4종+문·패널·소환구, 구역 5개, 웨이브, 체크포인트, 기록·도감·도전과제 10개, 어려움 모드 해금, 설정(음량·음소거·효과 강도·힌트·피해 숫자), 튜토리얼(체험형 5단계, 건너뛰기=설정에서 힌트 끄기, 도움말 다시 보기), 자동 일시정지, 단일 파일 빌드.

## 미완료 · 알려진 제한
- 사람 플레이·실기기 검증 없음(TEST_REPORT 참고). 보스 2단계·4구역 웨이브 난이도는 봇 기준으로 어렵게 나옴.
- 가로 화면은 최소 대응만. 태블릿 큰 화면에서는 세계가 작게 보일 수 있음(`renderer.scale` 상한 1.45).
- 배경음 없음(효과음만). 진동 없음.
- 적끼리의 우군 피해 없음(의도). 정비병 AI는 자가 회복을 하지 않음(빙의 창 보장, 의도).
- 빙의 대상이 문 반대편 등 벽 너머에 있어도 거리만 맞으면 빙의됨(벽 통과 빙의). 첫 버전에서는 허용.
- PWA(오프라인 설치) 없음. 스토어·공개 배포 없음.
