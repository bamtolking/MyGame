# 테스트 결과 (TEST_REPORT)

이 문서는 실제로 수행한 검증만 기록합니다. 검증 종류를 구분해 적습니다.

## 1. 로직·물리·저장 자동 테스트 (Vitest) — 통과

명령: `npm test` (약 1초). `tests/`의 47개 테스트 전부 통과.

- **물리 안정성**(`tests/physics.test.ts`)
  - 아무 입력 없이 10초 기다려도 세워 둔 기둥이 유지됨(위치·각도 변화 < 0.5px, 0.01rad).
  - 최대 속도(1450px/s) 발사체가 두께 22px 블록을 각도 0~40°에서 관통하지 않음.
  - 밧줄 절단이 실제 제약 조건 해제로 이어지고, 같은 밧줄은 한 번만 잘림. 절단 후 추가 낙하.
  - 빠른 발사체가 밧줄을 지나가면 스윕(이전↔현재 위치) 판정으로 잘림. 멀리 지나가면 안 잘림.
  - 회전하는 발판의 밧줄 연결점이 물체를 따라 정확히 이동(오차 < 0.01px).
  - 시소 축이 추 낙하 후에도 이동하지 않음(드리프트 < 2px).
  - 공이 경사면 이음새에서 90px/s 이상 비정상적으로 튀지 않고 실제로 굴러 내려감.
  - 잠든 블록이 굴러온 쇠공의 충돌에 깨어나 움직임.
- **발사·미리보기**: 짧은 당김 취소, 최대 당김 제한, 조준 미리보기와 실제 첫 비행의 오차 < 1.5px, 속도 계산 일관성.
- **세션 상태 기계**: 비행/성공/실패 중 발사 무시와 탄 수 정확, 첫 발 결과 유지, 작은 흔들림 오판 없음, 보호상자 직접 명중·안전 구역 이탈 판정, 바닥 접촉은 실패 아님, 목표 1회 집계·콤보 창, 반복 재시작 시 물체·제약 수 불변.
- **저장**(`tests/save.test.ts`): 손상 데이터 거부, 최고 기록만 갱신(낮은 기록으로 덮어쓰지 않음), 별 중복 누적 없음, 해금 범위 초과 없음.
- **스테이지**(`tests/levels.test.ts`): 20개 데이터 규칙 준수, 해법 버전 일치, 각 스테이지 해법 재생 성공+보호 안전+3별 기준 충족, 무입력 시 자동 성공/실패 없음, 빗나간 약한 발사로 성공하지 않음, 대표 스테이지 재생 결정성.

## 2. 스테이지 전체 물리 재생 검증 (validate) — 20/20 통과

명령: `npm run validate` (`scripts/validate-levels.ts`). 결과 표: `docs/LEVEL_VALIDATION.md`, 원자료: `docs/level-validation.json`.

각 스테이지에 대해 실제 물리로 다음을 확인:

- 데이터 규칙 검사(두께·배치·역할·별 기준 등) 통과.
- 무입력 8초 동안 목표·보호물에 변화 없음(자동 성공/붕괴 없음).
- 기록된 해법 입력 재생 시 성공, 보호물 안전, 3별 기준 충족.
- 같은 입력 3회 재생 결과와 최종 위치가 완전히 동일(결정성).
- 각 발사에 ±1.5°, ±0.03(정규화 세기) 흔들림 8종을 주었을 때의 성공률(해법 여유 확인).
- 실패 입력(약한 발사·수직 발사·보호상자 방향 발사)이 성공으로 처리되지 않음.

흔들림 성공률은 대부분 8/8이며, 일부 정밀 스테이지(L03 7/8, L15 6/8, L16 11/16, L17 13/16)는 낮습니다. 이는 한 픽셀 정답이 아니라 여유가 상대적으로 좁다는 뜻이며, 기록된 해법은 격자 탐색의 견고한 지점(이웃도 성공)에서 골랐습니다.

## 3. 브라우저 실기동 테스트 (헤드리스 Chromium, 모바일 뷰포트) — 통과

명령: `npm run e2e` (`scripts/e2e.mjs`, Playwright + 사전 설치 Chromium). 뷰포트 390×844 / 360×800 / 430×932.

- 실제 터치 이벤트(CDP `Input.dispatchTouchEvent`)로 발사대를 당겨 발사.
- **20개 스테이지 전부를 터치 조작으로 클리어**(각 3별) — 콘솔·페이지 오류 0건.
- 짧은 당김·터치 취소가 발사되지 않음, 힌트 등 UI 버튼 터치가 발사로 처리되지 않음 확인.
- 조준 미리보기·발사·비행·밧줄 절단·시소·공·도미노·보호물·연쇄 붕괴·결과 화면 스크린샷 저장(`e2e-out/`).
- 재시작 후 물체·제약 수 불변, 일시정지 시 시뮬레이션 스텝 정지, 재개 후 진행, 새로고침 후 타이틀에 "이어하기" 표시(현재 스테이지 처음부터).

## 수정한 주요 오류

- 초기 도미노 연쇄가 서브스텝(4.17ms) 접촉 감쇠로 멈추던 문제 → 단일 60Hz 갱신 + 중력 1.6배(미니어처 스케일)로 해결.
- 원형 물체가 변 수 부족으로 매끄럽게 구르지 않던 문제 → 40각형 근사로 생성.
- 조준 상태에서 뒤늦게 목표가 무너져도 성공 처리되지 않던 누락 → `observeLateSuccess` 추가.
- 천천히 기울어지는 블록을 안정으로 오판하던 문제 → 최근 0.75초 누적 이동·회전(creep) 검사 추가.
- 얇은 발판(두께 18~20px)이 최대 속도 발사체에 관통될 수 있던 문제 → 최소 두께 22px 규칙(lint)로 강제.

## 확인하지 못한 항목 (한계)

- **실제 휴대폰 기기 테스트 미수행**: iOS Safari / Android Chrome의 실제 터치 반응·오디오 잠금 해제·성능(FPS)은 검증하지 못했습니다. 여기서 "모바일"은 헤드리스 Chromium의 모바일 뷰포트를 뜻합니다.
- **사람 플레이 테스트 미수행**: 자동 재생으로 풀린다는 것과 사람이 느끼는 재미·난이도는 다릅니다. 재미는 검증되지 않았습니다.
- **다른 브라우저 엔진의 비트 단위 동일성 미보장**: 같은 환경·같은 입력의 재현성만 검증했습니다.
- 오디오는 코드로 재생 경로만 확인했고 실제 소리 품질은 사람이 듣지 않았습니다.
