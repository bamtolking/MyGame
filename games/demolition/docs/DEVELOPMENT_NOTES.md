# 개발 노트 (DEVELOPMENT_NOTES)

## 현재 구조

- **TypeScript + Vite + matter-js(0.20.0) + Canvas 2D.** 물리 월드는 matter-js 하나만 사용.
- 레이어 분리: 데이터(`src/data`) → 시뮬레이션(`src/sim`, DOM 없음) → 렌더/입력/플랫폼(`src/render`, `src/ui`, `src/platform`).
- 시뮬레이션은 순수 TS라 Node에서 그대로 재생·검증 가능(테스트·validate·solve 스크립트가 이를 사용).

## 주요 게임 규칙

- **발사**: 발사대에서 당김 벡터 → 반대 방향 발사. 세기는 당김 거리/최대 당김(0~1). 최대 속도 1450px/s. 짧은 당김(<18px)·터치 취소·UI 터치는 발사 안 함. 스테이지당 1~2발.
- **밧줄 절단**: 발사체의 이전↔현재 위치 선분과 밧줄 선분의 최소 거리 ≤ 반지름+2px이면 절단. 스윕 방식이라 빠른 발사체도 놓치지 않음. 같은 밧줄은 한 번만. 절단 시 제약 조건 제거 + 양끝 물체 깨움.
- **판정**: 넘어뜨리기 = 초기 자세 대비 50° 이상 + 중심 이동, 또는 높이 1.5배 낙하; 0.3초 유지. 떨어뜨리기 = 중심이 구역 안 0.3초(구역 지나 소멸도 인정). 보호 = 발사체 직접 접촉 또는 중심의 안전 구역 이탈.
- **결과 판정 순서**: 매 물리 스텝에서 보호물 실패를 목표보다 먼저 확인. 목표 전부 달성 후에도 주요 물체가 안정될 때까지(또는 최대 5초) 관찰해 굴러오는 공 등의 뒤늦은 보호물 실패를 잡음. 발사 후 최대 관찰 13초.
- **안정 감지**: 동적 물체의 속도·각속도 + 최근 0.75초 누적 이동(creep)으로 판단. 매달린 추는 완화된 기준. 장식 파티클은 판정에 무관.
- **별**: 사용 탄 수가 `stars.three` 이하면 3별, `stars.two` 이하면 2별, 성공하면 최소 1별.

## 물리·밸런스 설정 위치

- `src/data/physics.ts`: 고정 스텝(1/60s), 서브스텝(1), 중력(1.6), 발사(최대 당김·속도·미리보기), 발사체(반지름 15·밀도·반발), 판정 기준값(JUDGE), 수면 임계값, 경계.
- `src/data/materials.ts`: 재질별 밀도·마찰·정지 마찰·반발·공기 저항·구름 저항(나무/금속/콘크리트/쇠/보호상자/바닥/커터볼).
- 스테이지별 좌표·수치: `src/data/levels/L01~L20.ts`. 임시 보정 힘 없이 재질·배치로만 조정.

## 구현 완료

- 발사·조준·미리보기(엔진과 같은 Verlet 적분), 커터볼 1종, 밧줄 스윕 절단.
- 핵심 장치 5종: 구조 블록, 밧줄+매달린 추, 힌지 발판/시소, 고정 경사면, 굴림 공. 공통 요소: 발사대·바닥·목표 표시·보호상자.
- 장치 연계: 블록 도미노, 밧줄 절단→추 낙하→목표, 추 낙하→시소 회전→공 이동, 공→경사면→목표, 두 밧줄 중 하나 절단, 그리고 밧줄→추→시소→공→도미노 대연쇄(L20).
- 목표 2종(넘어뜨리기·떨어뜨리기), 보호상자(직접 명중·구역 이탈), 성공/실패 안정 판정과 최대 관찰 한도.
- 20개 스테이지 + 각 스테이지의 검증된 해결 입력(`solutions.ts`)과 전체 재생 검증(`validate`).
- 상태 기계(초기화·조준·발사후·일시정지·결과·성공·실패), 다시 시작(완전 복원), 힌트 2단계, 튜토리얼(기본·밧줄·공·시소·보호·2발), 콤보.
- 모바일 UI(세로 우선·안전 영역·44px+ 터치·스크롤 방지), 상/중/하 HUD.
- 절차적 그래픽(재질 패턴·목표 줄무늬·시소 볼트·커터볼 절단 링·쇠공), 파티클·먼지·불꽃·끊긴 밧줄 반응·화면 흔들림(감소 옵션), WebAudio 절차적 효과음(당김·발사·나무/금속/돌 충돌·절단·구름·목표·성공/실패·별, 동시 재생·간격 제한).
- 로컬 저장(검증·손상 처리·초기화), 백그라운드 자동 정지, 개발용 재생·충돌 모양·연결점 보기(?dev=1).

## 구현하지 않음 (첫 버전 제외 범위)

- 로그인·온라인·서버 랭킹·광고·결제·가챠·에너지·유료 힌트.
- 웨이브/물리 진행 중 상태 저장(정책상 스테이지 처음부터 재시작), 물리 되감기.
- 슬로모션, 다수의 특수탄·스킬, 실시간 조각 파괴, 정밀 구조 해석.
- 추가 맵·무한 모드, PWA(설치형), Android/iOS 네이티브 패키징. (플랫폼 코드는 `src/platform`으로 분리되어 이후 Capacitor 등으로 감쌀 수 있음.)

## 실행 명령

`npm run dev` / `npm run typecheck` / `npm test` / `npm run validate` / `npm run build` / `npm run e2e`.
개발용 도구: `npx tsx scripts/solve.ts L07` (해법 격자 탐색), `npx tsx scripts/describe.ts L07 25,0.85` (상태 추적).
