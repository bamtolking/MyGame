# 나 혼자 도둑단: 25초의 공범 (웹 베타 v0.1)

보안 로봇이 지키는 시설에서 25초 안에 에너지 코어를 훔쳐 나오는 모바일 우선 탑다운 액션.
**실패한 시도의 내 행동이 다음 시도에서 "분신"으로 그대로 재생**되고, 분신의 공격은 실제로 피해를 주고
분신이 밟은 발판은 실제로 작동합니다. 분신에게 한 가지 일을 맡기고, 나는 다른 길로 코어를 가져옵니다.

- 순수 TypeScript 고정 스텝(60Hz) 시뮬레이션 + Canvas 2D. 서버·로그인·결제·광고 없음.
- 작전 6개, 무기 2종(연사 소총·산탄총), 적 3종(추적 경비·고정 포탑·중장갑 경비), 장치 4종(발전기·시간 발판·레이저·금고/코어).
- 분신 기록 슬롯 3개, 기록 추가/버리기/다시 녹화(취소 시 기존 기록 복원), 일찍 기록 마치기.
- 저장: 이 브라우저의 로컬 저장소(localStorage). 승인한 분신 기록·최고 기록·해금·설정만 저장됩니다.

## 휴대폰에서 바로 플레이 (비개발자용)

`play/index.html` 한 파일이 게임 전체입니다(빌드 결과물, 외부 자산 없음).

1. **가장 쉬운 방법**: 이 파일을 휴대폰으로 보내(메신저·메일·클라우드) 브라우저(Chrome/Safari)로 열면 바로 실행됩니다.
2. **같은 Wi‑Fi의 PC에서 개발 서버 띄우기**: PC에 Node.js 22를 설치한 뒤
   ```bash
   cd heist
   npm install
   npm run dev          # 터미널에 표시되는 http://<PC의 IP>:5173 주소를 휴대폰 브라우저로 열기
   ```
   휴대폰에서 `localhost`는 열리지 않습니다. 터미널에 표시되는 **Network** 주소(예: `http://192.168.0.12:5173`)를 쓰세요. 개발 서버가 켜져 있는 동안만 접속됩니다.
3. 이 저장소가 원격(클라우드) 환경에서 만들어졌다면 그 환경의 주소는 휴대폰에서 열 수 없습니다. 1번 또는 2번을 이용하세요. 공개 배포(호스팅)는 하지 않았습니다.

세로 화면 기준(360×800 / 390×844 / 430×932에서 확인). 가로 화면에서도 동작하지만 버튼이 작아집니다.

## 조작

| 조작 | 방법 |
|---|---|
| 이동 | 화면 **왼쪽 아무 곳**을 누른 자리에 조이스틱이 생깁니다. 손가락을 떼면 멈춥니다. |
| 공격 | 자동. 사거리·시야 안의 가까운 위협(포탑 우선)을 쏩니다. 적이 없으면 발전기를 쏩니다. |
| 대시 | 오른쪽 아래 **대시**(3초 대기, 짧은 무적). 벽·레이저는 통과하지 못합니다. |
| 상호작용 | 발전기 근처에서 **발전기 조준**: 경비보다 발전기를 먼저 쏩니다. |
| 기록 마치기 | 살아 있을 때 누르면 그 시점까지의 기록으로 시도를 끝냅니다. 분신이 되면 **마지막 위치를 남은 시간 내내 유지**(발판 점유 가능). |
| 코어 회수 | 열린 금고 옆에 **0.7초** 머무르면 회수. 코어를 든 채 출구(시작 지점)에 도착하면 성공. |
| PC | WASD/방향키 이동, Space 대시, E 조준, F 기록 마치기 |

**시도 종료 뒤 선택지**: 이번 기록 추가하고 재도전 / 버리고 재도전 / 기록 하나 다시 만들기.
슬롯을 다시 녹화하는 동안 해당 분신은 그 시도에서 제외되고, 새 기록을 저장하기 전까지 기존 기록이 보존됩니다(취소하면 복원).

**기록 종료 방식**: ⏹ 일찍 마침 = 마지막 위치 유지 · ✖ 사망 = 그 시각 이후 사라짐 · ⏱ 시간 종료 = 25초 재생 뒤 종료.
분신은 코어를 옮기거나 대신 탈출할 수 없고, 적·레이저에 죽거나 밀리지 않습니다(시간 투영체).

## 규칙 요약

- 한 시도 25초. 성공(코어 들고 출구) / 사망 / 시간 종료 / 기록 마치기로 끝납니다.
- 시도가 끝나면 시설은 동일한 시작 상태로 되돌아갑니다. 실패해도 적이 강해지지 않습니다.
- 분신 최대 3명 + 현재 플레이어 1명. 분신은 **현재 플레이어의 실제 행동 기록만** 재생합니다(분신의 행동은 다시 기록되지 않음).
- 분신의 공격은 현재 월드에 실제 투사체를 만들고, **지금 그 자리에 맞는 대상이 있을 때만** 피해를 줍니다. 벽에 막히고, 적이 다른 위치에 있으면 빗나갑니다. 분신은 새로 조준하지 않습니다.
- 경비는 현재 플레이어만 쫓습니다. 다만 총알을 맞거나 가까운 총성을 들으면 그 자리를 확인하러 갑니다(그래서 기록 당시와 비슷하게 움직입니다).
- 레이저는 현재 플레이어에게만 위험합니다(닿으면 피해 2 + 밀려남, 켜져 있으면 통과 불가). 발전기를 부수면 연결된 레이저가 꺼집니다. 시간 패턴 레이저는 켜지기 0.8초 전에 점멸합니다.
- 금고는 연결된 발판이 모두 눌리고 연결된 발전기가 모두 파괴되면 열립니다. 조건이 다시 깨져도 **2.5초** 동안 열려 있습니다. 회수한 코어는 빼앗기지 않습니다.
- 중장갑 경비는 몸으로 길을 막고(통과 불가) 예고된 방향으로 강타합니다. 피격 후 0.8초 무적이라 한 프레임에 즉사하지 않습니다.
- 기록 항목: 클리어 여부, 탈출 시간, 사용한 분신 수, 받은 피해, 성공한 구성. "더 빠르게"와 "더 적은 분신으로"는 따로 표시됩니다. 일반 클리어만으로 다음 작전이 열립니다.

## 개발 명령

```bash
cd heist
npm install
npm run dev        # 개발 서버 (--host: 같은 네트워크의 휴대폰에서 접속 가능)
npm run typecheck  # 타입 검사
npm run test       # Vitest: 엔진 규칙·분신 재생·세션/저장·6개 작전 해법 검증 (tests/solutions/*.json 갱신)
npm run build      # 타입검사 + Vite 빌드(dist/) + 단일 파일 play/index.html
npm run e2e        # 헤드리스 Chromium, 휴대폰 뷰포트 3종 + 가로 1종 실기동 → e2e-out/*.png, e2e-out/report.txt
```

## 저장 초기화

타이틀 화면의 **저장 초기화** 버튼, 또는 브라우저 개발자 도구에서 `localStorage.removeItem('solo_heist_25s_v1')`.
저장 데이터가 손상되면 읽을 수 있는 부분만 복구하고 타이틀 화면에 사유를 표시합니다.
맵 버전이 바뀌면 그 작전의 이전 분신 기록은 사용할 수 없어 비워지고 안내합니다.

## 구조

```
src/sim/      순수 시뮬레이션(DOM 없음): constants, geom(충돌·시야), rng, maps(ASCII→벽), engine(한 틱 진행·기록·재생), ai(적), recording(검증), bot(테스트용 경로 입력)
src/data/     missions.ts — 작전 6개 (그리드·장치·적·버전)
src/game/     loop(고정 스텝·일시정지), session(슬롯·다시 녹화·기록 반영), storage(검증 저장)
src/render/   renderer(카메라·월드·연출), sprites(절차적 캐릭터/로봇/장치), fx(파티클)
src/ui/       app(화면·HUD·흐름), input(조이스틱·버튼·키보드), audio(WebAudio 효과음)
tests/        core(핵심 장면 A/B 비교·결정론·분신 규칙), shell(루프·세션·저장), missions(6개 작전 해법·장치 규칙), solutions/*.json(검증된 입력·기록)
scripts/      singlefile.mjs(단일 HTML), e2e.mjs(Playwright 실기동)
```

자세한 규칙과 다음 작업은 `DEVELOPMENT_NOTES.md`, 테스트 결과는 `TEST_REPORT.md`를 보세요.
