## 왜 Phaser가 아닌 자체 엔진인가

분신 재생의 핵심은 "고정된 게임 시간 기준으로 기록된 위치를 그대로 재생"하는 결정론이다. Phaser Arcade 물리는 프레임 시간에 따라 결과가 달라지고 헤드리스 테스트가 번거롭다.
같은 저장소의 기존 게임(대박수비대)이 이미 검증한 구조(순수 TS 고정 스텝 시뮬레이션 + Canvas 2D + Vitest + Playwright)를 그대로 따랐고, 의존성은 동일 버전으로 고정했다.

## 기록 형식 (Recording)

```
{ v:1, mapId, mapVersion, weapon, endKind: finish|death|timeout|escape, endTick,
  pos:[x0,y0,x1,y1,...] (0.1px 정수, 틱당 1개), face:[deg...], shots:[{t,x,y,w,a:[각도...]}], dashes:[tick...] }
```
- 현재 플레이어 자신의 위치·방향·실제 발사(산탄 펠릿 각도 포함)·대시만 기록. 분신의 발사·파생 효과는 기록하지 않는다(테스트로 보장).
- 재생: 틱 t에서 `pos[t-1]`. `finish/escape`는 마지막 프레임 유지, `death/timeout`은 프레임이 끝나면 소멸. 발사는 기록된 틱에 기록된 위치·각도로 실제 투사체 생성.

## 중요한 규칙·결정

- 분신은 시간 투영체: 피격·밀림·레이저 영향 없음, 코어 회수·탈출 불가, 서로 몸을 밀지 않음.
- 적은 현재 플레이어만 조준. 다만 **총알에 맞거나 230px 안에서 총성을 들으면(시야 필요) 그 지점을 확인하러 간다** — 기록 당시 플레이어를 쫓던 움직임을 재생 시에도 비슷하게 만들기 위한 위치 기반 규칙. 중장갑 경비는 듣지 않는다.
- 레이저: 켜져 있으면 현재 플레이어에게 벽 + 접촉 시 피해 2와 밀어내기. 타이머 레이저는 off → warn(0.8s 점멸, 통과 가능) → on.
- 금고: 조건이 깨져도 2.5초 유지(사람이 이해할 수 있는 여유). 코어 회수 0.7초 채널(엄호의 가치).
- 자동 조준 우선순위: 포탑 우선, 멀리 있는 중장갑 경비는 후순위, 그 외 가까운 순. 발전기는 적이 없을 때 또는 "발전기 조준" 토글 시.
- 이동: 축 분리 슬라이딩, 이미 겹친 벽은 축 처리에서 제외(순간이동 방지), 잔여 겹침은 최소 침투 방향으로 밀어냄.
- 시드 난수는 소총 탄 퍼짐에만 쓰인다. 같은 입력 = 같은 결과(배치 크기 무관, 테스트).

## 알려진 한계 · 미검증

- 이동하는 추적 경비를 노린 분신 공격은 이번 시도에서 경비 위치가 다르면 빗나갈 수 있다(의도된 규칙). 포탑·발전기·중장갑 경비처럼 고정 대상이 분신에게 맡기기 확실한 일이다.
- 작전 5의 왼쪽 레이저 우회로는 사람의 타이밍이 필요해 봇으로는 검증하지 못했다(봇은 레이저에 부딪혀 사망). 오른쪽 경로는 분신 유/무 모두 검증.
- 작전 3은 완벽한 플레이라면 분신 없이도 통과 가능(체력 2 남음). 규칙상 허용.
- 사람이 느끼는 재미·조작감·분신 규칙의 이해도는 검증되지 않았다.
