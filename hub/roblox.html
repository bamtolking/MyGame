⬇ 실행 파일 받기 ({{FILE_SIZE}})

{{FILE_NAME}} · 마지막 업데이트 {{UPDATED}} (한국 시간, 커밋 {{COMMIT}}) · 개발할 때마다 이 주소의 파일이 새 버전으로 바뀝니다

🖥️ PC·Mac 에서 바로 실행

  1. Roblox Studio 를 설치하고 로그인합니다 (무료).
  2. 위 버튼으로 받은 {{FILE_NAME}} 파일을 더블클릭합니다. 열리지 않으면 Studio 에서 File → Open from File.
  3. 위쪽 ▶ Play (F5) 를 누르면 게임이 시작됩니다. 여러 명으로 시험하려면 Test 탭 → Clients and Servers → 플레이어 2~3명 → Start.

처음 Play 하면 Output 창에 “DataStore 사용 불가 → 메모리 저장” 경고가 뜨는데 정상입니다.

📱 아이폰·안드로이드 로블록스 앱에서 하려면

로블록스 게임은 파일로는 휴대폰에서 실행할 수 없고, 한 번 로블록스에 올려야 앱에서 할 수 있습니다.

  1. PC 의 Roblox Studio 에서 파일을 열고 File → Publish to Roblox → 새 게임으로 올립니다.
  2. Game Settings → Places 에서 최대 플레이어를 8명으로 둡니다 (기지가 8개).
  3. 휴대폰 로블록스 앱에서 같은 계정으로 로그인하면 내 창작물(Creations)에서 바로 실행할 수 있습니다. 친구도 하게 하려면 Game Settings 에서 공개(Public)로 바꿉니다.

새 버전이 나오면 새 파일을 Studio 로 열고 같은 게임에 다시 Publish 하면 됩니다.

지금 휴대폰으로 이 페이지를 보고 있다면 아래 주소를 PC 로 보내서 여세요.
