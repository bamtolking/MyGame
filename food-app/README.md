# 먹는 원리 — 기능의학 식품 사전

음식을 검색하면 **영양성분 → 핵심 성분 → 그 성분이 몸에 들어와 작용하는 과정(단계별 기전) → 먹는 법 → 주의점과 흔한 오해**를 보여주는 웹앱입니다.
모든 기전에는 **근거 수준**(강함·중간·제한적·논쟁 중)을 경로마다 따로 표시합니다. 예를 들어 "안토시아닌이 활성산소를 직접 중화한다"는 시험관에서는 맞지만 몸속에서는 근거가 제한적이라, 실제 주요 경로(Nrf2 신호, 혈관 산화질소)와 나란히 보여줍니다.

## 바로 쓰기

- **휴대폰/PC에서 파일로**: `play/index.html` 하나가 앱 전체입니다. 브라우저로 열면 됩니다(인터넷 없이도 동작, 폰트만 기본 폰트로 표시).
- **claude.ai에서**: `play/artifact.html`을 Artifact로 올리면 DB에 없는 식품도 **AI 분석**(Claude가 같은 형식으로 작성)과 **더 물어보기**를 쓸 수 있습니다. AI가 쓴 항목은 "AI가 작성한 분석"으로 따로 표시되고 그 브라우저에만 저장됩니다.

## 기능

- 검색: 이름·별칭·영어, **초성 검색**(ㅅㄱㅊ → 시금치), 한 글자 오타 허용, 성분·작용(항산화, 염증 유발 등)으로도 검색
- 식품 페이지: 한국식 영양정보 표(100g / 1회 분량 전환, 1일 영양성분 기준치 %, 식약처 기준 "함유"·"풍부" 표시, 열량 구성 막대), 성분별 작용 경로 다이어그램, 먹는 법·궁합, 주의·흔한 오해
- 성분 페이지: 경로 1~3개(흡수 → 대사 → 표적 → 결과), 근거 요약, 알아두면 좋은 사실, 이 성분이 들어 있는 식품, 참고자료
- 작용별 보기, 분류별 보기, 최근 본 식품, 밝은/어두운 테마

## 데이터

```
src/data/types.ts        스키마 (식품·성분·경로·근거 수준)
src/data/nutrients.ts    영양소 정의와 1일 영양성분 기준치(식약처 「식품등의 표시기준」)
src/data/catalog.ts      성분 id 목록 — 식품은 이 id로만 성분을 참조
src/data/compounds/*.ts  성분 설명 (기전·근거·참고자료)
src/data/foods/*.ts      식품 (100g당 영양성분, 핵심 성분, 먹는 법, 주의, 오해)
```

- 영양성분은 USDA FoodData Central(SR Legacy) 등 공개 DB의 100g당 대략값이며, 확실하지 않은 항목은 비워 둡니다.
- 식품 추가: `src/data/foods/`의 파일에 항목을 추가하고 `npm test`로 검사합니다(열량≈탄단지 계산, 지방산 합계, 성분 참조 등).
- 성분 추가: `catalog.ts`에 id를 넣고 `src/data/compounds/`에 설명을 씁니다. 목록에 있는데 설명이 없으면 테스트가 실패합니다.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173 (같은 Wi-Fi의 휴대폰은 PC IP:5173)
npm test         # 데이터 무결성 + 검색 + AI 응답 정리 테스트
npm run build    # 타입검사 + 빌드 + play/index.html, play/artifact.html 생성
npm run shot     # 헤드리스 Chromium으로 휴대폰 화면 캡처 (shots/)
node scripts/e2e-ai.mjs   # window.claude를 흉내 내 AI 분석·질문 흐름 점검
```

## 한계

- 교육용 정보이며 진단·치료를 대신하지 않습니다.
- 내용은 공개된 연구·기관 자료를 바탕으로 정리했지만, 전문가 검수를 거치지 않았습니다. 수치는 품종·조리법에 따라 달라집니다.
- AI 분석은 claude.ai 안에서만 동작하며, 보는 사람의 Claude 사용량을 씁니다(첫 사용 시 허용 여부를 묻습니다).
